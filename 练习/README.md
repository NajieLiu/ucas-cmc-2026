每册专题练习都是同一套结构，先扫一眼头部就会用：

- **头部说明**：适用考试、题源范围、本专题考试地位、建议训练用时、题目分布统计；
- **题目分布速览表**：逐题列出 届次 / 题号 / 难度 / 方法标签，可以当目录和自检清单用；
- **A 组（近年真题，第 10–17 届）**：解答引自官方参考答案，保留原卷过程分标注；
- **B 组（早期真题，第 1–9 届）**：解答来自备考项目编写或转录的参考解答（均已逐题验算；具体来源标注见各册头部说明）；
- **C 组（部分册：09、10、12、13）**：综合提高题。

格式提示：全部文件为 Markdown + KaTeX 公式，建议用支持数学渲染的编辑器打开（Typora / Obsidian / VS Code + 插件）。（PDF 若被某些阅读器提示异常，用 Edge/WPS/福昕打开即可——解析器误报，文件本身无加密）

## 二、三块材料怎么配合用

### 第 1 块 · 专题练习 —— 跟教学文档同步，「学一篇、做一篇」

- **什么时候做**：每读完一篇教学文档（比如《01 极限的计算方法》），当天或第二天做对应编号的练习册。册与篇一一对应（01 对 01，……，13 对 13）。
- **怎么做**：按册内建议用时拆开做（常见「分 3 次、每次约 1 小时」）；建议**先 A 组、后 B 组**（时间紧就优先保 A 组近年真题）。每题先限时独立作答——小题标准：易 ≤3 分钟、中 5–10 分钟、难 10 分钟以上。填空题的答案已用横线隐去，动笔后再看解答。
- **做完怎么复盘**：对照官方解答看「分是怎么给的」（官方解答里保留「……（5 分）」这类原卷过程分标注），把自己漏掉的得分步骤记在错题旁。

### 第 2 块 · 历年真题整卷 —— 周末限时 150 分钟自测

- **题面卷 vs 答案册**：`题面卷/` 是去掉答案的可打印版（做题用）；`答案册/` 是完整版（批改用）。
- **用法**：从第 3 周起，每周末挑一套题面卷，严格闭卷计时 **150 分钟**（建议按真实档期 9:00–11:30 来，把生物钟校准到考场节奏）；当天不批改也行，**次日再用答案册复盘**，错题按板块归档回对应专题册。
- **顺序建议**：由近及远——近三届（17→16→15）风格最贴近考场，优先做；老届版式不同（填空 5 分制、题号用「第二题」体例），后期当补充。
- **半程体检**：第 3 周周末用第 13 届整卷做第一次全流程模拟（《00 总纲》路线里的「半程体检」就是它）。

### 第 3 块 · 模拟卷 —— 三轮复习节奏的「新题体检」

- **是什么**：原创命题卷（不照搬真题，数值/结构/问法全新），对标第 15–17 届难度；150 分钟 / 100 分，卷末附「命题双向细目表」，逐题说明考点、难度、与真题的呼应关系和差异。
- **用来干什么**：真题刷多遍会「背答案」，模拟卷是你没见过的题——检验「新题能不能下手」；细目表还能帮你定位薄弱板块，回到对应专题册补。
- **三轮复习里怎么排**：
  1. 第一轮（跟教学文档过专题，第 1–4 周）：不做模拟卷，先把专题练习做扎实；
  2. 第二轮（强化、整卷 + 错题）：用 **A 卷（基础）/ B 卷（标准）** 检验综合能力（先用 A 再用 B）；
  3. 第三轮（冲刺，第 5 周）：用 **C 卷（冲刺提高）** 做最后体检——标准难度 + 2 道拉分题。
- **状态**：A、B、C 三卷均已入库（含题面卷/答案册拆分版）。

### 5.4 三个使用小贴士

1. **先做后看**：所有册的填空题答案都已隐去，这是刻意的——先独立作答，再对解答；
2. **B 组解答看开头标注**：写「本解答由备考项目编写」的就不是官方答案；质检虽已逐题验算，仍鼓励自己复核关键步骤；
3. **难度标注只做参考**：个别题的难度标注偏松或口径不一（已在 5.2 列出），实际投入时间以你限时做下来的感觉为准，偏难不必慌。
