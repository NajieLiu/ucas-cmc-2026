## A 组 · 近年真题（第 10-17 届）

### A1（第10届·题一(2)，2018年）　难度：中

**方法**：参数方程求导、隐函数求导、切线方程

若曲线 $`y = y(x)`$ 由 $`\begin{cases} x = t + \cos t \\ e^y + ty + \sin t = 1 \end{cases}`$ 确定，则此曲线在 $`t = 0`$ 对应点处的切线方程为 $`\underline{\qquad}`$。

> **解答**（官方解法）：当 $`t = 0`$ 时，$`x = 1`$，$`y = 0`$。对 $`x = t + \cos t`$ 两边关于 $`t`$ 求导：$`\dfrac{\mathrm{d}x}{\mathrm{d}t} = 1 - \sin t`$，$`\left.\dfrac{\mathrm{d}x}{\mathrm{d}t}\right|_{t=0} = 1`$；
> 对 $`e^y + ty + \sin t = 1`$ 两边关于 $`t`$ 求导：$`e^y\dfrac{\mathrm{d}y}{\mathrm{d}t} + y + t\dfrac{\mathrm{d}y}{\mathrm{d}t} + \cos t = 0`$，$`\left.\dfrac{\mathrm{d}y}{\mathrm{d}t}\right|_{t=0} = -1`$，则 $`\left.\dfrac{\mathrm{d}y}{\mathrm{d}x}\right|_{t=0} = -1`$。
> 所以，切线方程为 $`y - 0 = -(x-1)`$（即 $`x + y = 1`$）。

### A2（第12届·题一【2】，2020年）　难度：中

**方法**：莱布尼茨（Leibniz）公式求高阶导数值

设函数 $`f(x) = (x+1)^ne^{-x^2}`$，则 $`f^{(n)}(-1) = \underline{\qquad}`$。

> **解答**（官方解法）：利用莱布尼兹求导法则，得
>
> ```math
> f^{(n)}(x) = n!\,e^{-x^2} + \sum_{k=0}^{n-1}C_n^k\left[(x+1)^n\right]^{(k)}\left(e^{-x^2}\right)^{(n-k)},
> ```
>
> 所以 $`f^{(n)}(-1) = \dfrac{n!}{e}`$。
>
> （要点：和式中每一项含因子 $`\left[(x+1)^n\right]^{(k)}`$（$`k \leqslant n-1`$），代入 $`x=-1`$ 全部为 0，只剩 $`n!e^{-x^2}\big|_{x=-1}`$。）

### A3（第12届·题一【3】，2020年）　难度：易

**方法**：隐函数两端求导、切线方程

设 $`y = f(x)`$ 是由方程 $`\arctan\dfrac{x}{y} = \ln\sqrt{x^2+y^2} - \dfrac{1}{2}\ln 2 + \dfrac{\pi}{4}`$ 确定的隐函数，且满足 $`f(1) = 1`$，则曲线 $`y = f(x)`$ 在点 $`(1,1)`$ 处的切线方程为 $`\underline{\qquad}`$。

> **解答**（官方解法）：对所给方程两端关于 $`x`$ 求导，得
>
> ```math
> \frac{\dfrac{y-xy'}{y^2}}{1+\left(\dfrac{x}{y}\right)^2} = \frac{x+yy'}{x^2+y^2},
> ```
>
> 即 $`(x+y)y' = y-x`$，所以 $`f'(1) = 0`$，曲线 $`y = f(x)`$ 在点 $`(1,1)`$ 处的切线方程为 $`y = 1`$。

### A4（第13届·题一(3)，2021年）　难度：中

**方法**：变限积分求导、洛必达法则、积分中值定理

设函数 $`f(x)`$ 连续，且 $`f(0)\neq 0`$，则 $`\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x (x-t)f(t)\,\mathrm{d}t}{x\displaystyle\int_0^x f(x-t)\,\mathrm{d}t}=\underline{\qquad}`$。

> **解答**（官方解法）：原式 $`=\lim\limits_{x\to 0}\dfrac{2x\displaystyle\int_0^x f(t)\,\mathrm{d}t-2\displaystyle\int_0^x tf(t)\,\mathrm{d}t}{x\displaystyle\int_0^x f(u)\,\mathrm{d}u}=\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x f(t)\,\mathrm{d}t+2xf(x)-2xf(x)}{\displaystyle\int_0^x f(u)\,\mathrm{d}u+xf(x)}`$
>
> ```math
> =\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x f(t)\,\mathrm{d}t}{\displaystyle\int_0^x f(u)\,\mathrm{d}u+xf(x)}=\lim\limits_{x\to 0}\dfrac{2xf(\xi)}{xf(\xi)+xf(x)}=1,
> ```
>
> 其中 $`\xi`$ 介于 $`0,x`$ 之间（最后一步用积分中值定理与 $`f`$ 的连续性、$`f(0)\neq0`$）。
>
> （跨专题：另见极限专题——本题主要考点为极限，核心手法是变限积分求导。）

### A5（第14届第二次补赛·题一(2)，2023年）　难度：中

**方法**：可微蕴含连续、导数定义、切线方程

设函数 $`f(x)`$ 在 $`x=1`$ 的某一邻域内可微，且满足

```math
f(1+x)-3f(1-x)=4+2x+o(x),
```

其中 $`o(x)`$ 是当 $`x\to 0`$ 时 $`x`$ 的高阶无穷小，则曲线 $`y=f(x)`$ 在点 $`(1,f(1))`$ 处的切线方程为 $`\underline{\qquad}`$。

> **解答**（官方解法）：由于 $`f(x)`$ 在 $`x=1`$ 处可微，因而连续，故对所给等式求极限 $`x\to 0`$，可得 $`-2f(1)=4`$，所以 $`f(1)=-2`$。仍由所给等式，得
>
> ```math
> \frac{f(1+x)-f(1)}{x}+3\cdot\frac{f(1-x)-f(1)}{-x}=2+\frac{o(x)}{x},
> ```
>
> 两边取极限 $`x\to 0`$，并根据导数的定义，得 $`4f'(1)=2`$，所以 $`f'(1)=\dfrac{1}{2}`$。
>
> 因此，曲线 $`y=f(x)`$ 在点 $`(1,f(1))`$ 处的切线方程为
>
> ```math
> y-f(1)=f'(1)(x-1),\qquad 即\quad x-2y-5=0.
> ```
>

### A6（第14届第二次补赛·题二，2023年）　难度：难

**方法**：变限积分求导、莱布尼茨公式、n 阶导数系数递推

设函数 $`f(x)=e^{-x}\displaystyle\int_0^x\frac{t^{2023}}{1+t^2}\,\mathrm{d}t`$，正整数 $`n\le 2023`$，求导数 $`f^{(n)}(0)`$。

> **解答**（官方解法）：令 $`F(x)=\displaystyle\int_0^x\frac{t^{2023}}{1+t^2}\,\mathrm{d}t`$，则 $`F'(x)=\dfrac{x^{2023}}{1+x^2}`$，$`F''(x)=\dfrac{2023x^{2022}(1+x^2)-2x^{2024}}{(1+x^2)^2}`$，所以 $`F(0)=F'(0)=F''(0)=0`$。……（5 分）
>
> 对 $`f(x)=e^{-x}F(x)`$ 利用 Leibniz 公式，再代入 $`x=0`$ 得
>
> ```math
> f^{(n)}(0)=e^{-x}\sum_{k=0}^n(-1)^{n-k}C_n^kF^{(k)}(x)\Big|_{x=0}=\sum_{k=0}^n(-1)^{n-k}C_n^kF^{(k)}(0).
> ```
>
> ……（4 分）
>
> 欲求 $`F^{(k)}(0)`$，对 $`(1+x^2)F'(x)=x^{2023}`$ 两边求 $`k-1`$ 阶导数，并利用 Leibniz 公式，得
>
> ```math
> (1+x^2)F^{(k)}(x)+2(k-1)xF^{(k-1)}(x)+(k-1)(k-2)F^{(k-2)}(x)=(x^{2023})^{(k-1)},
> ```
>
> 代入 $`x=0`$，并注意到 $`k\le n\le 2023`$，得 $`F^{(k)}(0)=-(k-1)(k-2)F^{(k-2)}(0)`$。由此递推，得
>
> ```math
> F^{(2k)}(0)=\cdots=(-1)^{k-1}(2k-1)!F''(0)=0,
> ```
>
> ```math
> F^{(2k+1)}(0)=\cdots=(-1)^k(2k)!F'(0)=0,
> ```
>
> 因此，$`f^{(n)}(0)=\displaystyle\sum_{k=0}^n(-1)^{n-k}C_n^kF^{(k)}(0)=0`$。……（5 分）

### A7（第15届·题一(3)，2023年）　难度：中

**方法**：有理函数裂项、$`\dfrac{1}{(x-a)}`$ 型 n 阶导数公式

设 $`f(x) = \dfrac{1}{x^2-3x+2}`$, 则 $`f^{(n)}(0) = \underline{\qquad}`$。

> **解答**（官方解法）：
>
> ```math
> f(x) = -\frac{1}{x-1} + \frac{1}{x-2}.
> ```
>
> ```math
> f^{(n)}(x) = (-1)^{n+1}\cdot n!\left(\frac{1}{(x-1)^{n+1}} - \frac{1}{(x-2)^{n+1}}\right).
> ```
>
> ```math
> f^{(n)}(0) = n!\left(1-\frac{1}{2^{n+1}}\right).
> ```
>

### A8（第17届·题一(3)，2025年）　难度：中

**方法**：变限积分求导、等价无穷小、洛必达法则

极限 $`\lim\limits_{x\to 0}\dfrac{\displaystyle\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\left(\sqrt[3]{1+x^3} - 1\right)\sin x} = \underline{\qquad}`$。

> **解答**（官方解法）：
>
> ```math
> \lim_{x\to 0}\frac{\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\left(\sqrt[3]{1+x^3}-1\right)\sin x} = \lim_{x\to 0}\frac{\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\frac{1}{3}x^4}
> ```
>
> （这里用了 $`\sqrt[3]{1+x^3}-1 \sim \frac{1}{3}x^3`$，$`\sin x \sim x`$）继续用洛必达法则：
>
> ```math
> = \lim_{x\to 0}\frac{\ln(1+\sin^2 x)\cdot 2\sin x\cos x}{\frac{4}{3}x^3} = \frac{3}{2}.
> ```
>
> （跨专题：另见极限专题——核心手法是变限积分求导。）

### A9（第17届·题二，2025年）　难度：中

**方法**：可导定义（$`f'(0)`$）、自洽积分方程

设 $`f(x)`$ 在 $`(-\infty, +\infty)`$ 上连续，在 $`x = 0`$ 处可导，且满足

```math
f(x) = x^3 + x^2\lim_{x\to 0}\frac{f(x)}{x} - x\int_0^1 f(x)\,\mathrm{d}x.
```

求函数 $`f(x)`$ 的表达式。

> **解答**（官方解法）：易知 $`f(0) = 0`$，所以 $`\lim\limits_{x\to 0}\dfrac{f(x)}{x} = \lim\limits_{x\to 0}\dfrac{f(x) - f(0)}{x - 0} = f'(0)`$。
>
> 记 $`a = f'(0)`$，$`b = \displaystyle\int_0^1 f(x)\,\mathrm{d}x`$，则
>
> ```math
> f(x) = x^3 + ax^2 - bx. \tag{1}
> ```
>
> 由此得 $`a = \lim\limits_{x\to 0}\dfrac{f(x)}{x} = -b`$。……（6 分）
>
> 再对式子 (1) 的两边在 $`[0,1]`$ 上作定积分，得
>
> ```math
> b = \int_0^1 x^3\,\mathrm{d}x + a\int_0^1 x^2\,\mathrm{d}x - b\int_0^1 x\,\mathrm{d}x = \frac{1}{4} + \frac{1}{3}a - \frac{1}{2}b.
> ```
>
> ……（10 分）
>
> 与 $`a = -b`$ 联立解得 $`a = -\dfrac{3}{22}`$，$`b = \dfrac{3}{22}`$。所以
>
> ```math
> f(x) = x^3 - \frac{3}{22}x^2 - \frac{3}{22}x,\qquad -\infty < x < +\infty.
> ```
>
> ……（14 分）
>
> （跨专题：另见函数方程与积分方程类专题——本题主要考点为"可导定义 + 积分自洽方程"。）

### B1（第01届·题一(4)，2009年）　难度：易

**方法**：隐函数求导（取对数）+ 二阶导数

设 $`y = y(x)`$ 由方程 $`xe^{f(y)} = e^y \ln 29`$ 确定，其中 $`f`$ 具有二阶导数，且 $`f' \neq 1`$，则 $`\dfrac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \underline{\qquad}`$。

> **解答**：（本解答由备考项目编写，非官方答案）
> 方程两端取对数（由方程知 $`x>0`$）：$`\ln x + f(y) = y + \ln\ln 29`$。
> 两端对 $`x`$ 求导：$`\dfrac{1}{x} + f'(y)\,y' = y'`$，即
>
> ```math
> \frac{1}{x} = y'\left[1-f'(y)\right] \ \Longrightarrow\ y' = \frac{1}{x\left[1-f'(y)\right]}
> ```
>
> （条件 $`f'\neq 1`$ 保证分母不为 0。）
> 再对 $`x`$ 求导：$`-\dfrac{1}{x^2} = y''\left[1-f'(y)\right] - (y')^2 f''(y)`$（对乘积 $`y'(1-f'(y))`$ 用乘积法则与链式法则）。
> 解出 $`y''\left[1-f'(y)\right] = (y')^2 f''(y) - \dfrac{1}{x^2}`$，代入 $`y' = \dfrac{1}{x\left[1-f'(y)\right]}`$ 得
>
> ```math
> y'' = \frac{1}{x^2\left[1-f'(y)\right]}\left[\frac{f''(y)}{\left[1-f'(y)\right]^2} - 1\right] = \frac{f''(y) - \left[1-f'(y)\right]^2}{x^2\left[1-f'(y)\right]^3}.
> ```
>
> **答案**：$`\dfrac{f''(y) - \left[1-f'(y)\right]^2}{x^2\left[1-f'(y)\right]^3}`$。

### B2（第01届·题第三题，2009年）　难度：难

**方法**：含参变限积分求导、换元、连续性讨论

设函数 $`f(x)`$ 连续，$`g(x) = \displaystyle\int_0^1 f(xt)\,\mathrm{d}t`$，且 $`\lim\limits_{x\to 0}\dfrac{f(x)}{x} = A`$，$`A`$ 为常数，求 $`g'(x)`$ 并讨论 $`g'(x)`$ 在 $`x = 0`$ 处的连续性。

> **解答**：（本解答由备考项目编写，非官方答案）
> **第一步（化简 $`g`$）**：由 $`\lim\limits_{x\to0}\dfrac{f(x)}{x} = A`$ 知 $`f(0) = 0`$，且当 $`x\to 0`$ 时 $`f(x) = Ax + o(x)`$。
> 当 $`x \neq 0`$ 时，对 $`g(x) = \displaystyle\int_0^1 f(xt)\,\mathrm{d}t`$ 作换元 $`u = xt`$：
>
> ```math
> g(x) = \frac{1}{x}\int_0^x f(u)\,\mathrm{d}u;
> ```
>
> 而 $`g(0) = \displaystyle\int_0^1 f(0)\,\mathrm{d}t = f(0) = 0`$。
> **第二步（$`x\neq0`$ 时的导数）**：由变限积分求导与商法则，
>
> ```math
> g'(x) = \frac{xf(x) - \displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2}.
> ```
>
> **第三步（$`g'(0)`$）**：先估计 $`\displaystyle\int_0^x f(u)\,\mathrm{d}u`$。写 $`f(u) = Au + \varepsilon(u)`$，其中 $`\varepsilon(u) = o(u)\ (u\to0)`$，即对任意 $`\delta>0`$，当 $`|u|`$ 充分小时 $`|\varepsilon(u)| \leqslant \delta|u|`$，于是
>
> ```math
> \left|\int_0^x \varepsilon(u)\,\mathrm{d}u\right| \leqslant \delta\cdot\frac{x^2}{2},\qquad\text{故}\quad \int_0^x f(u)\,\mathrm{d}u = \frac{A}{2}x^2 + o(x^2).
> ```
>
> 由导数定义，
>
> ```math
> g'(0) = \lim_{x\to0}\frac{g(x)-g(0)}{x} = \lim_{x\to0}\frac{\displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2} = \frac{A}{2}.
> ```
>
> **第四步（连续性）**：当 $`x\neq0`$ 时，
>
> ```math
> g'(x) = \frac{xf(x) - \displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2} = \frac{\left[Ax^2 + o(x^2)\right] - \left[\frac{A}{2}x^2 + o(x^2)\right]}{x^2} = \frac{A}{2} + o(1)\ \xrightarrow{\ x\to0\ }\ \frac{A}{2}.
> ```
>
> 可见 $`\lim\limits_{x\to0}g'(x) = g'(0) = \dfrac{A}{2}`$，故 $`g'(x)`$ 在 $`x = 0`$ 处**连续**。
> **结论**：$`g'(x) = \dfrac{xf(x) - \displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2}\ (x\neq0)`$，$`g'(0) = \dfrac{A}{2}`$，且 $`g'`$ 在 $`x=0`$ 处连续。

### B3（第02届·题第三题，2010年）　难度：中

**方法**：参数方程二阶导数公式、相切条件定初值（跨专题：另见常微分方程专题）

设 $`y = f(x)`$ 由参数方程 $`\begin{cases} x = 2t + t^2 \\ y = \psi(t) \end{cases}`$（$`t > -1`$）所确定。且 $`\dfrac{d^2 y}{d x^2} = \dfrac{3}{4(1+t)}`$，其中 $`\psi(t)`$ 具有二阶导数，曲线 $`y = \psi(t)`$ 与 $`y = \displaystyle\int_1^{t^2} e^{-u^2}\,\mathrm{d}u + \dfrac{3}{2e}`$ 在 $`t = 1`$ 处相切。求函数 $`\psi(t)`$。

> **解答**：（本解答由备考项目编写，非官方答案）
> **第一步（参数方程求导）**：$`\dfrac{\mathrm{d}x}{\mathrm{d}t} = 2+2t = 2(1+t)`$，故
>
> ```math
> \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\psi'(t)}{2(1+t)},\qquad
> \frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{1}{2(1+t)}\cdot\frac{\mathrm{d}}{\mathrm{d}t}\left[\frac{\psi'(t)}{2(1+t)}\right] = \frac{\psi''(t)(1+t)-\psi'(t)}{4(1+t)^3}.
> ```
>
> 由题设 $`\dfrac{\psi''(t)(1+t)-\psi'(t)}{4(1+t)^3} = \dfrac{3}{4(1+t)}`$，即
>
> ```math
> \psi''(t)(1+t) - \psi'(t) = 3(1+t)^2. \tag{1}
> ```
>
> **第二步（解微分方程）**：记 $`p(t) = \psi'(t)`$，则 (1) 化为 $`p'(1+t) - p = 3(1+t)^2`$，即
>
> ```math
> p' - \frac{1}{1+t}p = 3(1+t).
> ```
>
> 由于 $`\left(\dfrac{p}{1+t}\right)' = \dfrac{p'(1+t)-p}{(1+t)^2}`$，故上式等价于 $`\left(\dfrac{p}{1+t}\right)' = 3`$，积分得
>
> ```math
> \frac{p}{1+t} = 3t + C_1,\qquad \psi'(t) = p = (3t+C_1)(1+t).
> ```
>
> 再积分：
>
> ```math
> \psi(t) = t^3 + \frac{3+C_1}{2}t^2 + C_1t + C_2. \tag{2}
> ```
>
> **第三步（相切条件定常数）**：记 $`h(t) = \displaystyle\int_1^{t^2} e^{-u^2}\,\mathrm{d}u + \dfrac{3}{2e}`$，$`h'(t) = 2te^{-t^4}`$。"在 $`t=1`$ 处相切"即
>
> ```math
> \psi(1) = h(1) = \frac{3}{2e},\qquad \psi'(1) = h'(1) = \frac{2}{e}.
> ```
>
> 由 $`\psi'(1) = (3+C_1)\cdot 2 = \dfrac{2}{e}`$ 得 $`C_1 = \dfrac{1}{e}-3`$；
> 代入 (2)：$`\psi(1) = 1 + \dfrac{3+C_1}{2} + C_1 + C_2 = 1 + \dfrac{1}{2e} + \dfrac{1}{e} - 3 + C_2 = \dfrac{3}{2e}`$，得 $`C_2 = 2`$。
> **答案**：$`\psi(t) = t^3 + \dfrac{1}{2e}t^2 + \left(\dfrac{1}{e}-3\right)t + 2`$。
> （自检：$`\psi(1) = 1+\frac{1}{2e}+\frac1e-3+2 = \frac{3}{2e}`$ ✓，$`\psi'(1) = 3+\frac1e+\frac1e-3 = \frac2e`$ ✓。）

### B4（第05届·题一(3)，2013年）　难度：中

**方法**：隐函数求导、极值判定（跨专题：另见导数应用专题）

设 $`y=y(x)`$ 由 $`x^3+3x^2y-2y^3=2`$ 所确定，求 $`y(x)`$ 的极值。

> **解答**：（本解答由备考项目编写，非官方答案）
> **第一步（隐函数求导）**：两端对 $`x`$ 求导：
>
> ```math
> 3x^2 + 6xy + 3x^2y' - 6y^2y' = 0\ \Longrightarrow\ x^2+2xy+(x^2-2y^2)y' = 0,
> ```
>
> 故
>
> ```math
> y' = -\frac{x(x+2y)}{x^2-2y^2}.
> ```
>
> **第二步（求驻点）**：$`y'=0`$ 当且仅当 $`x(x+2y)=0`$（此时必有 $`x^2-2y^2\neq 0`$：若 $`x=0`$ 且 $`x^2=2y^2`$ 则 $`y=0`$，代入原方程得 $`0=2`$ 矛盾；若 $`x=-2y`$ 且 $`x^2=2y^2`$ 则 $`y=0`$，同样矛盾）。分两种情形联立原方程：
> - $`x = 0`$：代入原方程得 $`-2y^3 = 2`$，$`y = -1`$，得驻点 $`P_1(0,-1)`$；
> - $`x + 2y = 0`$，即 $`y = -\dfrac{x}{2}`$：代入原方程得 $`x^3 - \dfrac{3}{2}x^3 + \dfrac{1}{4}x^3 = 2`$，即 $`-\dfrac{1}{4}x^3 = 2`$，$`x = -2`$，$`y = 1`$，得驻点 $`P_2(-2,1)`$。
> （两驻点处均有 $`x^2-2y^2\neq0`$：$`P_1`$ 处为 $`-2`$，$`P_2`$ 处为 $`2`$。）
> **第三步（二阶导判号）**：将 $`x^2+2xy+(x^2-2y^2)y' = 0`$ 两端再对 $`x`$ 求导：
>
> ```math
> 2x+2y+2xy'+(2x-4yy')y'+(x^2-2y^2)y'' = 0.
> ```
>
> 在驻点处 $`y'=0`$，得 $`y'' = \dfrac{-2(x+y)}{x^2-2y^2}`$。于是
>
> ```math
> y''(P_1) = \frac{-2(0-1)}{-2} = -1 < 0\ (\text{极大}),\qquad y''(P_2) = \frac{-2(-2+1)}{2} = 1 > 0\ (\text{极小}).
> ```
>
> **答案**：极大值 $`y(0) = -1`$；极小值 $`y(-2) = 1`$。

### B5（第06届·题一(3)，2014年）　难度：中

**方法**：变限积分确定的隐函数求导

设 $`y = y(x)`$ 由 $`x = \displaystyle\int_1^{y-x} \sin^2\left(\frac{\pi t}{4}\right)\mathrm{d}t`$ 所确定，则 $`\left.\dfrac{\mathrm{d}y}{\mathrm{d}x}\right|_{x=0} = \underline{\qquad}`$。

> **解答**：（本解答由备考项目编写，非官方答案）
> **第一步（求 $`x=0`$ 对应的 $`y`$）**：$`x=0`$ 时 $`0 = \displaystyle\int_1^{y}\sin^2\left(\frac{\pi t}{4}\right)\mathrm{d}t`$。在 $`t=1`$（即 $`u=y-x=1`$）附近，被积函数 $`\sin^2\frac{\pi t}{4}>0`$（$`1<t<4`$），故必 $`y-0 = y = 1`$；即在点 $`(x,y)=(0,1)`$ 处 $`u = y-x = 1`$，且此时 $`\sin^2\left(\dfrac{\pi\cdot 1}{4}\right) = \dfrac{1}{2}\neq 0`$，隐函数存在。
> **第二步（两端对 $`x`$ 求导）**：利用变限积分求导法则（上限 $`y(x)-x`$ 是 $`x`$ 的函数）：
>
> ```math
> 1 = \sin^2\left(\frac{\pi(y-x)}{4}\right)\cdot(y'-1).
> ```
>
> **第三步（代值）**：代入 $`(x,y) = (0,1)`$，$`\sin^2\dfrac{\pi}{4} = \dfrac{1}{2}`$：
>
> ```math
> 1 = \frac{1}{2}(y'-1)\ \Longrightarrow\ y' = 3.
> ```
>
> **答案**：$`3`$。

### B6（第08届·题一(4)，2016年）　难度：易

**方法**：莱布尼茨公式 / Taylor 展开求高阶导数值

设 $`f(x) = e^x \sin 2x`$，则 $`f^{(4)}(0) = \underline{\qquad}`$。

> **解答**：（本解答由备考项目编写，非官方答案）
> **解法（莱布尼茨公式）**：在 $`x=0`$ 处，$`e^x`$ 的各阶导数均为 1，而 $`(\sin 2x)^{(k)} = 2^k\sin\left(2x+\dfrac{k\pi}{2}\right)`$，故
>
> ```math
> \left.(\sin 2x)^{(k)}\right|_{x=0} = 2^k\sin\frac{k\pi}{2} = \begin{cases}0, & k = 0,2,4,\\ 2, & k=1,\\ -8, & k=3.\end{cases}
> ```
>
> 由莱布尼茨公式 $`f^{(4)}(0) = \displaystyle\sum_{k=0}^{4}C_4^k\left.(e^x)^{(4-k)}\right|_{x=0}\left.(\sin 2x)^{(k)}\right|_{x=0} = \sum_{k=0}^{4}C_4^k\cdot 2^k\sin\frac{k\pi}{2}`$：
>
> ```math
> f^{(4)}(0) = C_4^1\cdot 2 + C_4^3\cdot(-8) = 4\times 2 + 4\times(-8) = -24.
> ```
>
> **答案**：$`-24`$。
> （可用 Taylor 展开复核：$`e^x\sin 2x`$ 中 $`x^4`$ 的系数为 $`-\dfrac{1}{4!}\times 24 = -1`$，故 $`f^{(4)}(0) = 4!\times(-1) = -24`$ ✓。）

### B7（第09届·题一(1)，2017年）　难度：中

**方法**：变限积分求导、函数方程化微分方程（跨专题：另见常微分方程专题）

已知可导函数 $`f(x)`$ 满足 $`f(x)\cos x + 2\displaystyle\int_0^x f(t)\sin t\,\mathrm{d}t = x+1`$，则 $`f(x) = \underline{\qquad\qquad}`$。

> **解答**：（本解答由备考项目编写，非官方答案）
> **第一步（求初值）**：令 $`x=0`$，由 $`\int_0^0 = 0`$ 得 $`f(0) = 1`$。
> **第二步（求导）**：两端对 $`x`$ 求导（变限积分用微积分基本定理）：
>
> ```math
> f'(x)\cos x - f(x)\sin x + 2f(x)\sin x = 1,\qquad\text{即}\quad f'(x)\cos x + f(x)\sin x = 1.
> ```
>
> **第三步（凑导数求解）**：注意到
>
> ```math
> \left(\frac{f(x)}{\cos x}\right)' = \frac{f'(x)\cos x + f(x)\sin x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x,
> ```
>
> 积分得 $`\dfrac{f(x)}{\cos x} = \tan x + C`$，即 $`f(x) = \sin x + C\cos x`$。
> 由 $`f(0) = 1`$ 得 $`C = 1`$。
> **答案**：$`f(x) = \sin x + \cos x`$。
> （自检：$`f\cos x + 2\int_0^x(\sin t+\cos t)\sin t\,\mathrm{d}t = \sin x\cos x+\cos^2x + \left[x-\frac{\sin 2x}{2}+\sin^2x\right] = x+1`$ ✓。）

## 本专题训练建议

**做题顺序**：先做 B1、B6（易，5 分钟热身）→ A3、A5（概念辨析）→ A1、A2、A4、A7、A8、A9、B3、B4、B5、B7（主体训练）→ B2、A6（压轴）。B 组与 A 组交叉做效果更好（老题的技巧常在新题中重现）。

**目标正确率**：填空题（A1-A5、A7、A8、B1、B5、B6、B7 对应类型）要求 90% 以上——这是初赛必得分区；大题中的求导环节（A6、A9、B2、B3）要求步骤完整、能独立写出过程，目标 80%。

**易错提醒**：
1. **隐函数求导**永远记住对 $`y`$ 求导时链式乘 $`y'`$；二阶导数要在含 $`y'`$ 的等式上再求一遍导，别漏 $`f''(y)\cdot(y')^2`$ 项（见 B1）。
2. **参数方程二阶导**不是 $`\dfrac{\psi''(t)}{x''(t)}`$，而是 $`\dfrac{\mathrm{d}^2y}{\mathrm{d}x^2} = \dfrac{1}{x'(t)}\cdot\dfrac{\mathrm{d}}{\mathrm{d}t}\left(\dfrac{y'(t)}{x'(t)}\right)`$（见 B3、A1）。
3. **变限积分求导**：上限是 $`u(x)`$ 时别漏乘 $`u'(x)`$（如 A8 中上限 $`\sin^2x`$）；被积函数含参变量 $`x`$（如 A4 的 $`\int_0^x(x-t)f(t)\mathrm{d}t`$）要先把 $`x`$ 提出积分号外再求导。
4. **$`x=0`$ 处**的变限积分/参数问题常需单独用**定义**处理，不能盲目代公式求导（见 B2、A9 的 $`f'(0)`$、B5 的定值）。
5. **莱布尼茨公式**求和时只保留代入后非零的项（A2 中 $`k=n`$ 项、B6 中奇数 $`k`$ 项），这是这类题最快的入口。
6. **n 阶导数公式**：$`\left(\dfrac{1}{x-a}\right)^{(n)} = \dfrac{(-1)^nn!}{(x-a)^{n+1}}`$，先裂项再套公式（A7）；裂项后的正负号是最常见的失分点。
7. 条件 $`f'\neq 1`$、$`f(0)\neq0`$ 之类不是装饰——它们保证解答中出现除法/隐函数定理可用，答题时要引用一句。

**二刷标准**：首刷做错或超时的题，隔 2-3 天重做；能不看解答、8 分钟内独立写出完整过程（含关键步骤说明）才算过关。A6、B2 两道难题二刷时要求能讲清"为什么想到用递推/换元"。
