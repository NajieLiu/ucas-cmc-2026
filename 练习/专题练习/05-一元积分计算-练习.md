### A1（第10届·题一(3)，2018年）

**难度**：中　｜　**方法**：不定积分·三角代换与分部积分两种解法

**题面**：$`\displaystyle\int \frac{\ln\left(x + \sqrt{1+x^2}\right)}{(1+x^2)^{3/2}}\,\mathrm{d}x = \underline{\qquad}`$。

> **解答**（官方解答）：
>
> **答案**：$`\dfrac{x}{\sqrt{1+x^2}}\ln\left(x + \sqrt{1+x^2}\right) - \dfrac{1}{2}\ln(1+x^2) + C`$
>
> **解法 1**（$`x = \tan t`$）：
>
> ```math
> \int \frac{\ln(x+\sqrt{1+x^2})}{(1+x^2)^{3/2}}\,\mathrm{d}x \xrightarrow{\ x=\tan t\ } \int \frac{\ln(\tan t + \sec t)}{\sec t}\,\mathrm{d}t = \int \ln(\tan t + \sec t)\,\mathrm{d}\sin t
> ```
>
> ```math
> = \sin t\ln(\tan t + \sec t) - \int \sin t\,\mathrm{d}\ln(\tan t + \sec t)
> ```
>
> ```math
> = \sin t\ln(\tan t + \sec t) - \int \sin t\cdot\frac{1}{\tan t + \sec t}(\sec^2 t + \tan t\sec t)\,\mathrm{d}t
> ```
>
> ```math
> = \sin t\ln(\tan t + \sec t) - \int \frac{\sin t}{\cos t}\,\mathrm{d}t
> ```
>
> ```math
> = \sin t\ln(\tan t + \sec t) + \ln|\cos t| + C = \frac{x}{\sqrt{1+x^2}}\ln(x+\sqrt{1+x^2}) - \frac{1}{2}\ln(1+x^2) + C.
> ```
>
> **解法 2**（分部积分）：
>
> ```math
> \int \frac{\ln(x+\sqrt{1+x^2})}{(1+x^2)^{3/2}}\,\mathrm{d}x = \int \ln(x+\sqrt{1+x^2})\,\mathrm{d}\frac{x}{\sqrt{1+x^2}}
> ```
>
> ```math
> = \frac{x}{\sqrt{1+x^2}}\ln(x+\sqrt{1+x^2}) - \int \frac{x}{\sqrt{1+x^2}}\cdot\frac{1}{x+\sqrt{1+x^2}}\left(1 + \frac{x}{\sqrt{1+x^2}}\right)\mathrm{d}x
> ```
>
> ```math
> = \frac{x}{\sqrt{1+x^2}}\ln(x+\sqrt{1+x^2}) - \int \frac{x}{1+x^2}\,\mathrm{d}x = \frac{x}{\sqrt{1+x^2}}\ln(x+\sqrt{1+x^2}) - \frac{1}{2}\ln(1+x^2) + C.
> ```
>

### A2（第11届·题一(2)，2019年）

**难度**：中　｜　**方法**：不定积分·换元（令 $`y=tx`$ 有理化）

**题面**：设隐函数 $`y = y(x)`$ 由方程 $`y^2(x-y) = x^2`$ 所确定，则 $`\displaystyle\int\frac{\mathrm{d}x}{y^2} = \underline{\qquad}`$。

> **解答**（官方解答）：
>
> **答案**：$`\dfrac{3y}{x} - 2\ln\left|\dfrac{y}{x}\right| + C`$
>
> 令 $`y = tx`$，则 $`x = \dfrac{1}{t^2(1-t)}`$，$`y = \dfrac{1}{t(1-t)}`$，$`\mathrm{d}x = \dfrac{-2+3t}{t^3(1-t)^2}\,\mathrm{d}t`$，
> 这样，
>
> ```math
> \int\frac{\mathrm{d}x}{y^2} = \int\frac{-2+3t}{t}\,\mathrm{d}t = 3t - 2\ln|t| + C = \frac{3y}{x} - 2\ln\left|\frac{y}{x}\right| + C.
> ```
>

### A3（第11届·题一(3)，2019年）

**难度**：中　｜　**方法**：定积分·分部积分互消（$`\int f\,\mathrm{d}\mathrm{e}^x`$ 型）

**题面**：定积分 $`\displaystyle\int_0^{\frac{\pi}{2}}\frac{e^x(1+\sin x)}{1+\cos x}\,\mathrm{d}x = \underline{\qquad}`$。

> **解答**（官方解答）：
>
> **答案**：$`e^{\frac{\pi}{2}}`$
>
> ```math
> \int_0^{\frac{\pi}{2}}\frac{e^x(1+\sin x)}{1+\cos x}\,\mathrm{d}x = \int_0^{\frac{\pi}{2}}\frac{e^x}{1+\cos x}\,\mathrm{d}x + \int_0^{\frac{\pi}{2}}\frac{\sin x}{1+\cos x}\,\mathrm{d}e^x
> ```
>
> ```math
> = \int_0^{\frac{\pi}{2}}\frac{e^x}{1+\cos x}\,\mathrm{d}x + \left.\frac{\sin x\,e^x}{1+\cos x}\right|_0^{\frac{\pi}{2}} - \int_0^{\frac{\pi}{2}}e^x\frac{\cos x(1+\cos x)+\sin^2 x}{(1+\cos x)^2}\,\mathrm{d}x
> ```
>
> ```math
> = \int_0^{\frac{\pi}{2}}\frac{e^x}{1+\cos x}\,\mathrm{d}x + \left.\frac{\sin x\,e^x}{1+\cos x}\right|_0^{\frac{\pi}{2}} - \int_0^{\frac{\pi}{2}}\frac{e^x}{1+\cos x}\,\mathrm{d}x = e^{\frac{\pi}{2}}.
> ```
>

### A4（第12届·题一【4】，2020年）

**难度**：难　｜　**方法**：广义积分·化归 $`\int\frac{\sin u}{u}\mathrm{d}u`$（跨专题：另见「重积分」专题）

**题面**：已知 $`\displaystyle\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x = \frac{\pi}{2}`$，则 $`\displaystyle\int_0^{+\infty}\!\!\int_0^{+\infty}\frac{\sin x\sin(x+y)}{x(x+y)}\,\mathrm{d}x\mathrm{d}y = \underline{\qquad}`$。

> **解答**（官方解答）：
>
> **答案**：$`\dfrac{\pi^2}{8}`$
>
> 令 $`u = x+y`$，得
>
> ```math
> I = \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_0^{+\infty}\frac{\sin(x+y)}{x+y}\,\mathrm{d}y = \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_x^{+\infty}\frac{\sin u}{u}\,\mathrm{d}u
> ```
>
> ```math
> = \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\left(\int_0^{+\infty}\frac{\sin u}{u}\,\mathrm{d}u - \int_0^x\frac{\sin u}{u}\,\mathrm{d}u\right) = \left(\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\right)^2 - \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_0^x\frac{\sin u}{u}\,\mathrm{d}u.
> ```
>
> 令 $`F(x) = \displaystyle\int_0^x\frac{\sin u}{u}\,\mathrm{d}u`$，则 $`F'(x) = \dfrac{\sin x}{x}`$，$`\lim\limits_{x\to+\infty}F(x) = \dfrac{\pi}{2}`$，所以
>
> ```math
> I = \frac{\pi^2}{4} - \int_0^{+\infty}F(x)F'(x)\,\mathrm{d}x = \frac{\pi^2}{4} - \left.\frac{1}{2}[F(x)]^2\right|_0^{+\infty} = \frac{\pi^2}{4} - \frac{1}{2}\left(\frac{\pi}{2}\right)^2 = \frac{\pi^2}{8}.
> ```
>

### A5（第12届·题六，2020年）

**难度**：难　｜　**方法**：取整函数积分 + 三角和恒等式（跨专题：另见「级数」专题）

**题面**：证明 $`f(n) = \displaystyle\sum_{m=1}^n\int_0^m\cos\frac{2\pi n[x+1]}{m}\,\mathrm{d}x`$ 等于 $`n`$ 的所有因子（包括 1 和 $`n`$ 本身）之和，其中 $`[x+1]`$ 表示不超过 $`x+1`$ 的最大整数，并计算 $`f(2021)`$。

> **解答**（官方解答）：
>
> ```math
> \int_0^m\cos\frac{2\pi n[x+1]}{m}\,\mathrm{d}x = \sum_{k=1}^m\int_{k-1}^k\cos\frac{2\pi n[x+1]}{m}\,\mathrm{d}x = \sum_{k=1}^m\int_{k-1}^k\cos\frac{2\pi nk}{m}\,\mathrm{d}x = \sum_{k=1}^m\cos k\frac{2\pi n}{m}.
> ```
>
> ……（4 分）
>
> 如果 $`m`$ 是 $`n`$ 的因子，那么 $`\displaystyle\int_0^m\cos\frac{2\pi n[x+1]}{m}\,\mathrm{d}x = m`$；否则，根据三角恒等式
>
> ```math
> \sum_{k=1}^m\cos kt = \cos\frac{m+1}{2}t\cdot\frac{\sin\frac{mt}{2}}{\sin\frac{t}{2}},
> ```
>
> 有
>
> ```math
> \int_0^m\cos\frac{2\pi n[x+1]}{m}\,\mathrm{d}x = \cos\left(\frac{m+1}{2}\cdot\frac{2\pi n}{m}\right)\cdot\frac{\sin\left(\frac{m}{2}\cdot\frac{2\pi n}{m}\right)}{\sin\frac{2\pi n}{2m}} = 0,
> ```
>
> 因此得证。……（5 分）
>
> 由此可得
>
> ```math
> f(2021) = 1 + 43 + 47 + 2021 = 2112.
> ```
>
> ……（3 分）

### A6（第13届补赛·题一(2)，2021年）

**难度**：中　｜　**方法**：定积分·区间再现换元（周期技巧）

**题面**：积分 $`\displaystyle\int_0^{\frac{\pi}{2}}\frac{\cos x}{1+\tan x}\,\mathrm{d}x = \underline{\qquad}`$。

> **解答**（官方解答）：
>
> **答案**：$`\dfrac{1}{\sqrt{2}}\ln(1+\sqrt{2})`$
>
> 作变换 $`x = \dfrac{\pi}{2} - t`$，则 $`\displaystyle\int_0^{\frac{\pi}{2}}\frac{\cos x}{1+\tan x}\mathrm{d}x = \int_0^{\frac{\pi}{2}}\frac{\sin t}{1+\cot t}\mathrm{d}t = \int_0^{\frac{\pi}{2}}\frac{\sin x}{1+\cot x}\mathrm{d}x`$。
> 于是
>
> ```math
> \int_0^{\frac{\pi}{2}}\frac{\cos x}{1+\tan x}\mathrm{d}x = \frac{1}{2}\left(\int_0^{\frac{\pi}{2}}\frac{\cos x}{1+\tan x}\mathrm{d}x + \int_0^{\frac{\pi}{2}}\frac{\sin x}{1+\cot x}\mathrm{d}x\right)
> ```
>
> ```math
> = \frac{1}{2}\int_0^{\frac{\pi}{2}}\frac{1}{\cos x + \sin x}\mathrm{d}x
> ```
>
> ```math
> = \frac{1}{2\sqrt{2}}\int_0^{\frac{\pi}{2}}\frac{1}{\sin\left(x + \frac{\pi}{4}\right)}\mathrm{d}x = \frac{1}{2\sqrt{2}}\int_0^{\frac{\pi}{2}}\csc\left(x + \frac{\pi}{4}\right)\mathrm{d}x
> ```
>
> ```math
> = \frac{1}{2\sqrt{2}}\int_0^{\frac{\pi}{2}}\csc\left(x + \frac{\pi}{4}\right)\mathrm{d}\left(x + \frac{\pi}{4}\right)
> ```
>
> ```math
> = \frac{1}{2\sqrt{2}}\ln\left[\csc\left(x + \frac{\pi}{4}\right) - \cot\left(x + \frac{\pi}{4}\right)\right]\Big|_0^{\frac{\pi}{2}}
> ```
>
> ```math
> = \frac{1}{\sqrt{2}}\ln(1+\sqrt{2}).
> ```
>

### A7（第13届补赛·题二，2021年）

**难度**：难　｜　**方法**：含绝对值定积分化为显式 + 变限积分求导 + 零点定理（跨专题：另见「微分学应用」专题）

**题面**：设 $`f(x) = -\dfrac{1}{2}\left(1 + \dfrac{1}{\mathrm{e}}\right) + \displaystyle\int_{-1}^{1}|x - t|\mathrm{e}^{-t^2}\mathrm{d}t`$。证明：在区间 $`(-1,1)`$ 内，$`f(x)`$ 有且仅有两个实根。

> **解答**（官方解答）：
>
> ```math
> f(x) = -\frac{1}{2}\left(1 + \frac{1}{\mathrm{e}}\right) + \int_{-1}^{1}|x - t|\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> = -\frac{1}{2}\left(1 + \frac{1}{\mathrm{e}}\right) + \int_{-1}^{x}(x - t)\mathrm{e}^{-t^2}\mathrm{d}t + \int_{x}^{1}(t - x)\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> = -\frac{1}{2}\left(1 + \frac{1}{\mathrm{e}}\right) + x\int_{-1}^{x}\mathrm{e}^{-t^2}\mathrm{d}t - \int_{-1}^{x}t\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> + \int_{x}^{1}t\mathrm{e}^{-t^2}\mathrm{d}t - x\int_{x}^{1}\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> = -\frac{1}{2}\left(1 + \frac{1}{\mathrm{e}}\right) + x\int_{-1}^{0}\mathrm{e}^{-t^2}\mathrm{d}t + x\int_{0}^{x}\mathrm{e}^{-t^2}\mathrm{d}t + \frac{1}{2}\mathrm{e}^{-t^2}\Big|_{-1}^{x}
> ```
>
> ```math
> - \frac{1}{2}\mathrm{e}^{-t^2}\Big|_{x}^{1} + x\int_{1}^{0}\mathrm{e}^{-t^2}\mathrm{d}t + x\int_{0}^{x}\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> = -\frac{1}{2} - \frac{3}{2}\mathrm{e}^{-1} + \mathrm{e}^{-x^2} + x\int_{-1}^{0}\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> + x\int_{1}^{0}\mathrm{e}^{-t^2}\mathrm{d}t + 2x\int_{0}^{x}\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> = -\frac{1}{2} - \frac{3}{2}\mathrm{e}^{-1} + \mathrm{e}^{-x^2} + 2x\int_{0}^{x}\mathrm{e}^{-t^2}\mathrm{d}t.
> ```
>
> ……（6 分）
>
> 显然，$`f(x)`$ 是偶函数，所以我们只需考察 $`f(x)`$ 在 $`(0,1)`$ 内的零点。由于
>
> ```math
> f(0) = \frac{1}{2} - \frac{3}{2}\mathrm{e}^{-1} = \frac{\mathrm{e} - 3}{2\mathrm{e}} < 0,
> ```
>
> ```math
> f(1) = -\frac{1}{2} - \frac{3}{2}\mathrm{e}^{-1} + \mathrm{e}^{-1} + 2\int_{0}^{1}\mathrm{e}^{-t^2}\mathrm{d}t
> ```
>
> ```math
> > -\left(\frac{1}{2} + \frac{1}{2}\mathrm{e}^{-1}\right) + 2\int_{0}^{1}\mathrm{e}^{-t}\mathrm{d}t = \frac{3}{2} - \frac{5}{2}\mathrm{e}^{-1} > 0,
> ```
>
> 又 $`f(x)`$ 在 $`[0,1]`$ 上连续，由闭区间上连续函数的零点定理，一定存在 $`\xi \in (0,1)`$，使 $`f(\xi) = 0`$。
> 由于 $`\forall x \in (0,1)`$，$`f'(x) = 2\displaystyle\int_0^x \mathrm{e}^{-t^2}\mathrm{d}t > 0`$，则 $`f(x)`$ 在 $`(0,1)`$ 内严格单调递增，所以 $`f(x)`$ 在 $`(0,1)`$ 内仅有一个实根。……（6 分）
>
> 因为 $`f(x)`$ 是偶函数，它在 $`(-1,0)`$ 内也仅有一个实根。因此 $`f(x)`$ 在 $`(-1,1)`$ 内仅有两个实根。……（2 分）

### A8（第13届补赛·题五，2021年）

**难度**：难　｜　**方法**：广义积分敛散判别·取整函数积分估计 + Dirichlet 判别法

**题面**：设 $`f(x) = \displaystyle\int_0^x\left(1 - \frac{[u]}{u}\right)\mathrm{d}u`$，其中 $`[x]`$ 表示小于等于 $`x`$ 的最大整数。试讨论

```math
\int_1^{+\infty}\frac{\mathrm{e}^{f(x)}}{x^p}\cos\left(x^2 - \frac{1}{x^2}\right)\mathrm{d}x
```

的敛散性，其中 $`p > 0`$。

> **解答**（官方解答）：
>
> $`\forall x \ge 1`$，
>
> ```math
> f(x) = \int_0^x\left(1 - \frac{[u]}{u}\right)\mathrm{d}u = \int_0^{[x]}\left(1 - \frac{[u]}{u}\right)\mathrm{d}u + \int_{[x]}^{x}\frac{u - [u]}{u}\mathrm{d}u
> ```
>
> ```math
> = \sum_{k=0}^{[x]-1}\int_k^{k+1}\left(1 - \frac{k}{u}\right)\mathrm{d}u + \int_{[x]}^{x}\frac{u - [x]}{u}\mathrm{d}u = [x] - \sum_{k=1}^{[x]-1}k\ln\left(1 + \frac{1}{k}\right) + O\left(\frac{1}{x}\right)
> ```
>
> ```math
> = [x] - \sum_{k=1}^{[x]-1}k\left[\frac{1}{k} - \frac{1}{2k^2} + \frac{1}{3k^3} + o\left(\frac{1}{k^3}\right)\right] + O\left(\frac{1}{x}\right) = 1 + \frac{1}{2}\sum_{k=1}^{[x]-1}\frac{1}{k} + O(1)
> ```
>
> ```math
> = \frac{1}{2}\ln[x] + \frac{1}{2}\left(\sum_{k=1}^{[x]}\frac{1}{k} - \ln[x]\right) + O(1) = \frac{1}{2}\ln x + O(1).
> ```
>
> 故存在 $`0 < C_1 \le C_2`$，使得
>
> ```math
> C_1\sqrt{x} \le \mathrm{e}^{f(x)} \le C_2\sqrt{x}, \quad \forall x \ge 1.
> ```
>
> ……（4 分）
>
> 若 $`p > \dfrac{3}{2}`$，$`\left|\dfrac{\mathrm{e}^{f(x)}}{x^p}\cos\left(x^2 - \dfrac{1}{x^2}\right)\right| \le \dfrac{C_2}{x^{p-\frac{1}{2}}}`$，故原积分绝对收敛。……（3 分）
>
> 再考虑 $`0 < p \le \dfrac{3}{2}`$。首先，注意到
>
> ```math
> \frac{\mathrm{e}^{f(x)}}{x^p}\cos\left(x^2 - \frac{1}{x^2}\right) = \frac{\mathrm{e}^{f(x)}x^{3-p}}{2(x^4+1)}2\left(x + \frac{1}{x^3}\right)\cos\left(x^2 - \frac{1}{x^2}\right),
> ```
>
> 且对任意 $`1 \le A < B < +\infty`$，成立
>
> ```math
> \left|\int_A^B 2\left(x + \frac{1}{x^3}\right)\cos\left(x^2 - \frac{1}{x^2}\right)\mathrm{d}x\right| = \left|\left.\sin\left(x^2 - \frac{1}{x^2}\right)\right|_A^B\right| \le 2.
> ```
>

>
> ```math
> \left|\frac{\mathrm{e}^{f(x)}}{x^p}\cos\left(x^2 - \frac{1}{x^2}\right)\right| \ge \frac{\mathrm{e}^{f(x)}}{x^p}\cos^2\left(x^2 - \frac{1}{x^2}\right)
> ```
>

> = \frac{\mathrm{e}^{f(x)}}{2x^p}\left(\cos\left[2\left(x^2 - \frac{1}{x^2}\right)\right] + 1\right).
> ```
>

### B1（第1届·题三，2009年）

**难度**：中　｜　**方法**：变限积分·含参换元求导 + 连续性讨论（原题 15 分）

**题面**：设函数 $`f(x)`$ 连续，$`g(x) = \displaystyle\int_0^1 f(xt)\,\mathrm{d}t`$，且 $`\lim\limits_{x\to 0}\dfrac{f(x)}{x} = A`$，$`A`$ 为常数，求 $`g'(x)`$ 并讨论 $`g'(x)`$ 在 $`x = 0`$ 处的连续性。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **答案**：$`g'(x) = \dfrac{xf(x) - \displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2}\ (x \neq 0)`$，$`g'(0) = \dfrac{A}{2}`$；$`g'(x)`$ 在 $`x = 0`$ 处连续。
>
> **（1）先定 $`f(0)`$**。由 $`\lim\limits_{x\to 0}\dfrac{f(x)}{x} = A`$ 得 $`f(x) = Ax + o(x)`$，令 $`x\to 0`$ 得 $`f(0) = 0`$。于是
>
> ```math
> g(0) = \int_0^1 f(0)\,\mathrm{d}t = 0.
> ```
>
> **（2）求 $`x \neq 0`$ 时的 $`g'(x)`$**。作换元 $`u = xt`$，则 $`g(x) = \dfrac{1}{x}\displaystyle\int_0^x f(u)\,\mathrm{d}u`$（$`x \neq 0`$）。记 $`F(x) = \displaystyle\int_0^x f(u)\,\mathrm{d}u`$，由 $`g = \dfrac{F}{x}`$ 及商的求导法则，
>
> ```math
> g'(x) = \frac{xF'(x) - F(x)}{x^2} = \frac{xf(x) - \displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2}, \qquad x \neq 0.
> ```
>
> **（3）求 $`g'(0)`$**。由 $`f(u) = Au + o(u)\ (u \to 0)`$ 得
>
> ```math
> \int_0^x f(u)\,\mathrm{d}u = \frac{A}{2}x^2 + o(x^2),
> ```
>
> 故
>
> ```math
> g'(0) = \lim_{x\to 0}\frac{g(x) - g(0)}{x} = \lim_{x\to 0}\frac{\displaystyle\int_0^x f(u)\,\mathrm{d}u}{x^2} = \lim_{x\to 0}\frac{\frac{A}{2}x^2 + o(x^2)}{x^2} = \frac{A}{2}.
> ```
>
> **（4）讨论连续性**。当 $`x \to 0\,(x \neq 0)`$ 时，$`xf(x) = x\left(Ax + o(x)\right) = Ax^2 + o(x^2)`$，于是
>
> ```math
> g'(x) = \frac{Ax^2 + o(x^2) - \left(\frac{A}{2}x^2 + o(x^2)\right)}{x^2} \longrightarrow \frac{A}{2} = g'(0),
> ```
>
> 所以 $`g'(x)`$ 在 $`x = 0`$ 处连续。

### B2（第2届·题一(3)，2010年）

**难度**：易　｜　**方法**：广义积分·分部积分建立递推

**题面**：设 $`s > 0`$，求 $`I_n = \displaystyle\int_0^{+\infty} e^{-sx}x^n\,\mathrm{d}x\ (n = 1, 2, \cdots)`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **答案**：$`I_n = \dfrac{n!}{s^{\,n+1}}`$。
>
> **（1）初始值**：
>
> ```math
> I_0 = \int_0^{+\infty} e^{-sx}\,\mathrm{d}x = \left.-\frac{1}{s}e^{-sx}\right|_0^{+\infty} = \frac{1}{s}.
> ```
>
> **（2）分部积分**（注意 $`x^n e^{-sx} \to 0`$ 当 $`x \to +\infty`$，因指数衰减快于幂函数增长）：
>
> ```math
> I_n = \int_0^{+\infty} x^n\,\mathrm{d}\left(-\frac{1}{s}e^{-sx}\right) = \left.-x^n\frac{1}{s}e^{-sx}\right|_0^{+\infty} + \frac{n}{s}\int_0^{+\infty}x^{n-1}e^{-sx}\,\mathrm{d}x = \frac{n}{s}I_{n-1}.
> ```
>
> **（3）递推求解**：反复使用递推式，
>
> ```math
> I_n = \frac{n}{s}\cdot\frac{n-1}{s}\cdots\frac{1}{s}\cdot I_0 = \frac{n!}{s^{n+1}}.
> ```
>
> 即 $`I_n = \dfrac{n!}{s^{\,n+1}}\ (n = 1, 2, \cdots)`$。

### B3（第4届·题二，2012年）

**难度**：中　｜　**方法**：广义积分·绝对值按周期分段 + 等比级数求和

**题面**：计算 $`\displaystyle\int_0^{+\infty}e^{-2x}|\sin x|\,\mathrm{d}x`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **答案**：$`\dfrac{1+e^{-2\pi}}{5\left(1-e^{-2\pi}\right)}\ \left(=\dfrac{1}{5}\coth\pi\right)`$。
>
> **（1）按 $`|\sin x|`$ 的周期分段**：
>
> ```math
> \int_0^{+\infty}e^{-2x}|\sin x|\,\mathrm{d}x = \sum_{k=0}^{\infty}\int_{k\pi}^{(k+1)\pi}e^{-2x}|\sin x|\,\mathrm{d}x.
> ```
>
> 在第 $`k`$ 段上令 $`x = k\pi + t\ (0 \le t \le \pi)`$，此时 $`|\sin x| = \sin t`$，故
>
> ```math
> \int_{k\pi}^{(k+1)\pi}e^{-2x}|\sin x|\,\mathrm{d}x = e^{-2k\pi}\int_0^{\pi}e^{-2t}\sin t\,\mathrm{d}t.
> ```
>
> **（2）计算单周期积分**。由 $`\displaystyle\int e^{at}\sin bt\,\mathrm{d}t = \frac{e^{at}(a\sin bt - b\cos bt)}{a^2+b^2}`$（取 $`a=-2`$，$`b=1`$）得
>
> ```math
> \int_0^{\pi}e^{-2t}\sin t\,\mathrm{d}t = \left.-\frac{e^{-2t}(2\sin t + \cos t)}{5}\right|_0^{\pi} = \frac{e^{-2\pi}}{5} + \frac{1}{5} = \frac{1+e^{-2\pi}}{5}.
> ```
>
> **（3）求和**。原式 $`= \dfrac{1+e^{-2\pi}}{5}\displaystyle\sum_{k=0}^{\infty}\left(e^{-2\pi}\right)^k = \dfrac{1+e^{-2\pi}}{5}\cdot\dfrac{1}{1-e^{-2\pi}}`$，是公比 $`e^{-2\pi} \in (0,1)`$ 的等比级数。即
>
> ```math
> \int_0^{+\infty}e^{-2x}|\sin x|\,\mathrm{d}x = \frac{1+e^{-2\pi}}{5\left(1-e^{-2\pi}\right)}.
> ```
>

### B4（第5届·题一(2)，2013年）

**难度**：中　｜　**方法**：广义积分敛散判别·分段放缩 + 调和级数发散

**题面**：证明广义积分 $`\displaystyle\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x`$ 不是绝对收敛的。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **（1）先说明该广义积分本身收敛**：$`x = 0`$ 不是奇点，因 $`\dfrac{\sin x}{x} \to 1`$；在 $`[1, +\infty)`$ 上由 Dirichlet 判别法，$`\dfrac{1}{x}`$ 单调趋于 $`0`$，且对任意 $`M > 1`$，$`\left|\displaystyle\int_1^M \sin x\,\mathrm{d}x\right| = |\cos 1 - \cos M| \le 2`$ 有界，故 $`\displaystyle\int_1^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x`$ 收敛。
>
> **（2）再证绝对值积分发散**。对每个 $`k = 1, 2, \cdots`$，在区间 $`[k\pi, (k+1)\pi]`$ 上 $`| \sin x |`$ 关于 $`x = \left(k+\frac{1}{2}\right)\pi`$ 对称，且 $`x \le (k+1)\pi`$，故
>
> ```math
> \int_{k\pi}^{(k+1)\pi}\frac{|\sin x|}{x}\,\mathrm{d}x \ge \frac{1}{(k+1)\pi}\int_{k\pi}^{(k+1)\pi}|\sin x|\,\mathrm{d}x = \frac{2}{(k+1)\pi}.
> ```
>
> （其中用了 $`\displaystyle\int_{k\pi}^{(k+1)\pi}|\sin x|\,\mathrm{d}x = \int_0^{\pi}\sin t\,\mathrm{d}t = 2`$。）于是
>
> ```math
> \int_{k\pi}^{n\pi}\frac{|\sin x|}{x}\,\mathrm{d}x \ge \frac{2}{\pi}\sum_{k=1}^{n-1}\frac{1}{k+1} \longrightarrow +\infty \quad (n \to \infty),
> ```
>
> 由调和级数 $`\displaystyle\sum_{k=1}^{\infty}\frac{1}{k}`$ 发散。因此 $`\displaystyle\int_0^{+\infty}\frac{|\sin x|}{x}\,\mathrm{d}x = +\infty`$，即 $`\displaystyle\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x`$ 收敛但非绝对收敛。

### B5（第5届·题二，2013年）

**难度**：中　｜　**方法**：定积分·对称性（区间再现）拆分技巧

**题面**：计算定积分 $`\displaystyle I=\int_{-\pi}^{\pi}\frac{x\sin x\cdot\arctan e^x}{1+\cos^2 x}\,\mathrm{d}x`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **答案**：$`I = \dfrac{\pi^3}{8}`$。
>
> **（1）用反演对称性化去 $`\arctan e^x`$**。记 $`f(x) = \dfrac{x\sin x\arctan e^x}{1+\cos^2 x}`$。因为 $`e^x \cdot e^{-x} = 1`$，对任意实数 $`x`$ 有
>
> ```math
> \arctan e^x + \arctan e^{-x} = \frac{\pi}{2}.
> ```
>
> 又对 $`I`$ 作换元 $`x = -u`$ 得 $`I = \displaystyle\int_{-\pi}^{\pi}f(-x)\,\mathrm{d}x`$，与 $`I = \displaystyle\int_{-\pi}^{\pi}f(x)\,\mathrm{d}x`$ 相加：
>
> ```math
> 2I = \int_{-\pi}^{\pi}\left[f(x)+f(-x)\right]\mathrm{d}x = \int_{-\pi}^{\pi}\frac{x\sin x\left(\arctan e^x + \arctan e^{-x}\right)}{1+\cos^2 x}\,\mathrm{d}x = \frac{\pi}{2}\int_{-\pi}^{\pi}\frac{x\sin x}{1+\cos^2 x}\,\mathrm{d}x.
> ```
>
> （用到了 $`f(-x) = \dfrac{(-x)(-\sin x)\arctan e^{-x}}{1+\cos^2 x} = \dfrac{x\sin x\arctan e^{-x}}{1+\cos^2 x}`$。）
>
> **（2）用偶函数性把区间减半**。$`\dfrac{x\sin x}{1+\cos^2 x}`$ 是偶函数，故
>
> ```math
> 2I = \frac{\pi}{2}\cdot 2\int_0^{\pi}\frac{x\sin x}{1+\cos^2 x}\,\mathrm{d}x, \qquad I = \frac{\pi}{2}J,\qquad J = \int_0^{\pi}\frac{x\sin x}{1+\cos^2 x}\,\mathrm{d}x.
> ```
>
> **（3）分部积分求 $`J`$**。取 $`u = x`$，$`\mathrm{d}v = \dfrac{\sin x}{1+\cos^2 x}\mathrm{d}x`$，则 $`v = -\arctan(\cos x)`$（因为 $`\left[-\arctan(\cos x)\right]' = \dfrac{\sin x}{1+\cos^2 x}`$）：
>
> ```math
> J = \left.-x\arctan(\cos x)\right|_0^{\pi} + \int_0^{\pi}\arctan(\cos x)\,\mathrm{d}x = -\pi\arctan(-1) + \int_0^{\pi}\arctan(\cos x)\,\mathrm{d}x = \frac{\pi^2}{4} + 0.
> ```
>
> 其中 $`\displaystyle\int_0^{\pi}\arctan(\cos x)\,\mathrm{d}x = 0`$：作换元 $`x = \pi - t`$ 得它等于 $`\displaystyle\int_0^{\pi}\arctan(-\cos t)\,\mathrm{d}t = -\int_0^{\pi}\arctan(\cos t)\,\mathrm{d}t`$，故为零。
>
> **（4）汇总**：$`I = \dfrac{\pi}{2}\cdot\dfrac{\pi^2}{4} = \dfrac{\pi^3}{8}`$。

### B8（第9届·题一(5)，2017年）

**难度**：中　｜　**方法**：不定积分·凑微分换元（$`t = \sin x`$）

**题面**：不定积分 $`I = \displaystyle\int \dfrac{e^{-\sin x}\sin 2x}{(1-\sin x)^2}\,\mathrm{d}x = \underline{\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **答案**：$`I = \dfrac{2e^{-\sin x}}{1-\sin x} + C`$。
>
> **（1）换元**。令 $`t = \sin x`$，则 $`\mathrm{d}t = \cos x\,\mathrm{d}x`$，且 $`\sin 2x = 2\sin x\cos x`$，于是
>
> ```math
> I = \int e^{-t}\cdot\frac{2t}{(1-t)^2}\,\mathrm{d}t.
> ```
>
> **（2）凑微分**。计算
>
> ```math
> \frac{\mathrm{d}}{\mathrm{d}t}\left[\frac{e^{-t}}{1-t}\right] = \frac{-e^{-t}(1-t) + e^{-t}}{(1-t)^2} = \frac{e^{-t}\left[-(1-t)+1\right]}{(1-t)^2} = \frac{t\,e^{-t}}{(1-t)^2}.
> ```
>
> 因此
>
> ```math
> I = 2\int \mathrm{d}\left[\frac{e^{-t}}{1-t}\right] = \frac{2e^{-t}}{1-t} + C.
> ```
>
> **（3）回代**：$`I = \dfrac{2e^{-\sin x}}{1-\sin x} + C`$。（验算：$`\left[\dfrac{2e^{-\sin x}}{1-\sin x}\right]' = \dfrac{2e^{-\sin x}\sin x\cos x}{(1-\sin x)^2} = \dfrac{e^{-\sin x}\sin 2x}{(1-\sin x)^2}`$，正确。）
