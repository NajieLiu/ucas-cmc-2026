### A1.（第10届·题二，2018年）｜难度：易

设函数 $`f(t)`$ 在 $`t \neq 0`$ 时一阶连续可导，且 $`f(1) = 0`$，求函数 $`f(x^2-y^2)`$，使得曲线积分

```math
\int_L y\left[2 - f(x^2-y^2)\right]\mathrm{d}x + xf(x^2-y^2)\,\mathrm{d}y
```

与路径无关，其中 $`L`$ 为任一不与直线 $`y = \pm x`$ 相交的分段光滑曲线。

> **解答**（官方解答）：设 $`P(x,y) = y\left(2 - f(x^2-y^2)\right)`$，$`Q(x,y) = xf(x^2-y^2)`$，由题设可知，积分与路径无关，于是有 $`\dfrac{\partial Q(x,y)}{\partial x} = \dfrac{\partial P}{\partial y}`$，由此可知
>
> ```math
> (x^2-y^2)f'(x^2-y^2) + f(x^2-y^2) = 1.
> ```
>
> ……（5 分）
>
> 记 $`t = x^2-y^2`$，则得微分方程 $`tf'(t) + f(t) = 1`$，即 $`(tf(t))' = 1`$，$`tf(t) = t + C`$。
> 又 $`f(1) = 0`$，可得 $`C = -1`$，$`f(t) = 1 - \dfrac{1}{t}`$，从而 $`f(x^2-y^2) = 1 - \dfrac{1}{x^2-y^2}`$。
> ……（8 分）

### A2.（第11届·题六，2019年）｜难度：难

设函数 $`f(x)`$ 在 $`[0,+\infty)`$ 上具有连续导数，满足

```math
3\left[3+f^2(x)\right]f'(x) = 2\left[1+f^2(x)\right]^2e^{-x^2},
```

且 $`f(0)\le 1`$。证明：存在常数 $`M>0`$，使得 $`x\in[0,+\infty)`$ 时，恒有 $`|f(x)|\le M`$。

> **证明**（官方解答）：由于 $`f'(x)>0`$，所以 $`f(x)`$ 是 $`[0,+\infty)`$ 上的严格增函数，故 $`\lim\limits_{x\to+\infty}f(x) = L`$（有限或为 $`+\infty`$）。下面证明 $`L\ne+\infty`$。……（2 分）
>
> 记 $`y = f(x)`$，将所给等式分离变量并积分得
>
> ```math
> \int\frac{3+y^2}{(1+y^2)^2}\,\mathrm{d}y = \frac{2}{3}\int e^{-x^2}\,\mathrm{d}x,
> ```
>
> 即
>
> ```math
> \frac{y}{1+y^2}+2\arctan y = \frac{2}{3}\int_0^x e^{-t^2}\,\mathrm{d}t + C,
> ```
>
> ……（6 分）
> 其中 $`C = \dfrac{f(0)}{1+f^2(0)}+2\arctan f(0)`$。……（8 分）
>
> 若 $`L = +\infty`$，则对上式取极限 $`x\to+\infty`$，并利用 $`\displaystyle\int_0^{+\infty}e^{-t^2}\,\mathrm{d}t = \frac{\sqrt{\pi}}{2}`$，得 $`C = \pi-\dfrac{\sqrt{\pi}}{3}`$。……（10 分）
>
> 另一方面，令 $`g(u) = \dfrac{u}{1+u^2}+2\arctan u`$，则 $`g'(u) = \dfrac{3+u^2}{(1+u^2)^2}>0`$，所以函数 $`g(u)`$ 在 $`(-\infty,+\infty)`$ 上严格单调增加。因此，当 $`f(0)\le 1`$ 时，$`C = g(f(0))\le g(1) = \dfrac{1+\pi}{2}`$，但
>
> ```math
> C > \frac{2\pi-\sqrt{\pi}}{2} > \frac{1+\pi}{2},
> ```
>
> 矛盾，这就证明了 $`\lim\limits_{x\to+\infty}f(x) = L`$ 为有限数。
>
> 最后，取 $`M = \max\{|f(0)|,|L|\}`$，则 $`|f(x)|\le M`$，$`\forall x\in[0,+\infty)`$。……（14 分）

### A3.（第12届·题四，2020年）｜难度：中｜（跨专题：另见多元微分专题）

已知 $`z = xf\left(\dfrac{y}{x}\right) + 2y\varphi\left(\dfrac{x}{y}\right)`$，其中 $`f`$，$`\varphi`$ 均为二次可微函数。

（1）求 $`\dfrac{\partial z}{\partial x}`$，$`\dfrac{\partial^2 z}{\partial x\partial y}`$；

（2）当 $`f = \varphi`$，且 $`\left.\dfrac{\partial^2 z}{\partial x\partial y}\right|_{x=a} = -by^2`$ 时，求 $`f(y)`$。

> **解答**（官方解答）：（1）
>
> ```math
> \frac{\partial z}{\partial x} = f\left(\frac{y}{x}\right) - \frac{y}{x}f'\left(\frac{y}{x}\right) + 2\varphi'\left(\frac{x}{y}\right),\qquad \frac{\partial^2 z}{\partial x\partial y} = -\frac{y}{x^2}f''\left(\frac{y}{x}\right) - \frac{2x}{y^2}\varphi''\left(\frac{x}{y}\right).
> ```
>
> ……（3 分）
>
> （2）
>
> ```math
> \left.\frac{\partial^2 z}{\partial x\partial y}\right|_{x=a} = -\frac{y}{a^2}f''\left(\frac{y}{a}\right) - \frac{2a}{y^2}\varphi''\left(\frac{a}{y}\right) = -by^2.
> ```
>
> 因为 $`f = \varphi`$，所以
>
> ```math
> \frac{y}{a^2}f''\left(\frac{y}{a}\right) + \frac{2a}{y^2}f''\left(\frac{a}{y}\right) = by^2.
> ```
>
> 令 $`y = au`$，则 $`\dfrac{u}{a}f''(u) + \dfrac{2}{au^2}f''\left(\dfrac{1}{u}\right) = a^2bu^2`$，即
>
> ```math
> u^3f''(u) + 2f''\left(\frac{1}{u}\right) = a^3bu^4.
> ```
>
> 上式中以 $`\dfrac{1}{u}`$ 换 $`u`$ 得
>
> ```math
> 2f''\left(\frac{1}{u}\right) + 4u^3f''(u) = 2a^3b\,\frac{1}{u}.
> ```
>
> ……（5 分）
>
> 联立二式，解得 $`-3u^3f''(u) = a^3b\left(u^4 - \dfrac{2}{u}\right)`$，所以 $`f''(u) = \dfrac{a^3b}{3}\left(\dfrac{2}{u^4}-u\right)`$，从而有
>
> ```math
> f(u) = \frac{a^3b}{3}\left(\frac{1}{3u^2} - \frac{u^3}{6}\right) + C_1u + C_2.
> ```
>
> 故
>
> ```math
> f(y) = \frac{a^3b}{3}\left(\frac{1}{3y^2} - \frac{y^3}{6}\right) + C_1y + C_2.
> ```
>
> ……（4 分）

### A4.（第13届·题三，2021年）｜难度：中

设 $`f(x)`$ 在 $`[0,+\infty)`$ 上是有界连续函数，证明：方程 $`y''+14y'+13y=f(x)`$ 的每一个解在 $`[0,+\infty)`$ 上都是有界函数。

> **证明**（官方解答）：易得对应的齐次方程 $`y''+14y'+13y=0`$ 的通解为
>
> ```math
> y=C_1e^{-x}+C_2e^{-13x}.
> ```
>
> ……（4 分）
>
> 又由 $`y''+14y'+13y=f(x)`$，得 $`(y''+y')+13(y'+y)=f(x)`$。令 $`y_1=y'+y`$，则 $`y_1'+13y_1=f(x)`$，解得 $`y_1=e^{-13x}\left(\displaystyle\int_0^x f(t)e^{13t}\,\mathrm{d}t+C_3\right)`$。
>
> 同理，由 $`y''+14y'+13y=f(x)`$，得 $`(y''+13y')+(y'+13y)=f(x)`$。令 $`y_2=y'+13y`$，则 $`y_2'+y_2=f(x)`$，解得 $`y_2=e^{-x}\left(\displaystyle\int_0^x f(t)e^t\,\mathrm{d}t+C_4\right)`$。
>
> 取 $`C_3=C_4=0`$，得
>
> ```math
> \begin{cases}
> y'+y=e^{-13x}\displaystyle\int_0^x f(t)e^{13t}\,\mathrm{d}t,\\
> y'+13y=e^{-x}\displaystyle\int_0^x f(t)e^t\,\mathrm{d}t,
> \end{cases}
> ```
>
> 由此解得原方程的一个特解为
>
> ```math
> y^*=\frac{1}{12}e^{-x}\int_0^x f(t)e^t\,\mathrm{d}t-\frac{1}{12}e^{-13x}\int_0^x f(t)e^{13t}\,\mathrm{d}t.
> ```
>
> 因此，原方程的通解为
>
> ```math
> y=C_1e^{-x}+C_2e^{-13x}+\frac{1}{12}e^{-x}\int_0^x f(t)e^t\,\mathrm{d}t-\frac{1}{12}e^{-13x}\int_0^x f(t)e^{13t}\,\mathrm{d}t.
> ```
>
> ……（6 分）
>
> 因为 $`f(x)`$ 在 $`[0,+\infty)`$ 上有界，所以，存在 $`M>0`$，使得 $`|f(x)|\leq M`$，$`0\leq x<+\infty`$，注意到当 $`x\in[0,+\infty)`$ 时，$`0<e^{-x}\leq1`$，$`0<e^{-13x}\leq1`$，所以
>
> ```math
> |y|\leq|C_1|e^{-x}+|C_2|e^{-13x}+\frac{1}{12}e^{-x}\left|\int_0^x f(t)e^t\,\mathrm{d}t\right|+\frac{1}{12}e^{-13x}\left|\int_0^x f(t)e^{13t}\,\mathrm{d}t\right|
> ```
>
> ```math
> \leq|C_1|+|C_2|+\frac{M}{12}e^{-x}\int_0^x e^t\,\mathrm{d}t+\frac{M}{12}e^{-13x}\int_0^x e^{13t}\,\mathrm{d}t
> ```
>
> ```math
> \leq|C_1|+|C_2|+\frac{M}{12}\left(1-e^{-x}\right)+\frac{M}{12\times13}\left(1-e^{-13x}\right)
> ```
>
> ```math
> \leq|C_1|+|C_2|+\frac{M}{12}+\frac{M}{12\times13}=|C_1|+|C_2|+\frac{7M}{78}.
> ```
>
> 对于方程的每一个确定的解，常数 $`C_1`$、$`C_2`$ 是固定的，所以，原方程的每一个解都是有界的。……（4 分）

### A5.（第13届补赛·一(5)，2021年）｜难度：易

微分方程 $`\begin{cases}(x+1)\dfrac{\mathrm{d}y}{\mathrm{d}x} + 1 = 2\mathrm{e}^{-y}\\ y(0) = 0\end{cases}`$ 的解是 $`\underline{\qquad}`$。

> **解答**（官方解答）：方程变形为：$`\mathrm{e}^y\dfrac{\mathrm{d}y}{\mathrm{d}x} = -\dfrac{1}{x+1}\mathrm{e}^y + \dfrac{2}{x+1}`$，
> 即，$`\dfrac{\mathrm{d}\mathrm{e}^y}{\mathrm{d}x} = -\dfrac{1}{x+1}\mathrm{e}^y + \dfrac{2}{x+1}`$，
>
> ```math
> \mathrm{e}^y = \mathrm{e}^{\int\frac{-1}{x+1}\mathrm{d}x}\left[\int\frac{2}{x+1}\mathrm{e}^{-\int\frac{-1}{x+1}\mathrm{d}x}\mathrm{d}x + C\right] = \frac{1}{x+1}\left[\int\frac{2}{x+1}\cdot(x+1)\mathrm{d}x + C\right]
> ```
>
> ```math
> = \frac{1}{x+1}[2x + C]
> ```
>
> 由 $`y(0) = 0`$，得到，$`C = 1`$，
> 所以 $`\mathrm{e}^y = \dfrac{2x+1}{x+1}`$，故，$`y = \ln\dfrac{2x+1}{x+1}`$。

**答案**：$`y=\ln\dfrac{2x+1}{x+1}`$

### A6.（第13届补赛·题四，2021年）｜难度：难｜（跨专题：另见曲面积分专题）

若对于 $`R^3`$ 中半空间 $`\{(x,y,z) \in R^3 \mid x > 0\}`$ 内的任意有向光滑封闭曲面 $`S`$，都有：

```math
\oiint_S xf'(x)\mathrm{d}y\mathrm{d}z + y\left(xf(x) - f'(x)\right)\mathrm{d}z\mathrm{d}x - xz\left(\sin x + f'(x)\right)\mathrm{d}x\mathrm{d}y = 0,
```

其中 $`f`$ 在 $`(0,+\infty)`$ 上二阶导数连续且 $`\lim\limits_{x\to 0^+} f(x) = \lim\limits_{x\to 0^+} f'(x) = 0`$，求 $`f(x)`$。

> **解答**（官方解答）：任取一定点 $`P(x,y,z) \in \{(x,y,z) \in R^3 \mid x > 0\}`$，对任意充分小 $`\varepsilon > 0`$，以 $`P`$ 点为中心半径为 $`2\varepsilon`$ 的有向球面 $`S_{2\varepsilon}(P)`$ 仍位于此半空间中。记 $`B_{\varepsilon}(P)`$ 为球面 $`S_{\varepsilon}(P)`$（取外侧）所围内部开球域。
> 由题设条件及 Gauss 公式，得：
>
> ```math
> 0 = \oiint_{S_{\varepsilon}(P)} xf'(x)\mathrm{d}y\mathrm{d}z + y(xf(x) - f'(x))\mathrm{d}z\mathrm{d}x - xz(\sin x + f'(x))\mathrm{d}x\mathrm{d}y =
> ```
>
> ```math
> \iiint_{B_{\varepsilon}(P)}\left[f'(x) + xf''(x) + xf(x) - f'(x) - x\sin x - xf'(x)\right]\mathrm{d}x\mathrm{d}y\mathrm{d}z =
> ```
>
> ```math
> \iiint_{B_{\varepsilon}(P)}\left[xf''(x) - xf'(x) + xf(x) - x\sin x\right]\mathrm{d}x\mathrm{d}y\mathrm{d}z = \rho\left[f''(\rho) - f'(\rho) + f(\rho) - \sin\rho\right]\cdot\frac{4}{3}\pi\varepsilon^3,
> ```
>
> 其中 $`|\rho - x| \le \varepsilon`$。
> 由此可得 $`f''(\rho) - f'(\rho) + f(\rho) - \sin\rho = 0`$。
> 令 $`\varepsilon \to 0^+`$，由 $`f`$ 在 $`(0,+\infty)`$ 上二阶导数连续得
>
> ```math
> f''(x) - f'(x) + f(x) - \sin x = 0\ (\forall x > 0),
> ```
>
> 即
>
> ```math
> f''(x) - f'(x) + f(x) = \sin x\ (\forall x > 0).
> ```
>
> ……（7 分）
> （以上方程也可通过反证法得到）。
> 求解此二阶方程，齐次方程通解为 $`\mathrm{e}^{\frac{x}{2}}\left(c_1\cos\frac{\sqrt{3}}{2}x + c_2\sin\frac{\sqrt{3}}{2}x\right)`$，非齐次方程特解为 $`\cos x`$，故可得：
>
> ```math
> f(x) = \mathrm{e}^{\frac{x}{2}}\left(c_1\cos\frac{\sqrt{3}}{2}x + c_2\sin\frac{\sqrt{3}}{2}x\right) + \cos x, \quad \forall x > 0.
> ```
>
> 由 $`\lim\limits_{x\to 0^+} f(x) = 0`$ 可得：$`c_1 = -1`$。
> 再由 $`\lim\limits_{x\to 0^+} f'(x) = 0`$，得
>
> ```math
> \lim_{x\to 0^+}\left[\frac{\mathrm{e}^{\frac{x}{2}}}{2}\left((c_1 + \sqrt{3}c_2)\cos\frac{\sqrt{3}}{2}x + (c_2 - \sqrt{3}c_1)\sin\frac{\sqrt{3}}{2}x\right) - \sin x\right] = \frac{c_1 + \sqrt{3}c_2}{2} = 0,
> ```
>
> 可得：$`c_2 = \dfrac{\sqrt{3}}{3}`$。
> 因此，$`f(x) = \mathrm{e}^{\frac{x}{2}}\left(\dfrac{\sqrt{3}}{3}\sin\dfrac{\sqrt{3}}{2}x - \cos\dfrac{\sqrt{3}}{2}x\right) + \cos x, \quad \forall x > 0.`$
> ……（7 分）

### A7.（第14届·一(4)，2022年）｜难度：易

微分方程 $`\dfrac{\mathrm{d}y}{\mathrm{d}x}x\ln x\sin y + \cos y(1-x\cos y) = 0`$ 的通解为 $`\underline{\qquad}`$。

> **解答**（官方解答）：原方程等价于 $`\dfrac{\mathrm{d}y}{\mathrm{d}x}\sin y + \dfrac{1}{x\ln x}\cos y = \dfrac{1}{\ln x}\cos^2 y`$。令 $`u = \cos y`$，则方程可化为 $`\dfrac{\mathrm{d}u}{\mathrm{d}x} - \dfrac{1}{x\ln x}u = -\dfrac{1}{\ln x}u^2`$。再令 $`w = \dfrac{1}{u}`$，则方程可进一步化为 $`\dfrac{\mathrm{d}w}{\mathrm{d}x} + \dfrac{1}{x\ln x}w = \dfrac{1}{\ln x}`$。这是一阶线性微分方程，利用求解公式得
>
> ```math
> w = e^{-\int\frac{\mathrm{d}x}{x\ln x}}\left(\int\frac{1}{\ln x}e^{\int\frac{\mathrm{d}x}{x\ln x}}\mathrm{d}x + C\right) = \frac{1}{\ln x}(x+C).
> ```
>
> 将变量 $`w = \dfrac{1}{u} = \dfrac{1}{\cos y}`$ 代回，得
>
> ```math
> (x+C)\cos y = \ln x.
> ```
>

### B1.（第01届·第五题，2009年）｜难度：中

已知 $`y_1 = xe^x + e^{2x}`$，$`y_2 = xe^x + e^{-x}`$，$`y_3 = xe^x + e^{2x} - e^{-x}`$ 是某二阶常系数线性非齐次微分方程的三个解，试求此微分方程。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：由解的结构确定齐次部分。** 设所求方程为 $`y'' + py' + qy = f(x)`$。线性非齐次方程任意两解之差是对应齐次方程的解，于是
>
> ```math
> y_1 - y_3 = e^{-x},\qquad y_1 - y_2 = e^{2x} - e^{-x}.
> ```
>
> 故 $`e^{-x}`$ 与 $`e^{2x}`$ 均为齐次方程 $`y'' + py' + qy = 0`$ 的解，且二者线性无关，构成齐次方程的通解 $`C_1e^{2x} + C_2e^{-x}`$。因此特征根为 $`\lambda_1 = 2`$，$`\lambda_2 = -1`$，特征方程为
>
> ```math
> \lambda^2 - \lambda - 2 = 0.
> ```
>
> 即齐次部分为 $`y'' - y' - 2y = 0`$（$`p = -1`$，$`q = -2`$）。
>
> **第二步：由任一解确定非齐次项。** 对 $`y'' - y' - 2y`$ 而言，$`e^{2x}`$、$`e^{-x}`$ 代入得 $`0`$，故只需将 $`xe^x`$ 代入。由 $`(xe^x)' = (x+1)e^x`$，$`(xe^x)'' = (x+2)e^x`$，得
>
> ```math
> (xe^x)'' - (xe^x)' - 2xe^x = \big[(x+2) - (x+1) - 2x\big]e^x = (1-2x)e^x.
> ```
>
> 所以非齐次项 $`f(x) = (1-2x)e^x`$。
>
> **所求微分方程为**
>
> ```math
> \boxed{\,y'' - y' - 2y = (1-2x)e^x\,}
> ```
>
> **验算**：将 $`y_1 = xe^x + e^{2x}`$ 代入：$`y_1' = (x+1)e^x + 2e^{2x}`$，$`y_1'' = (x+2)e^x + 4e^{2x}`$，
>
> ```math
> y_1'' - y_1' - 2y_1 = \big[(x+2)-(x+1)-2x\big]e^x + (4-2-2)e^{2x} = (1-2x)e^x. \checkmark
> ```
>
> 将 $`y_2`$ 代入：$`e^{-x}`$ 项贡献 $`\big[1-(-1)-2\big]e^{-x} = 0`$，其余同 $`y_1`$，得 $`(1-2x)e^x`$；将 $`y_3`$ 代入同理成立。三个解都满足，验算通过。

### B2.（第01届·第七题，2009年）｜难度：中｜（跨专题：另见级数专题）

已知 $`u_n(x)`$ 满足 $`u_n'(x) = u_n(x) + x^{n-1}e^x`$（$`n`$ 为正整数），且 $`u_n(1) = \dfrac{e}{n}`$，求函数项级数 $`\displaystyle\sum_{n=1}^{\infty} u_n(x)`$ 之和。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：解一阶线性方程求 $`u_n(x)`$。** 方程即 $`u_n' - u_n = x^{n-1}e^x`$。乘积分因子 $`e^{-x}`$ 得
>
> ```math
> \left(u_n(x)e^{-x}\right)' = x^{n-1}.
> ```
>
> 积分得 $`u_n(x)e^{-x} = \dfrac{x^n}{n} + C`$，即 $`u_n(x) = e^x\left(\dfrac{x^n}{n} + C\right)`$。代入 $`u_n(1) = \dfrac{e}{n}`$：
>
> ```math
> e\left(\frac{1}{n} + C\right) = \frac{e}{n}\ \Longrightarrow\ C = 0.
> ```
>
> 故
>
> ```math
> u_n(x) = \frac{x^n e^x}{n}.
> ```
>
> **第二步：求函数项级数之和。** 由 $`\displaystyle\sum_{n=1}^{\infty}\frac{x^n}{n} = -\ln(1-x)`$（$`|x|<1`$）得
>
> ```math
> \sum_{n=1}^{\infty} u_n(x) = e^x\sum_{n=1}^{\infty}\frac{x^n}{n} = -\,e^x\ln(1-x),\qquad -1\le x<1.
> ```
>
> （$`x=1`$ 时 $`u_n(1) = \dfrac{e}{n}`$，级数发散；$`x=-1`$ 时 $`\displaystyle\sum\frac{(-1)^n}{n}`$ 收敛，和为 $`-e^{-1}\ln 2`$。）
>
> **验算**：对和函数 $`S(x) = -e^x\ln(1-x)`$ 逐项对照。一方面 $`S(0) = 0 = u_1(0)`$ 起各项均为 $`0\ \checkmark`$；另一方面逐项求导：$`\sum u_n'(x) = \sum\left(\dfrac{x^n e^x}{n} + x^{n-1}e^x\right) = -e^x\ln(1-x) + \dfrac{e^x}{1-x}`$，而
>
> ```math
> S'(x) = -e^x\ln(1-x) + \frac{e^x}{1-x}\ \checkmark
> ```
>
> 两者一致，且初值 $`S(0)=0`$ 一致，验算通过。

### B3.（第02届·第三题，2010年）｜难度：中

设 $`y = f(x)`$ 由参数方程 $`\begin{cases} x = 2t + t^2 \\ y = \psi(t) \end{cases}`$（$`t > -1`$）所确定。且 $`\dfrac{d^2 y}{d x^2} = \dfrac{3}{4(1+t)}`$，其中 $`\psi(t)`$ 具有二阶导数，曲线 $`y = \psi(t)`$ 与 $`y = \displaystyle\int_1^{t^2} e^{-u^2}\,\mathrm{d}u + \dfrac{3}{2e}`$ 在 $`t = 1`$ 处相切。求函数 $`\psi(t)`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：将二阶导条件化为 $`\psi`$ 的微分方程。** 由参数方程求导公式，$`\dfrac{dx}{dt} = 2 + 2t = 2(1+t)`$，故
>
> ```math
> \frac{dy}{dx} = \frac{\psi'(t)}{2(1+t)}.
> ```
>
> 再对 $`x`$ 求导：
>
> ```math
> \frac{d^2y}{dx^2} = \frac{1}{2(1+t)}\cdot\frac{d}{dt}\left(\frac{\psi'(t)}{2(1+t)}\right) = \frac{\psi''(t)(1+t) - \psi'(t)}{4(1+t)^3}.
> ```
>
> 代入条件 $`\dfrac{d^2y}{dx^2} = \dfrac{3}{4(1+t)}`$，得
>
> ```math
> (1+t)\psi''(t) - \psi'(t) = 3(1+t)^2.\tag{1}
> ```
>
> **第二步：由相切条件得初值。** 记 $`F(t) = \displaystyle\int_1^{t^2} e^{-u^2}\,du + \dfrac{3}{2e}`$。相切于 $`t=1`$ 处，故
>
> ```math
> \psi(1) = F(1) = \frac{3}{2e},\qquad \psi'(1) = F'(1) = 2t\,e^{-t^4}\Big|_{t=1} = \frac{2}{e}.
> ```
>
> **第三步：解方程。** 令 $`p = \psi'(t)`$，方程 (1) 即 $`p' - \dfrac{p}{1+t} = 3(1+t)`$。乘积分因子 $`\dfrac{1}{1+t}`$ 得
>
> ```math
> \left(\frac{p}{1+t}\right)' = 3\ \Longrightarrow\ \frac{p}{1+t} = 3t + C_1\ \Longrightarrow\ \psi'(t) = (3t+C_1)(1+t).
> ```
>
> 由 $`\psi'(1) = \dfrac{2}{e}`$ 得 $`(3+C_1)\cdot 2 = \dfrac{2}{e}`$，故 $`C_1 = \dfrac{1}{e} - 3`$。再积分：
>
> ```math
> \psi(t) = \int (3t+C_1)(1+t)\,dt = \int\left(3t^2 + (3+C_1)t + C_1\right)dt = t^3 + \frac{3+C_1}{2}t^2 + C_1t + C_2.
> ```
>
> 代入 $`C_1 = \dfrac{1}{e} - 3`$（此时 $`\dfrac{3+C_1}{2} = \dfrac{1}{2e}`$），并由 $`\psi(1) = \dfrac{3}{2e}`$：
>
> ```math
> 1 + \frac{1}{2e} + \frac{1}{e} - 3 + C_2 = \frac{3}{2e}\ \Longrightarrow\ C_2 = 2.
> ```
>
> **所求函数为**
>
> ```math
> \boxed{\ \psi(t) = t^3 + \frac{1}{2e}t^2 + \left(\frac{1}{e}-3\right)t + 2\ }
> ```
>
> **验算**：$`\psi(1) = 1 + \dfrac{1}{2e} + \dfrac{1}{e} - 3 + 2 = \dfrac{3}{2e}\ \checkmark`$；$`\psi'(t) = 3t^2 + \dfrac{t}{e} + \dfrac{1}{e} - 3`$，$`\psi'(1) = 3 + \dfrac{1}{e} + \dfrac{1}{e} - 3 = \dfrac{2}{e}\ \checkmark`$；且 $`\psi''(t) = 6t + \dfrac{1}{e}`$，于是
>
> ```math
> (1+t)\psi''(t) - \psi'(t) = (1+t)\left(6t + \frac{1}{e}\right) - \left(3t^2 + \frac{t}{e} + \frac{1}{e} - 3\right) = 3t^2 + 6t + 3 = 3(1+t)^2\ \checkmark
> ```
>
> 方程 (1) 也满足，验算通过。

### B4.（第04届·一(4)，2012年）｜难度：中

设 $`u = u(x)`$ 连续可微，$`u(2) = 1`$，且

```math
\int_L (x + 2y)u\,\mathrm{d}x + (x + u^3)u\,\mathrm{d}y
```

在右半平面上与路径无关，求 $`u(x)`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：由路径无关条件建立方程。** 记 $`P = (x+2y)u`$，$`Q = (x+u^3)u`$（其中 $`u = u(x)`$）。在右半平面与路径无关等价于 $`\dfrac{\partial Q}{\partial x} = \dfrac{\partial P}{\partial y}`$，其中
>
> ```math
> \frac{\partial P}{\partial y} = 2u,\qquad \frac{\partial Q}{\partial x} = \frac{d}{dx}\left[xu + u^4\right] = u + xu' + 4u^3u'.
> ```
>
> 故 $`u + xu' + 4u^3u' = 2u`$，即
>
> ```math
> u'(x + 4u^3) = u. \tag{1}
> ```
>
> **第二步：把 $`x`$ 看作 $`u`$ 的函数解线性方程。** 在 $`u \neq 0`$ 处（由 $`u(2)=1`$ 及连续性，$`u`$ 在 $`x=2`$ 附近不为零），由 (1) 得
>
> ```math
> \frac{dx}{du} = \frac{x + 4u^3}{u},\qquad 即\quad \frac{dx}{du} - \frac{1}{u}x = 4u^2.
> ```
>
> 这是关于 $`x`$ 的一阶线性方程，积分因子为 $`\dfrac{1}{u}`$：
>
> ```math
> \left(\frac{x}{u}\right)' = 4u\ \Longrightarrow\ \frac{x}{u} = 2u^2 + C\ \Longrightarrow\ x = 2u^3 + Cu.
> ```
>
> 代入 $`u(2) = 1`$（即 $`x = 2`$ 时 $`u = 1`$）：$`2 = 2 + C`$，得 $`C = 0`$，故 $`x = 2u^3`$。
>
> **所求函数为**
>
> ```math
> \boxed{\ u(x) = \left(\frac{x}{2}\right)^{1/3} = \frac{\sqrt[3]{x}}{\sqrt[3]{2}}\ }
> ```
>
> **验算**：$`u'(x) = \dfrac{1}{3}\left(\dfrac{x}{2}\right)^{-2/3}\cdot\dfrac{1}{2} = \dfrac{1}{6}\left(\dfrac{x}{2}\right)^{-2/3}`$，于是
>
> ```math
> u'(x + 4u^3) = \frac{1}{6}\left(\frac{x}{2}\right)^{-2/3}\left(x + 4\cdot\frac{x}{2}\right) = \frac{1}{6}\left(\frac{x}{2}\right)^{-2/3}\cdot 3x = \left(\frac{x}{2}\right)^{1/3} = u\ \checkmark
> ```
>
> 方程 (1) 满足；且 $`\dfrac{\partial P}{\partial y} = 2u = 2\left(\dfrac{x}{2}\right)^{1/3}`$，$`\dfrac{\partial Q}{\partial x} = u + (x+4u^3)u' = u + u = 2u`$，两者相等，路径无关条件满足；$`u(2) = 1`$ 也满足，验算通过。

### B5.（第06届·一(1)，2014年）｜难度：易

已知 $`y_1 = e^x`$ 和 $`y_2 = xe^x`$ 是齐次二阶常系数线性微分方程的解，则该微分方程是 $`\underline{\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> 设方程为 $`y'' + py' + qy = 0`$，特征方程 $`\lambda^2 + p\lambda + q = 0`$。由 $`y_1 = e^x`$、$`y_2 = xe^x`$ 均为解，知 $`\lambda = 1`$ 为特征根；又 $`y_2`$ 中含因子 $`x`$，说明 $`\lambda = 1`$ 是特征方程的二重根（否则通解中第二项应为 $`e^{\lambda_2 x}`$ 而非 $`xe^x`$）。故特征方程为
>
> ```math
> (\lambda - 1)^2 = 0,\qquad 即\quad \lambda^2 - 2\lambda + 1 = 0,
> ```
>
> 所以 $`p = -2`$，$`q = 1`$。
>
> **该微分方程是**
>
> ```math
> \boxed{\,y'' - 2y' + y = 0\,}
> ```
>
> **验算**：$`y_1 = e^x`$：$`y_1'' - 2y_1' + y_1 = (1 - 2 + 1)e^x = 0\ \checkmark`$；$`y_2 = xe^x`$：$`y_2' = (x+1)e^x`$，$`y_2'' = (x+2)e^x`$，$`y_2'' - 2y_2' + y_2 = \big[(x+2) - 2(x+1) + x\big]e^x = 0\ \checkmark`$，验算通过。

### B6.（第08届·一(3)，2016年）｜难度：中｜（跨专题：另见多元微分专题）

设 $`f(x)`$ 有连续导数，且 $`f(1) = 2`$。记 $`z = f\left(e^x y^2\right)`$，若 $`\dfrac{\partial z}{\partial x} = z`$，$`f(x)`$ 在 $`x > 0`$ 的表达式为 $`\underline{\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> 记 $`u = e^x y^2`$，则 $`z = f(u)`$。由链式法则
>
> ```math
> \frac{\partial z}{\partial x} = f'(u)\cdot e^x y^2 = f'(u)\cdot u.
> ```
>
> 代入 $`\dfrac{\partial z}{\partial x} = z = f(u)`$，得
>
> ```math
> u f'(u) = f(u).
> ```
>
> 即 $`\dfrac{f'(u)}{f(u)} = \dfrac{1}{u}`$（由 $`f(1) = 2 \neq 0`$ 及连续性知在 $`u > 0`$ 上 $`f(u)\neq 0`$——在 $`f \neq 0`$ 的区间上分离变量，再按连续性延拓）。积分得
>
> ```math
> \ln|f(u)| = \ln u + C_1\ \Longrightarrow\ f(u) = Cu\ (u > 0).
> ```
>
> 由 $`f(1) = 2`$ 得 $`C = 2`$。
>
> **所求表达式为**
>
> ```math
> \boxed{\,f(x) = 2x\quad (x>0)\,}
> ```
>
> **验算**：此时 $`z = 2e^x y^2`$，$`\dfrac{\partial z}{\partial x} = 2e^x y^2 = z\ \checkmark`$；$`f(1) = 2\ \checkmark`$，验算通过。

### B7.（第09届·一(1)，2017年）｜难度：中

已知可导函数 $`f(x)`$ 满足 $`f(x)\cos x + 2\displaystyle\int_0^x f(t)\sin t\,\mathrm{d}t = x+1`$，则 $`f(x) = \underline{\qquad\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：取 $`x=0`$ 得初值。** $`f(0)\cdot 1 + 0 = 1`$，故 $`f(0) = 1`$。
>
> **第二步：求导化为一阶线性方程。** 对恒等式两边求导（$`f`$ 可导，左端第一项用乘积法则，第二项用变限积分求导）：
>
> ```math
> f'(x)\cos x - f(x)\sin x + 2f(x)\sin x = 1,
> ```
>
> 即
>
> ```math
> f'(x)\cos x + f(x)\sin x = 1.
> ```
>
> 在 $`\cos x \neq 0`$ 处化为标准线性方程
>
> ```math
> f'(x) + f(x)\tan x = \sec x.
> ```
>
> 积分因子 $`\mu(x) = e^{\int \tan x\,dx} = \sec x`$：
>
> ```math
> \left(f(x)\sec x\right)' = \sec^2 x\ \Longrightarrow\ f(x)\sec x = \tan x + C\ \Longrightarrow\ f(x) = \sin x + C\cos x.
> ```
>
> （在 $`\cos x = 0`$ 的点由 $`f`$ 可导（从而连续）延拓，等式仍成立。）
>
> **第三步：定常数。** 由 $`f(0) = 1`$ 得 $`C = 1`$。
>
> **所求函数为**
>
> ```math
> \boxed{\,f(x) = \sin x + \cos x\,}
> ```
>
> **验算**：代入原恒等式：$`f(x)\cos x = \sin x\cos x + \cos^2 x`$；而
>
> ```math
> 2\int_0^x (\sin t + \cos t)\sin t\,\mathrm{d}t = 2\int_0^x \left(\sin^2 t + \sin t\cos t\right)\mathrm{d}t = \left[t - \frac{\sin 2t}{2} + \sin^2 t\right]_0^x = x - \sin x\cos x + \sin^2 x,
> ```
>
> 两式相加得 $`\sin x\cos x + \cos^2 x + x - \sin x\cos x + \sin^2 x = x + 1\ \checkmark`$，验算通过。

## 本专题训练建议

**做题顺序**（约 3 小时，分 2 个训练单元）：

1. **热身（第一单元前半）**：A5、A7、A8、A13、B5、B6——一阶换元（$`\mathrm{e}^y`$、$`\cos y`$）、伯努利、二阶常系数初值、反求方程的基本套路。这几道是"送分题"，要求 3 分钟内做到 100% 正确。
2. **结构型与反推型（第一单元后半）**：A1、B1、B2、B4、B7——路径无关条件、解的结构反求方程、积分恒等式求导、参数方程相切条件。重在**识别"隐藏方程"**：看清条件给的是 $`tf'(t)+f(t)=1`$、$`(1+t)\psi''-\psi'=\cdots`$ 这类"凑微分/降阶"结构。
3. **综合与证明（第二单元）**：A2、A3、A4、A6、A9、A10、A11、A12——有界性估计、两次换元、跨专题综合。其中 A4、A11、A12 的官方解答要能独立复述。

**目标正确率**：A5、A7、A8、A13、B5 一类小题 100%；高分大题（A2、A4、A6、A9、A11、B3）≥80%。

**易错提醒**：

- 换元（$`\mathrm{e}^y`$、$`u=\cos y`$、$`u=y^2`$、$`v/y`$ 型）后必须**回代并定常数**（通解写 $`C`$，初值题必须算到底），B3、B4 都是"常数定错则全错"。
- 伯努利方程 $`y'+p(x)y=q(x)y^n`$ 的标准换元是 $`z=y^{1-n}`$；A7/A13 含 $`\ln x`$，注意定义域 $`x>0,\ x\neq 1`$。
- 由路径无关条件（$`\partial Q/\partial x=\partial P/\partial y`$）导出的方程常可凑成 $`\big(tf(t)\big)'=1`$ 或关于 $`x(u)`$ 的线性方程，先观察再硬算（A1、B4）。
- 有界性证明（A2、A4）的评分点在**估计链**：先写通解中各项的界，再逐项放缩，最后说明 $`C_1,C_2`$ 对每个确定的解是常数；不要跳步。
- 参数方程二阶导数公式 $`\dfrac{d^2y}{dx^2} = \dfrac{\psi''(t)x'(t)-\psi'(t)x''(t)}{[x'(t)]^3}`$ 易漏项，B3 的得分点就在此。
- **重复题警示**：A7 与 A13 是同一方程（2022 填空、2025 解答题），A1 与 B4 同型（路径无关），B1 与 B5 同型（反求方程）——这些"命题人偏爱题型"考前必须做到条件反射。
