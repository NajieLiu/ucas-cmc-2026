### A1（第10届·一(4)，2018年）｜难度：中

**方法标签**：连乘式拆分 + 等价无穷小

$`\lim\limits_{x\to 0}\dfrac{1 - \cos x\sqrt{\cos 2x}\sqrt[3]{\cos 3x}}{x^2} = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`3`$）：
>
> ```math
> \lim_{x\to 0}\frac{1-\cos x\sqrt{\cos 2x}\sqrt[3]{\cos 3x}}{x^2} = \lim_{x\to 0}\left[\frac{1-\cos x}{x^2} + \frac{\cos x\left(1-\sqrt{\cos 2x}\sqrt[3]{\cos 3x}\right)}{x^2}\right]
> ```
>
> ```math
> = \frac{1}{2} + \lim_{x\to 0}\frac{1-\sqrt{\cos 2x}\sqrt[3]{\cos 3x}}{x^2} = \frac{1}{2} + \lim_{x\to 0}\left[\frac{1-\sqrt{\cos 2x}}{x^2} + \frac{\sqrt{\cos 2x}\left(1-\sqrt[3]{\cos 3x}\right)}{x^2}\right]
> ```
>
> ```math
> = \frac{1}{2} + \lim_{x\to 0}\left[\frac{1-\sqrt{(\cos 2x - 1)+1}}{x^2} + \frac{1-\sqrt[3]{(\cos 3x - 1)+1}}{x^2}\right]
> ```
>
> ```math
> = \frac{1}{2} + \lim_{x\to 0}\frac{1-\cos 2x}{2x^2} + \lim_{x\to 0}\frac{1-\cos 3x}{3x^2} = \frac{1}{2} + 1 + \frac{3}{2} = 3.
> ```
>

### A2（第11届·一(1)，2019年）｜难度：中

**方法标签**：等价无穷小替换 + 极限拆分（对数型复合）

极限 $`\lim\limits_{x\to 0}\dfrac{\ln(e^{\sin x}+\sqrt[3]{1-\cos x})-\sin x}{\arctan(4\sqrt[3]{1-\cos x})} = \dfrac{1}{4}`$。

> **解答**（官方参考答案；答案：$`\dfrac{1}{4}`$）：
>
> ```math
> \lim_{x\to 0}\frac{\ln(e^{\sin x}+\sqrt[3]{1-\cos x})-\sin x}{\arctan(4\sqrt[3]{1-\cos x})} = \lim_{x\to 0}\frac{(e^{\sin x}-1)+\sqrt[3]{1-\cos x}}{4\sqrt[3]{1-\cos x}} - \lim_{x\to 0}\frac{\sin x}{4\sqrt[3]{1-\cos x}}
> ```
>
> ```math
> = \lim_{x\to 0}\frac{e^{\sin x}-1}{4\left(\frac{x^2}{2}\right)^{1/3}} + \frac{1}{4} - \lim_{x\to 0}\frac{\sin x}{4\left(\frac{x^2}{2}\right)^{1/3}} = \frac{1}{4}.
> ```
>
> （两次用到同一个尺度：$`\sqrt[3]{1-\cos x}\sim\left(\dfrac{x^2}{2}\right)^{1/3}=2^{-1/3}x^{2/3}`$，与 $`x`$ 相比是低阶无穷小，故含 $`e^{\sin x}-1\sim x`$、$`\sin x\sim x`$ 的两项在分母 $`x^{2/3}`$ 下都趋近 $`0`$。）

### A3（第12届·一(5)，2020年）｜难度：难

**方法标签**：幂指函数差 + 等价无穷小（$`e^u-1\sim u`$、$`\ln(1+u)\sim u`$）

设 $`f(x)`$，$`g(x)`$ 在 $`x=0`$ 的某一邻域 $`U`$ 内有定义，对任意 $`x\in U`$，$`f(x)\neq g(x)`$，且 $`\lim\limits_{x\to 0}f(x) = \lim\limits_{x\to 0}g(x) = a > 0`$，则 $`\lim\limits_{x\to 0}\dfrac{[f(x)]^{g(x)}-[g(x)]^{g(x)}}{f(x)-g(x)} = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`a^a`$）：
>
> 根据极限的保号性，存在 $`x=0`$ 的一个去心邻域 $`U_1`$，使得 $`x\in U_1`$ 时 $`f(x)>0`$，$`g(x)>0`$。当 $`x\to 0`$ 时，有 $`e^x-1\sim x`$，$`\ln(1+x)\sim x`$，利用等价无穷小替换，得
>
> ```math
> \lim_{x\to 0}\frac{[f(x)]^{g(x)}-[g(x)]^{g(x)}}{f(x)-g(x)} = \lim_{x\to 0}[g(x)]^{g(x)}\frac{\left(\frac{f(x)}{g(x)}\right)^{g(x)}-1}{f(x)-g(x)} = a^a\lim_{x\to 0}\frac{\left(\frac{f(x)}{g(x)}\right)^{g(x)}-1}{f(x)-g(x)}
> ```
>
> ```math
> = a^a\lim_{x\to 0}\frac{e^{g(x)\ln\frac{f(x)}{g(x)}}-1}{f(x)-g(x)} = a^a\lim_{x\to 0}\frac{g(x)\ln\frac{f(x)}{g(x)}}{f(x)-g(x)} = a^a\lim_{x\to 0}\frac{g(x)\ln\left(1+\left(\frac{f(x)}{g(x)}-1\right)\right)}{f(x)-g(x)}
> ```
>
> ```math
> = a^a\lim_{x\to 0}\frac{g(x)\left(\frac{f(x)}{g(x)}-1\right)}{f(x)-g(x)} = a^a.
> ```
>

### A4（第12届·二，2020年）｜难度：中

**方法标签**：递推数列取倒数 + 递推求和 + $`e`$ 的级数表示

设数列 $`\{a_n\}`$ 满足：$`a_1 = 1`$，且 $`a_{n+1} = \dfrac{a_n}{(n+1)(a_n+1)}`$，$`n\geq 1`$。求极限 $`\lim\limits_{n\to\infty}n!\,a_n`$。

> **解答**（官方参考答案；答案：$`\dfrac{1}{e}`$）：
>
> 利用归纳法易知 $`a_n > 0`$（$`n\geq 1`$）。由于
>
> ```math
> \frac{1}{a_{n+1}} = (n+1)\left(1+\frac{1}{a_n}\right) = (n+1) + (n+1)\frac{1}{a_n} = (n+1) + (n+1)\left(n + n\frac{1}{a_{n-1}}\right)
> ```
>
> ```math
> = (n+1) + (n+1)n + (n+1)n\frac{1}{a_{n-1}},
> ```
>
> ……（4 分）
>
> 如此递推，得
>
> ```math
> \frac{1}{a_{n+1}} = (n+1)!\left(\sum_{k=1}^n\frac{1}{k!} + \frac{1}{a_1}\right) = (n+1)!\sum_{k=0}^n\frac{1}{k!},
> ```
>
> ……（3 分）
>
> 因此
>
> ```math
> \lim_{n\to\infty}n!\,a_n = \frac{1}{\lim\limits_{n\to\infty}\sum\limits_{k=0}^{n-1}\dfrac{1}{k!}} = \frac{1}{e}.
> ```
>
> ……（3 分）

### A6（第13届·一(3)，2021年）｜难度：中

**方法标签**：变限积分求导 + 洛必达 + 积分中值定理

设函数 $`f(x)`$ 连续，且 $`f(0)\neq 0`$，则 $`\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x (x-t)f(t)\,\mathrm{d}t}{x\displaystyle\int_0^x f(x-t)\,\mathrm{d}t}=\underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`1`$）：
>
> 原式 $`=\lim\limits_{x\to 0}\dfrac{2x\displaystyle\int_0^x f(t)\,\mathrm{d}t-2\displaystyle\int_0^x tf(t)\,\mathrm{d}t}{x\displaystyle\int_0^x f(u)\,\mathrm{d}u}=\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x f(t)\,\mathrm{d}t+2xf(x)-2xf(x)}{\displaystyle\int_0^x f(u)\,\mathrm{d}u+xf(x)}`$
>
> ```math
> =\lim\limits_{x\to 0}\dfrac{2\displaystyle\int_0^x f(t)\,\mathrm{d}t}{\displaystyle\int_0^x f(u)\,\mathrm{d}u+xf(x)}=\lim\limits_{x\to 0}\dfrac{2xf(\xi)}{xf(\xi)+xf(x)}=1,
> ```
>
> 其中 $`\xi`$ 介于 $`0,x`$ 之间。

### A7（第14届·一(1)，2022年）｜难度：易

**方法标签**：洛必达法则（根式求导、凑 $`\dfrac{\sin x}{x}`$）

极限 $`\lim\limits_{x\to 0}\dfrac{1-\sqrt{1-x^2}\cos x}{1+x^2-\cos^2 x} = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`\dfrac{1}{2}`$）：
>
> 利用洛必达法则，得
> 原式 $`= \lim\limits_{x\to 0}\dfrac{\sqrt{1-x^2}\sin x + \dfrac{x\cos x}{\sqrt{1-x^2}}}{2x+2\cos x\sin x} = \lim\limits_{x\to 0}\dfrac{\sqrt{1-x^2}\cdot\dfrac{\sin x}{x} + \dfrac{\cos x}{\sqrt{1-x^2}}}{2+2\dfrac{\sin x}{x}\cdot\cos x} = \dfrac{1}{2}`$。
>
> **另解（Taylor 展开，备考项目补注）**：$`x\to 0`$ 时，$`\sqrt{1-x^2} = 1-\dfrac{x^2}{2}+o(x^2)`$，$`\cos x = 1-\dfrac{x^2}{2}+o(x^2)`$，故
>
> ```math
> \sqrt{1-x^2}\cos x = 1-x^2+o(x^2),\qquad 1-\sqrt{1-x^2}\cos x = x^2+o(x^2);
> ```
>
> ```math
> 1+x^2-\cos^2 x = 1+x^2-\left(1-\frac{x^2}{2}+o(x^2)\right)^2 = 2x^2+o(x^2),
> ```
>
> 故原式 $`= \lim\limits_{x\to 0}\dfrac{x^2+o(x^2)}{2x^2+o(x^2)} = \dfrac{1}{2}`$。

### A8（第14届第二次补赛·一(1)，2023年）｜难度：易

**方法标签**：定积分定义（黎曼和）

极限 $`\lim\limits_{n\to\infty}\dfrac{1}{n^3}\left[1^2+3^2+\cdots+(2n-1)^2\right] = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`\dfrac{4}{3}`$）：
>
> 利用定积分的定义，得
>
> ```math
> \lim_{n\to\infty}\frac{1}{n^3}\left[1^2+3^2+\cdots+(2n-1)^2\right] = 4\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n}\left(\frac{k}{n}-\frac{1}{2n}\right)^2 = 4\int_0^1 x^2\,\mathrm{d}x = \frac{4}{3}.
> ```
>
> **另解（求和公式，备考项目补注）**：由 $`\sum\limits_{k=1}^n(2k-1)^2 = 4\sum\limits_{k=1}^n k^2-4\sum\limits_{k=1}^n k+n = \dfrac{n(4n^2-1)}{3}`$，原式 $`= \lim\limits_{n\to\infty}\dfrac{4n^2-1}{3n^2} = \dfrac{4}{3}`$。

### A9（第16届·一(2)，2024年）｜难度：中

**方法标签**：极坐标 + 二重积分 + Taylor 展开（跨专题：另见重积分专题）

设 $`D: x^2+y^2 \leqslant r^2`$，其中 $`r > 0`$。则

```math
\lim_{r\to 0^+}\frac{\displaystyle\iint_D \left(\mathrm{e}^{x^2+y^2}-1\right)\mathrm{d}x\,\mathrm{d}y}{r^4} = \underline{\qquad}.
```

> **解答**（官方参考答案；答案：$`\dfrac{\pi}{2}`$）：
>
> 利用极坐标变换 $`x = \rho\cos\theta`$，$`y = \rho\sin\theta`$，则
>
> ```math
> \iint_D \left(\mathrm{e}^{x^2+y^2}-1\right)\mathrm{d}x\,\mathrm{d}y = 2\pi\int_0^r \left(\mathrm{e}^{\rho^2}-1\right)\rho\,\mathrm{d}\rho = \pi\left(\mathrm{e}^{r^2}-1-r^2\right).
> ```
>
> 注意，$`r \to 0^+`$ 时，$`\mathrm{e}^{r^2}-1-r^2 = \dfrac{r^4}{2} + o(r^4)`$，故原式 $`= \dfrac{\pi}{2}`$。

### A10（第17届·一(1)，2025年）｜难度：易

**方法标签**：Taylor 展开确定参数

设函数 $`f(x) = x - \ln(1+x) - \dfrac{1}{2}x\sin x`$，$`g(x) = ax^3`$，且满足 $`\lim\limits_{x\to 0}\dfrac{f(x)}{g(x)} = 1`$，则 $`a = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`a = -\dfrac{1}{3}`$）：
>
> 根据 Taylor 公式，$`\ln(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} + o(x^3)`$，$`\sin x = x - \dfrac{x^3}{6} + o(x^3)`$，所以
>
> ```math
> f(x) = -\frac{1}{3}x^3 + o(x^3).
> ```
>
> 因为 $`\lim\limits_{x\to 0}\dfrac{f(x)}{g(x)} = 1`$，即 $`\lim\limits_{x\to 0}\dfrac{-\frac{1}{3}x^3 + o(x^3)}{ax^3} = 1`$，所以 $`a = -\dfrac{1}{3}`$。

### A11（第17届·一(3)，2025年）｜难度：易

**方法标签**：变限积分 + 等价无穷小 + 洛必达

极限 $`\lim\limits_{x\to 0}\dfrac{\displaystyle\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\left(\sqrt[3]{1+x^3} - 1\right)\sin x} = \underline{\qquad}`$。

> **解答**（官方参考答案；答案：$`\dfrac{3}{2}`$）：
>
> ```math
> \lim_{x\to 0}\frac{\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\left(\sqrt[3]{1+x^3}-1\right)\sin x} = \lim_{x\to 0}\frac{\int_0^{\sin^2 x}\ln(1+t)\,\mathrm{d}t}{\frac{1}{3}x^4}
> ```
>
> （这里用了 $`\sqrt[3]{1+x^3}-1 \sim \frac{1}{3}x^3`$，$`\sin x \sim x`$）继续用洛必达法则：
>
> ```math
> = \lim_{x\to 0}\frac{\ln(1+\sin^2 x)\cdot 2\sin x\cos x}{\frac{4}{3}x^3} = \frac{3}{2}.
> ```
>

### A12（第17届·二，2025年）｜难度：中

**方法标签**：定积分自洽方程 + 导数定义

设 $`f(x)`$ 在 $`(-\infty, +\infty)`$ 上连续，在 $`x = 0`$ 处可导，且满足

```math
f(x) = x^3 + x^2\lim_{x\to 0}\frac{f(x)}{x} - x\int_0^1 f(x)\,\mathrm{d}x.
```

求函数 $`f(x)`$ 的表达式。

> **解答**（官方参考答案；答案：$`f(x) = x^3 - \dfrac{3}{22}x^2 - \dfrac{3}{22}x`$）：
>
> 易知 $`f(0) = 0`$，所以 $`\lim\limits_{x\to 0}\dfrac{f(x)}{x} = \lim\limits_{x\to 0}\dfrac{f(x) - f(0)}{x - 0} = f'(0)`$。
>
> 记 $`a = f'(0)`$，$`b = \displaystyle\int_0^1 f(x)\,\mathrm{d}x`$，则
>
> ```math
> f(x) = x^3 + ax^2 - bx. \tag{1}
> ```
>
> 由此得 $`a = \lim\limits_{x\to 0}\dfrac{f(x)}{x} = -b`$。……（6 分）
>
> 再对式子 (1) 的两边在 $`[0,1]`$ 上作定积分，得
>
> ```math
> b = \int_0^1 x^3\,\mathrm{d}x + a\int_0^1 x^2\,\mathrm{d}x - b\int_0^1 x\,\mathrm{d}x = \frac{1}{4} + \frac{1}{3}a - \frac{1}{2}b.
> ```
>
> ……（10 分）
>
> 与 $`a = -b`$ 联立解得 $`a = -\dfrac{3}{22}`$，$`b = \dfrac{3}{22}`$。所以
>
> ```math
> f(x) = x^3 - \frac{3}{22}x^2 - \frac{3}{22}x,\qquad -\infty < x < +\infty.
> ```
>
> ……（14 分）

### B1（第01届·一(2)，2009年）｜难度：易

**方法标签**：定积分为常数的函数方程

设 $`f(x)`$ 是连续函数，满足 $`f(x) = 3x^2 - \displaystyle\int_0^2 f(x)\,\mathrm{d}x - 2`$，则 $`f(x) = \underline{\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`f(x) = 3x^2 - \dfrac{10}{3}`$）：
>
> 注意定积分 $`A = \displaystyle\int_0^2 f(x)\,\mathrm{d}x`$ 是一个确定的常数（与 $`x`$ 无关，虽然写成含 $`f`$ 的形式）。于是题设即
>
> ```math
> f(x) = 3x^2 - A - 2.
> ```
>
> 两边在 $`[0,2]`$ 上积分：
>
> ```math
> A = \int_0^2(3x^2 - A - 2)\,\mathrm{d}x = \left.x^3\right|_0^2 - 2A - 4 = 8 - 2A - 4,
> ```
>
> 解得 $`A = \dfrac{4}{3}`$。因此 $`f(x) = 3x^2 - \dfrac{4}{3} - 2 = 3x^2 - \dfrac{10}{3}`$。
>
> **验算**：$`\displaystyle\int_0^2\left(3x^2 - \dfrac{10}{3}\right)\mathrm{d}x = 8 - \dfrac{20}{3} = \dfrac{4}{3} = A`$，且 $`3x^2 - A - 2 = 3x^2 - \dfrac{10}{3}`$，与原方程自洽。

### B2（第01届·第二题，2009年）｜难度：易

**方法标签**：$`1^\infty`$ 型幂指函数（取对数，含参 $`n`$）

求极限

```math
\lim_{x\to 0}\left(\frac{e^x + e^{2x} + \cdots + e^{nx}}{n}\right)^{\frac{e}{x}},
```

其中 $`n`$ 是给定的正整数。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`e^{\frac{e(n+1)}{2}}`$）：
>
> 记 $`S(x) = \dfrac{e^x+e^{2x}+\cdots+e^{nx}}{n}`$，则 $`S(0) = 1`$，属 $`1^\infty`$ 型。取对数后利用导数定义：
>
> ```math
> \ln(\text{原式}) = \lim_{x\to 0}\frac{e}{x}\ln S(x) = e\lim_{x\to 0}\frac{\ln S(x) - \ln S(0)}{x - 0} = e\left[\ln S(x)\right]'\Big|_{x=0} = e\cdot\frac{S'(0)}{S(0)}.
> ```
>
> 而 $`\left(e^{kx}\right)'\big|_{x=0} = k`$，故
>
> ```math
> S'(0) = \frac{1}{n}\sum_{k=1}^n k = \frac{n(n+1)}{2n} = \frac{n+1}{2}.
> ```
>
> 因此原式 $`= e^{\frac{e(n+1)}{2}}`$。
>
> **验算**：$`n = 1`$ 时原式为 $`\left(e^x\right)^{e/x} = e^e`$，公式给出 $`e^{\frac{e\cdot 2}{2}} = e^e`$ ✓。

### B3（第02届·一(1)，2010年）｜难度：中

**方法标签**：无穷乘积（乘 $`(1-a)`$ 连锁平方差）

设 $`x_n = (1+a)\cdot(1+a^2)\cdots(1+a^{2^n})`$，其中 $`|a| < 1`$，求 $`\lim\limits_{n\to\infty} x_n`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`\dfrac{1}{1-a}`$）：
>
> 利用平方差公式 $`(1-a^{2^k})(1+a^{2^k}) = 1 - a^{2^{k+1}}`$ 连锁化简：
>
> ```math
> (1-a)x_n = (1-a)(1+a)(1+a^2)\cdots(1+a^{2^n}) = (1-a^2)(1+a^2)\cdots(1+a^{2^n}) = \cdots = 1 - a^{2^{n+1}}.
> ```
>
> 由于 $`|a| < 1`$，$`a^{2^{n+1}} \to 0`$，故
>
> ```math
> x_n = \frac{1-a^{2^{n+1}}}{1-a} \to \frac{1}{1-a}.
> ```
>
> **验算**：取 $`a = \dfrac{1}{2}`$，$`x_1 = \dfrac{3}{2}\cdot\dfrac{5}{4} = \dfrac{15}{8} = 1.875`$，公式给出的极限为 $`2`$ ✓（序列单调增趋向 $`2`$）。

### B4（第03届·一(1)，2011年）｜难度：难

**方法标签**：幂指函数 Taylor 展开 + 配凑相消

```math
\lim_{x\to 0}\frac{(1+x)^{\frac{2}{x}} - e^2\left(1 - \ln(1+x)\right)}{x}.
```

> **解答**（本解答由备考项目编写，非官方答案；答案：$`0`$）：
>
> 两个 $`e^2`$ 型的项都展开到 $`x^2`$ 项，才能看清相消后的阶。
>
> 先展开第一项。由 $`\ln(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} + o(x^3)`$ 得
>
> ```math
> \frac{2}{x}\ln(1+x) = 2 - x + \frac{2}{3}x^2 + o(x^2),
> ```
>
> 故（用 $`e^u = 1 + u + \dfrac{u^2}{2} + o(u^2)`$，$`u = -x + \dfrac{2}{3}x^2 + o(x^2)`$，$`u^2 = x^2 + o(x^2)`$）
>
> ```math
> (1+x)^{\frac{2}{x}} = e^{2-x+\frac{2}{3}x^2+o(x^2)} = e^2\left[1 - x + \left(\frac{2}{3}+\frac{1}{2}\right)x^2 + o(x^2)\right] = e^2\left[1 - x + \frac{7}{6}x^2 + o(x^2)\right].
> ```
>
> 再展开第二项：$`e^2\left(1-\ln(1+x)\right) = e^2\left[1 - x + \dfrac{x^2}{2} + o(x^2)\right]`$。
>
> 两式相减，分子
>
> ```math
> = e^2\left[\left(\frac{7}{6}-\frac{1}{2}\right)x^2 + o(x^2)\right] = e^2\cdot\frac{2}{3}x^2 + o(x^2).
> ```
>
> 除以 $`x`$ 后为 $`e^2\cdot\dfrac{2}{3}x + o(x) \to 0`$，故原极限 $`= 0`$。
>
> **验算**：代 $`x = 0.001`$ 数值检查（$`e^2 \approx 7.389`$）：$`(1.001)^{2000} - e^2(1-\ln 1.001) \approx 7.389 \times \frac{2}{3}\times 10^{-6} \approx 4.93\times 10^{-6}`$，除以 $`x = 0.001`$ 得 $`\approx 4.93\times 10^{-3} \to 0`$，与 $`O(x)`$ 的量级一致 ✓。

### B5（第04届·一(1)，2012年）｜难度：中

**方法标签**：幂指型数列、取对数 + 夹逼估计

求极限 $`\lim\limits_{n\to\infty}(n!)^{\frac{1}{n^2}}`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`1`$）：
>
> 记 $`a_n = (n!)^{\frac{1}{n^2}}`$，先取对数：$`\ln a_n = \dfrac{\ln(n!)}{n^2} = \dfrac{1}{n^2}\sum\limits_{k=1}^{n}\ln k`$。
>
> 用夹逼估计 $`\ln(n!)`$：对 $`1\le k\le n`$ 有 $`0\le \ln k\le \ln n`$（$`\ln 1 = 0`$，$`\ln`$ 单调），故
>
> ```math
> 0 \le \frac{\ln(n!)}{n^2} \le \frac{n\ln n}{n^2} = \frac{\ln n}{n}.
> ```
>
> 又 $`\lim\limits_{n\to\infty}\dfrac{\ln n}{n} = 0`$（洛必达或标准结论），由夹逼准则 $`\dfrac{\ln(n!)}{n^2}\to 0`$，所以
>
> ```math
> \lim_{n\to\infty}(n!)^{\frac{1}{n^2}} = e^{0} = 1.
> ```
>
> （注：用更精细的估计 $`\ln(n!) = n\ln n - n + O(\ln n)`$ 同样得到 $`\to 0`$；本题的关键是"取对数 + 廉价上下界"，不必动用 Stirling 公式。）
>
> **验算**：$`n = 100`$ 时 $`(100!)^{\frac{1}{10000}} \approx 1.0370`$，$`n = 1000`$ 时 $`\approx 1.0059`$，$`n = 5000`$ 时 $`\approx 1.0015`$，向 $`1`$ 缓慢收敛，与结论一致 ✓。

### B6（第05届·一(1)，2013年）｜难度：中

**方法标签**：根式渐近 + 三角周期性 + $`1^\infty`$

求极限 $`\lim\limits_{n\to\infty}\left(1+\sin\pi\sqrt{1+4n^2}\right)^n`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`e^{\frac{\pi}{4}}`$）：
>
> 第一步：利用 $`\sin`$ 的 $`2\pi`$ 周期性化简根式。$`2n`$ 是整数，故
>
> ```math
> \sin\left(\pi\sqrt{1+4n^2}\right) = \sin\left(\pi\sqrt{1+4n^2} - 2\pi n\right) = \sin\left(\pi\left(\sqrt{1+4n^2} - 2n\right)\right).
> ```
>
> 有理化：
>
> ```math
> \sqrt{1+4n^2} - 2n = \frac{1}{\sqrt{1+4n^2} + 2n} \sim \frac{1}{4n},
> ```
>
> 故 $`\sin\left(\pi\sqrt{1+4n^2}\right) \sim \dfrac{\pi}{4n}`$（$`n\to\infty`$ 时内层 $`\dfrac{\pi}{4n}\to 0`$，用 $`\sin t\sim t`$）。
>
> 第二步：按 $`1^\infty`$ 型处理。记 $`u_n = \sin\left(\pi\sqrt{1+4n^2}\right)`$，则 $`u_n\to 0`$ 且 $`nu_n\to \dfrac{\pi}{4}`$，而
>
> ```math
> (1+u_n)^n = e^{n\ln(1+u_n)},\qquad n\ln(1+u_n) \sim n u_n \to \frac{\pi}{4},
> ```
>
> 所以原极限 $`= e^{\frac{\pi}{4}}`$。
>
> **验算**：$`n = 10000`$ 时数值 $`\approx 2.193212`$，而 $`e^{\frac{\pi}{4}} \approx 2.193280`$，吻合 ✓。

### B7（第06届·第六题，2014年）｜难度：难

**方法标签**：黎曼和误差项 + Taylor 余项 + 夹逼

设

```math
A_n = \frac{n}{n^2+1} + \frac{n}{n^2+2^2} + \cdots + \frac{n}{n^2+n^2},
```

求 $`\lim\limits_{n\to\infty} n\left(\frac{\pi}{4} - A_n\right)`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`\dfrac{1}{4}`$）：
>
> 第一步：识别黎曼和。记 $`f(x) = \dfrac{1}{1+x^2}`$，则
>
> ```math
> A_n = \frac{1}{n}\sum_{k=1}^{n}\frac{1}{1+\left(\frac{k}{n}\right)^2} = \frac{1}{n}\sum_{k=1}^{n} f\left(\frac{k}{n}\right),\qquad \int_0^1 f(x)\,\mathrm{d}x = \frac{\pi}{4}.
> ```
>
> 第二步：把误差写成逐段积分。$`f`$ 在 $`[0,1]`$ 上单调减，$`A_n`$ 是右端点黎曼和，故
>
> ```math
> \frac{\pi}{4} - A_n = \sum_{k=1}^{n}\int_{\frac{k-1}{n}}^{\frac{k}{n}}\left[f(x) - f\left(\frac{k}{n}\right)\right]\mathrm{d}x.
> ```
>
> 在每个小区间对 $`f`$ 用 Taylor 展开：
>
> ```math
> f(x) = f\left(\frac{k}{n}\right) + f'\left(\frac{k}{n}\right)\left(x - \frac{k}{n}\right) + \frac{f''(\eta_k)}{2}\left(x - \frac{k}{n}\right)^2,\quad \eta_k\in\left(\frac{k-1}{n},\frac{k}{n}\right).
> ```
>
> 两个可直接算出的小量：
>
> ```math
> \int_{\frac{k-1}{n}}^{\frac{k}{n}}\left(x-\frac{k}{n}\right)\mathrm{d}x = -\frac{1}{2n^2},\qquad \int_{\frac{k-1}{n}}^{\frac{k}{n}}\left(x-\frac{k}{n}\right)^2\mathrm{d}x = \frac{1}{3n^3}.
> ```
>
> 又 $`f''(x) = \dfrac{2(3x^2-1)}{(1+x^2)^3}`$，在 $`[0,1]`$ 上 $`|f''(x)|\le 4`$，故余项总量
>
> ```math
> |R_n| \le \frac{4}{2}\cdot n\cdot\frac{1}{3n^3} = \frac{2}{3n^2},\qquad\text{即 } \frac{\pi}{4}-A_n = -\frac{1}{2n^2}\sum_{k=1}^{n}f'\left(\frac{k}{n}\right) + R_n,\quad |R_n|\le\frac{2}{3n^2}.
> ```
>
> 第三步：两边乘 $`n`$ 后取极限。
>
> ```math
> n\left(\frac{\pi}{4}-A_n\right) = \frac{1}{n}\sum_{k=1}^{n}\left[-\frac{1}{2}f'\left(\frac{k}{n}\right)\right] + nR_n.
> ```
>
> 其中 $`|nR_n|\le \dfrac{2}{3n}\to 0`$；而由 $`f'`$ 连续、黎曼和收敛及牛顿-莱布尼茨公式，
>
> ```math
> \lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n}\left[-\frac{1}{2}f'\left(\frac{k}{n}\right)\right] = -\frac{1}{2}\int_0^1 f'(x)\,\mathrm{d}x = -\frac{1}{2}\left[f(1)-f(0)\right] = -\frac{1}{2}\left(\frac{1}{2}-1\right) = \frac{1}{4}.
> ```
>
> 所以所求极限 $`= \dfrac{1}{4}`$。
>
> **验算**：$`n = 1000`$ 时数值 $`n\left(\frac{\pi}{4}-A_n\right) \approx 0.25004`$，$`n = 5000`$ 时 $`\approx 0.250008`$，趋于 $`\dfrac{1}{4}`$ ✓。

### B8（第08届·一(1)，2016年）｜难度：易

**方法标签**：$`1^\infty`$ 型：取对数归导数定义

若 $`f(x)`$ 在点 $`x = a`$ 处可导，且 $`f(a) \neq 0`$，则 $`\lim\limits_{n\to+\infty}\left[\dfrac{f(a+1/n)}{f(a)}\right]^n = \underline{\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`e^{\frac{f'(a)}{f(a)}}`$）：
>
> 取对数：由 $`f(a)\neq 0`$ 与连续性，$`f`$ 在 $`a`$ 附近不变号，$`g(x) = \ln|f(x)|`$ 在 $`a`$ 的某邻域内有定义且可导，$`g'(a) = \dfrac{f'(a)}{f(a)}`$。于是
>
> ```math
> \lim_{n\to\infty} n\ln\frac{f(a+1/n)}{f(a)} = \lim_{n\to\infty}\frac{\ln|f(a+1/n)| - \ln|f(a)|}{\frac{1}{n}} = g'(a) = \frac{f'(a)}{f(a)},
> ```
>
> （第二步把 $`\dfrac{1}{n}`$ 看作增量 $`h`$，恰为导数定义）。故原式 $`= e^{\frac{f'(a)}{f(a)}}`$。
>
> **验算**：取 $`f(x) = e^x`$，$`a = 0`$：原式 $`= \left(e^{1/n}\right)^n = e`$，公式给出 $`e^{\frac{e^0}{e^0}} = e`$ ✓。

### B9（第09届·一(2)，2017年）｜难度：易

**方法标签**：根式渐近（有理化）+ 三角周期性

极限 $`\lim\limits_{n\to\infty}\sin^2\left(\pi\sqrt{n^2+n}\right) = \underline{\qquad\qquad}`$。

> **解答**（本解答由备考项目编写，非官方答案；答案：$`1`$）：
>
> 利用 $`\sin^2(\theta + k\pi) = \sin^2\theta`$（$`k`$ 为整数，平方消掉符号）：取 $`k = n`$，
>
> ```math
> \sin^2\left(\pi\sqrt{n^2+n}\right) = \sin^2\left(\pi\left(\sqrt{n^2+n} - n\right)\right).
> ```
>
> 有理化：
>
> ```math
> \sqrt{n^2+n} - n = \frac{n}{\sqrt{n^2+n} + n} = \frac{1}{\sqrt{1+\frac{1}{n}} + 1} \longrightarrow \frac{1}{2}.
> ```
>
> 故 $`\pi\left(\sqrt{n^2+n} - n\right)\to \dfrac{\pi}{2}`$，再由 $`\sin^2`$ 的连续性，
>
> ```math
> \lim_{n\to\infty}\sin^2\left(\pi\sqrt{n^2+n}\right) = \sin^2\frac{\pi}{2} = 1.
> ```
>
> **验算**：$`n = 1000`$ 时数值 $`\approx 0.99999985`$ ✓。

- 若某题读完解答后仍有"想不到第一步"的感觉，把该题的"题眼"（如 A1 的 $`1-abc`$ 分解、B4 的展到 $`x^2`$ 项、B7 的误差化为逐段积分）记入错题本。

**易错提醒**

- **等价无穷小的使用纪律**：只在整个乘积因子或商的位置替换；出现在加减结构中时必须像 A1、A2 那样"拆项、逐层剥离"，或像 B4 那样展开到足够高阶。A1 的题眼是恒等分解 $`1-abc = (1-a)+a(1-b)+ab(1-c)`$，不能一步到位直接换。
- **Taylor 展开的阶数**：以"相消后仍能分出主部"为准。B4 中两项的 $`-x`$ 阶相消，必须展开到 $`x^2`$ 项才能得到极限 $`0`$；A10 同理（展到 $`x^3`$ 项定出 $`a`$）。
- **$`1^\infty`$ 型统一处理**：$`\lim(1+u_n)^{v_n} = e^{\lim u_n v_n}`$（$`u_n\to 0`$、$`v_n\to\infty`$、右端极限存在）。B2、B6、B8 都是这一式；切忌把 $`1^\infty`$ 写成 $`1`$。
- **变限积分求导**：先通分化简再求导（A6 中 $`\int_0^x(x-t)f(t)\mathrm{d}t`$ 与 $`\int_0^x f(x-t)\mathrm{d}t`$ 都要先化为标准变限积分）；上下限含 $`x`$ 时用复合函数求导（A11）；洛必达用完一步后若式子复原，改用积分中值定理（A6 官方解法）。
- **"定积分为常数"不是变量**：B1、A12 中把 $`\int_0^2 f`$、$`\int_0^1 f`$ 设为常数 $`A`$（或 $`a,b`$），函数方程即化为代数方程组；切勿对含参积分再求导。
- **数列极限先渐近、后取极限**：B5、B6、B9 的共同套路是先把表达式化简为渐近形式（$`\frac{\ln(n!)}{n^2}\to 0`$、$`\sin(\pi\sqrt{1+4n^2})\sim\frac{\pi}{4n}`$、$`\sqrt{n^2+n}-n\to\frac{1}{2}`$），再取极限；Riemann 和类（A8、B7）则先化为 $`\frac{1}{n}\sum f(\frac{k}{n})`$。
- **记两个"标配"结论**：$`\lim\frac{\ln n}{n}=0`$（B5）、$`\lim(1+\frac{c}{n})^n = e^{c}`$（B6 的收敛内核）。
