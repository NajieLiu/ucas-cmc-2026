## A 组 · 近年真题（第 10-17 届）

### A1（第11届·一(4)，2019年）由全微分求原函数 ｜ 难度：中

**题目**：已知 $`\mathrm{d}u(x,y) = \dfrac{y\,\mathrm{d}x - x\,\mathrm{d}y}{3x^2-2xy+3y^2}`$，则 $`u(x,y) = \underline{\qquad}`$。

> **解答（官方解答）**：
>
> ```math
> \mathrm{d}u(x,y) = \frac{y\,\mathrm{d}x - x\,\mathrm{d}y}{3x^2-2xy+3y^2} = \frac{\mathrm{d}\left(\frac{x}{y}\right)}{3\left(\frac{x}{y}\right)^2 - \frac{2x}{y} + 3} = \frac{1}{2\sqrt{2}}\,\mathrm{d}\arctan\frac{3}{2\sqrt{2}}\left(\frac{x}{y}-\frac{1}{3}\right).
> ```
>
> 所以，$`u(x,y) = \dfrac{1}{2\sqrt{2}}\arctan\dfrac{3}{2\sqrt{2}}\left(\dfrac{x}{y}-\dfrac{1}{3}\right) + C`$。

**编者注**：官方解法的关键是把分子凑成 $`\mathrm{d}\left(\dfrac{x}{y}\right) = \dfrac{y\,\mathrm{d}x - x\,\mathrm{d}y}{y^2}`$，分母提出 $`y^2`$ 后化为 $`\dfrac{\mathrm{d}t}{3t^2-2t+3}`$（$`t = \dfrac{x}{y}`$），再配方用 $`\arctan`$ 积分公式。另有两条快检路径：(1) 先验可积性条件 $`\dfrac{\partial}{\partial y}\left(\dfrac{y}{3x^2-2xy+3y^2}\right) = \dfrac{\partial}{\partial x}\left(\dfrac{-x}{3x^2-2xy+3y^2}\right)`$ 确认原函数存在；(2) 得到结果后可直接求偏导验证。

### A2（第11届·一(5)，2019年）两曲面相切求参数 ｜ 难度：中

> （跨专题：另见空间解析几何专题）

**题目**：设 $`a,b,c,\mu>0`$，曲面 $`xyz = \mu`$ 与曲面 $`\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2} = 1`$ 相切，则 $`\mu = \underline{\qquad}`$。

> **解答（官方解答）**：根据题意有：$`yz = \dfrac{2x}{a^2}\lambda`$，$`xz = \dfrac{2y}{b^2}\lambda`$，$`xy = \dfrac{2z}{c^2}\lambda`$，以及
>
> ```math
> \mu = 2\lambda\frac{x^2}{a^2},\qquad \mu = 2\lambda\frac{y^2}{b^2},\qquad \mu = 2\lambda\frac{z^2}{c^2},
> ```
>
> 从而得：$`\mu = \dfrac{8\lambda^3}{a^2b^2c^2}`$，$`3\mu = 2\lambda`$，
> 联立解得：$`\mu = \dfrac{abc}{3\sqrt{3}}`$。

**编者注**：官方解答略去的中间步骤——相切意味着两曲面在切点处法向量平行，即 $`(yz, xz, xy) = \lambda\left(\dfrac{2x}{a^2}, \dfrac{2y}{b^2}, \dfrac{2z}{c^2}\right)`$，即前三式；前三式两端分别乘 $`x, y, z`$（用 $`xyz = \mu`$）得 $`\mu = \dfrac{2\lambda x^2}{a^2} = \dfrac{2\lambda y^2}{b^2} = \dfrac{2\lambda z^2}{c^2}`$，三式相加并结合椭球面方程得 $`3\mu = 2\lambda`$；三式相乘得 $`\mu^3 = \dfrac{8\lambda^3\mu^2}{a^2b^2c^2}`$，即 $`\mu = \dfrac{8\lambda^3}{a^2b^2c^2}`$，最后消去 $`\lambda`$ 得 $`\mu = \dfrac{abc}{3\sqrt{3}}`$（验算：$`\lambda = \dfrac{3\mu}{2}`$ 代入 $`\mu = \dfrac{27\mu^3}{a^2b^2c^2}`$，得 $`\mu^2 = \dfrac{a^2b^2c^2}{27}`$）。

### A3（第12届·四，2020年）抽象复合偏导与函数方程 ｜ 难度：难

**题目**：已知 $`z = xf\left(\dfrac{y}{x}\right) + 2y\varphi\left(\dfrac{x}{y}\right)`$，其中 $`f`$，$`\varphi`$ 均为二次可微函数。

（1）求 $`\dfrac{\partial z}{\partial x}`$，$`\dfrac{\partial^2 z}{\partial x\partial y}`$；

（2）当 $`f = \varphi`$，且 $`\left.\dfrac{\partial^2 z}{\partial x\partial y}\right|_{x=a} = -by^2`$ 时，求 $`f(y)`$。

> **解答（官方解答）**：
>
> （1）
>
> ```math
> \frac{\partial z}{\partial x} = f\left(\frac{y}{x}\right) - \frac{y}{x}f'\left(\frac{y}{x}\right) + 2\varphi'\left(\frac{x}{y}\right),\qquad \frac{\partial^2 z}{\partial x\partial y} = -\frac{y}{x^2}f''\left(\frac{y}{x}\right) - \frac{2x}{y^2}\varphi''\left(\frac{x}{y}\right).
> ```
>
> ……（3 分）
>
> （2）
>
> ```math
> \left.\frac{\partial^2 z}{\partial x\partial y}\right|_{x=a} = -\frac{y}{a^2}f''\left(\frac{y}{a}\right) - \frac{2a}{y^2}\varphi''\left(\frac{a}{y}\right) = -by^2.
> ```
>
> 因为 $`f = \varphi`$，所以
>
> ```math
> \frac{y}{a^2}f''\left(\frac{y}{a}\right) + \frac{2a}{y^2}f''\left(\frac{a}{y}\right) = by^2.
> ```
>
> 令 $`y = au`$，则 $`\dfrac{u}{a}f''(u) + \dfrac{2}{au^2}f''\left(\dfrac{1}{u}\right) = a^2bu^2`$，即
>
> ```math
> u^3f''(u) + 2f''\left(\frac{1}{u}\right) = a^3bu^4.
> ```
>
> 上式中以 $`\dfrac{1}{u}`$ 换 $`u`$ 得
>
> ```math
> 2f''\left(\frac{1}{u}\right) + 4u^3f''(u) = 2a^3b\,\frac{1}{u}.
> ```
>
> ……（5 分）
>
> 联立二式，解得 $`-3u^3f''(u) = a^3b\left(u^4 - \dfrac{2}{u}\right)`$，所以 $`f''(u) = \dfrac{a^3b}{3}\left(\dfrac{2}{u^4}-u\right)`$，从而有
>
> ```math
> f(u) = \frac{a^3b}{3}\left(\frac{1}{3u^2} - \frac{u^3}{6}\right) + C_1u + C_2.
> ```
>
> 故
>
> ```math
> f(y) = \frac{a^3b}{3}\left(\frac{1}{3y^2} - \frac{y^3}{6}\right) + C_1y + C_2.
> ```
>
> ……（4 分）

**编者注**：本题第（2）问的解法精髓是把 $`f`$ 满足的方程与它"以 $`\frac{1}{u}`$ 换 $`u`$"得到的方程联立，消去 $`f''\left(\frac{1}{u}\right)`$ 项——一种对偶迭代消元。答案中的 $`C_1, C_2`$ 为任意常数。

### A4（第13届·一(2)，2021年）二元隐函数求偏导 ｜ 难度：易

**题目**：设 $`z=z(x,y)`$ 是由方程 $`2\sin(x+2y-3z)=x+2y-3z`$ 所确定的二元隐函数，则 $`\dfrac{\partial z}{\partial x}+\dfrac{\partial z}{\partial y} = \underline{\qquad}`$。

> **解答（官方解答）**：将方程两边分别关于 $`x`$ 和 $`y`$ 求偏导，得
>
> ```math
> \begin{cases}
> 2\cos(x+2y-3z)\left(1-3\dfrac{\partial z}{\partial x}\right)=1-3\dfrac{\partial z}{\partial x},\\[6pt]
> 2\cos(x+2y-3z)\left(2-3\dfrac{\partial z}{\partial y}\right)=2-3\dfrac{\partial z}{\partial y}.
> \end{cases}
> ```
>
> 按 $`\cos(x+2y-3z)=\dfrac{1}{2}`$ 和 $`\neq\dfrac{1}{2}`$ 两种情形，都可解得：
>
> ```math
> \begin{cases}
> \dfrac{\partial z}{\partial x}=\dfrac{1}{3},\\[6pt]
> \dfrac{\partial z}{\partial y}=\dfrac{2}{3}.
> \end{cases}
> ```
>
> 因此 $`\dfrac{\partial z}{\partial x}+\dfrac{\partial z}{\partial y}=1`$。

**编者注**：官方解答中"分两种情形讨论"的道理是：记 $`w = x+2y-3z`$，则 $`w`$ 满足 $`2\sin w = w`$。若 $`2\cos w = 1`$，则 $`w = \pm\dfrac{\pi}{3}+2k\pi`$，代入 $`2\sin w = w`$ 将得 $`\pm\sqrt{3} = \pm\dfrac{\pi}{3}+2k\pi`$，对任何整数 $`k`$ 都不成立，故必有 $`2\cos w \neq 1`$，从而可直接解出 $`\dfrac{\partial z}{\partial x}=\dfrac{1}{3}`$、$`\dfrac{\partial z}{\partial y}=\dfrac{2}{3}`$，答案为 $`1`$。

### A5（第14届补赛·一(4)，2023年）变量替换下复合函数求偏导 ｜ 难度：中

**题目**：设可微函数 $`z=z(x,y)`$ 满足 $`x^2\dfrac{\partial z}{\partial x}+y^2\dfrac{\partial z}{\partial y}=2z^2`$，又设 $`u=x`$，$`v=\dfrac{1}{y}-\dfrac{1}{x}`$，$`w=\dfrac{1}{z}-\dfrac{1}{x}`$，则对函数 $`w=w(u,v)`$，偏导数 $`\left.\dfrac{\partial w}{\partial u}\right|_{\substack{u=2\\v=1}} = \underline{\qquad}`$。

> **解答（官方解答）**：由 $`u=x`$，$`v=\dfrac{1}{y}-\dfrac{1}{x}`$ 解得 $`x=u`$，$`y=\dfrac{u}{uv+1}`$，且 $`w=\dfrac{1}{z}-\dfrac{1}{u}`$，所以
>
> ```math
> \frac{\partial w}{\partial u}=\frac{\partial}{\partial u}\left(\frac{1}{z}-\frac{1}{u}\right)=-\frac{1}{z^2}\cdot\frac{\partial z}{\partial u}+\frac{1}{u^2}=-\frac{1}{z^2}\left(\frac{\partial z}{\partial x}\cdot\frac{\partial x}{\partial u}+\frac{\partial z}{\partial y}\cdot\frac{\partial y}{\partial u}\right)+\frac{1}{u^2}
> ```
>
> ```math
> =-\frac{1}{z^2}\left(\frac{\partial z}{\partial x}+\frac{\partial z}{\partial y}\cdot\frac{uv+1-uv}{(uv+1)^2}\right)+\frac{1}{u^2}=-\frac{1}{z^2}\left(\frac{\partial z}{\partial x}+\frac{\partial z}{\partial y}\cdot\frac{1}{(uv+1)^2}\right)+\frac{1}{u^2}
> ```
>
> ```math
> =-\frac{1}{z^2}\left(\frac{\partial z}{\partial x}+\frac{\partial z}{\partial y}\cdot\frac{y^2}{u^2}\right)+\frac{1}{u^2}=-\frac{1}{z^2u^2}\left(x^2\frac{\partial z}{\partial x}+y^2\frac{\partial z}{\partial y}\right)+\frac{1}{u^2}=-\frac{1}{u^2}.
> ```
>
> 因此 $`\left.\dfrac{\partial w}{\partial u}\right|_{\substack{u=2\\v=1}}=-\dfrac{1}{4}`$。

**编者注**：本题的关键是识别出"约束方程的形式与 $`w`$ 的定义恰好配套"：把 $`w`$ 对 $`u`$ 求导展开后出现组合 $`x^2z_x + y^2z_y`$，直接用题设 $`=2z^2`$ 消去（注意此时 $`x=u`$，且 $`y = \dfrac{u}{uv+1}`$ ⇒ $`\dfrac{1}{(uv+1)^2} = \dfrac{y^2}{u^2}`$），最后 $`\dfrac{1}{z^2u^2}\cdot 2z^2 = \dfrac{2}{u^2}`$，故结果为 $`-\dfrac{2}{u^2}+\dfrac{1}{u^2} = -\dfrac{1}{u^2}`$。

### A6（第15届·一(2)，2023年）二阶混合偏导 ｜ 难度：中

**题目**：设 $`z = f(x^2-y^2,\,xy)`$, 且 $`f(u,v)`$ 有连续的二阶偏导数, 则 $`\dfrac{\partial^2 z}{\partial x\partial y} = \underline{\qquad}`$。

> **注**：此处原卷题面印为 $`\dfrac{\partial^2 z}{\partial y}`$，疑为排版时脱漏 $`\partial x`$；对照解答过程（先求 $`z_x`$，再对 $`y`$ 求偏导），题面正确应为 $`\dfrac{\partial^2 z}{\partial x\partial y}`$。

> **解答（官方解答）**：
>
> ```math
> z_x = 2xf_1 + yf_2,
> ```
>
> ```math
> z_{xy} = 2x\left(f_{11}(-2y) + xf_{12}\right) + f_2 + y\left(f_{21}(-2y) + xf_{22}\right)
> ```
>
> ```math
> = f_2 - 4xy f_{11} + 2(x^2-y^2) f_{12} + xy f_{22}.
> ```
>

**编者注**：答案应完整写为 $`f_2 - 4xyf_{11} + 2(x^2-y^2)f_{12} + xyf_{22}`$（各 $`f`$ 及其偏导均在 $`(u,v) = (x^2-y^2,\ xy)`$ 处取值）；其中"$`+f_2`$"项来自对 $`2xf_1`$ 中 $`f_1`$ 对 $`y`$ 求导的乘积法则，是最易漏项。

### A8（第17届·一(4)，2025年）隐函数求偏导 ｜ 难度：中

**题目**：设函数 $`f(u,v)`$ 具有一阶连续偏导数，$`f(2,0) = 3`$，$`f'_u(2,0) = 5`$，又设 $`z = z(x,y)`$ 是由方程 $`xz = f(2x-y,\,xyz)`$ 确定的隐函数，则 $`\left.\dfrac{\partial z}{\partial x}\right|_{\substack{x=1\\y=0}} = \underline{\qquad}`$。

> **解答（官方解答）**：对方程两边关于 $`x`$ 求偏导数，得
>
> ```math
> z + x\frac{\partial z}{\partial x} = 2f'_u + yf'_v\left(z + x\frac{\partial z}{\partial x}\right).
> ```
>
> 由此解得
>
> ```math
> \frac{\partial z}{\partial x} = \frac{1}{x}\left(\frac{2f'_u}{1 - yf'_v} - z\right).
> ```
>
> 注意到 $`x = 1,\,y = 0`$ 时，$`z = f(2,0) = 3`$，$`f'_u(2,0) = 5`$，所以
>
> ```math
> \left.\frac{\partial z}{\partial x}\right|_{\substack{x=1\\y=0}} = 2f'_u(2,0) - 3 = 7.
> ```
>

**编者注**：本题的亮点在于抽象偏导 $`f'_v`$ 虽未知，但求值点处 $`y = 0`$ 使含 $`f'_v`$ 的项整体消失，无需具体求出。此类"抽象函数 + 特殊取值点"的题要养成"先代特殊值再决定是否展开"的习惯。

### B1（第1届·一(3)，2009年）曲面切平面 ｜ 难度：易

> （跨专题：另见空间解析几何专题）

**题目**：曲面 $`z = \dfrac{x^2}{2} + y^2 - 2`$ 平行平面 $`2x + 2y - z = 0`$ 的切平面方程是 $`\underline{\qquad}`$。

> **解答（本解答由备考项目编写，非官方答案）**：

> ```math

> ```

### B2（第1届·一(4)，2009年）隐函数求二阶导数 ｜ 难度：中

**题目**：设 $`y = y(x)`$ 由方程 $`xe^{f(y)} = e^y \ln 29`$ 确定，其中 $`f`$ 具有二阶导数，且 $`f' \neq 1`$，则 $`\dfrac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \underline{\qquad}`$。

> **解答（本解答由备考项目编写，非官方答案）**：
> 在方程两端对 $`x`$ 求导（$`y = y(x)`$，$`f'(y)`$ 表示 $`f`$ 对 $`y`$ 的导数）：
>
> ```math
> e^{f(y)} + x e^{f(y)} f'(y)\, y' = e^y (\ln 29)\, y'.
> ```
>
> 把原方程 $`xe^{f(y)} = e^y \ln 29`$ 代入右端与第二项，得
>
> ```math
> e^{f(y)} = y'\left[e^y \ln 29 - x e^{f(y)} f'(y)\right] = y'\, x e^{f(y)}\left[1 - f'(y)\right].
> ```
>
> 因 $`xe^{f(y)} = e^y \ln 29 > 0`$，两端除以 $`xe^{f(y)}`$，得
>
> ```math
> \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{1}{x\left[1 - f'(y)\right]}.
> ```
>
> 再对 $`x`$ 求导：
>
> ```math
> \frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = -\frac{\left[x\left(1 - f'(y)\right)\right]'}{x^2\left[1-f'(y)\right]^2} = -\frac{\left(1 - f'(y)\right) - x f''(y)\, y'}{x^2\left[1-f'(y)\right]^2}.
> ```
>
> 利用 $`xy' = \dfrac{1}{1-f'(y)}`$，即 $`xf''(y)y' = \dfrac{f''(y)}{1-f'(y)}`$，代入得
>
> ```math
> \frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \frac{f''(y) - \left[1-f'(y)\right]^2}{x^2\left[1 - f'(y)\right]^3}.
> ```
>
> **验算**（取特殊 $`f`$ 代入核对）：令 $`f(y) = 2y`$（$`f' = 2 \neq 1`$，$`f'' = 0`$），则方程化为 $`x = e^{-y}\ln 29`$，即 $`y = \ln\ln 29 - \ln x`$，有 $`y'' = \dfrac{1}{x^2}`$；代入公式：$`\dfrac{0 - (1-2)^2}{x^2(1-2)^3} = \dfrac{-1}{-x^2} = \dfrac{1}{x^2}`$，一致。再取 $`f(y) = \ln y`$（$`f' = \dfrac{1}{y}`$，$`f'' = -\dfrac{1}{y^2}`$），方程化为 $`xy = e^y \ln 29`$，隐式求导可得 $`y'' = \dfrac{y\left(-y^2 + 2y - 2\right)}{x^2(y-1)^3}`$，与公式代入的结果 $`\dfrac{-y^2+2y-2}{y^2}\cdot\dfrac{y^3}{x^2(y-1)^3}`$ 相同，确认无误。

### B3（第2届·一(4)，2010年）复合函数二阶偏导（Laplace 型组合） ｜ 难度：中

**题目**：设 $`f(t)`$ 有二阶连续导数，$`r = \sqrt{x^2 + y^2}`$，$`g(x, y) = f\left(\dfrac{1}{r}\right)`$，求 $`\dfrac{\partial^2 g}{\partial x^2} + \dfrac{\partial^2 g}{\partial y^2}`$。

> **解答（本解答由备考项目编写，非官方答案）**：
> 记 $`t = \dfrac{1}{r}`$，则 $`\dfrac{\partial t}{\partial x} = -\dfrac{1}{r^2}\cdot\dfrac{\partial r}{\partial x} = -\dfrac{x}{r^3}`$（同理 $`\dfrac{\partial t}{\partial y} = -\dfrac{y}{r^3}`$），且
>
> ```math
> g_x = f'(t)\cdot\left(-\frac{x}{r^3}\right) = -\frac{x f'(t)}{r^3}.
> ```
>
> 再对 $`x`$ 求导（注意 $`t`$ 仍是 $`x`$ 的函数）：
>
> ```math
> g_{xx} = -\frac{f'(t)}{r^3} - x\cdot\frac{\mathrm{d}}{\mathrm{d}x}\left[\frac{f'(t)}{r^3}\right] = -\frac{f'(t)}{r^3} - x\left[\frac{f''(t)\,t_x}{r^3} - \frac{3 f'(t)\, r_x}{r^4}\right].
> ```
>
> 代入 $`t_x = -\dfrac{x}{r^3}`$、$`r_x = \dfrac{x}{r}`$，得
>
> ```math
> g_{xx} = -\frac{f'(t)}{r^3} - x\left[-\frac{x f''(t)}{r^6} - \frac{3x f'(t)}{r^5}\right] = \frac{x^2 f''(t)}{r^6} + \frac{3x^2 f'(t)}{r^5} - \frac{f'(t)}{r^3}.
> ```
>
> 由对称性（把 $`x`$ 换成 $`y`$）：
>
> ```math
> g_{yy} = \frac{y^2 f''(t)}{r^6} + \frac{3y^2 f'(t)}{r^5} - \frac{f'(t)}{r^3}.
> ```
>
> 相加并用 $`x^2 + y^2 = r^2`$：
>
> ```math
> g_{xx} + g_{yy} = \frac{r^2 f''(t)}{r^6} + \frac{3r^2 f'(t)}{r^5} - \frac{2f'(t)}{r^3} = \frac{f''(t)}{r^4} + \frac{f'(t)}{r^3}.
> ```
>
> 即 $`\dfrac{\partial^2 g}{\partial x^2} + \dfrac{\partial^2 g}{\partial y^2} = \dfrac{1}{r^4}f''\left(\dfrac{1}{r}\right) + \dfrac{1}{r^3}f'\left(\dfrac{1}{r}\right)`$。
> **验算**（用极坐标公式二次核对）：$`g = f(1/r)`$ 不依赖 $`\theta`$，二维 Laplace 算子为 $`\Delta g = g_{rr} + \dfrac{1}{r}g_r`$。$`g_r = -\dfrac{1}{r^2}f'(1/r)`$，$`g_{rr} = \dfrac{1}{r^4}f''(1/r) + \dfrac{2}{r^3}f'(1/r)`$，故 $`\Delta g = \dfrac{f''(1/r)}{r^4} + \dfrac{2f'(1/r)}{r^3} - \dfrac{f'(1/r)}{r^3} = \dfrac{f''(1/r)}{r^4} + \dfrac{f'(1/r)}{r^3}`$，一致（再以 $`f(t) = t^2`$ 检验：$`g = r^{-2}`$，$`\Delta g = 4r^{-4}`$，公式给出 $`t^4\cdot 2 + t^3\cdot 2t = 4t^4 = 4r^{-4}`$，相符）。

### B4（第3届·第五题，2011年）隐函数的一阶、二阶偏导恒等式 ｜ 难度：难

**题目**：设 $`z = z(x, y)`$ 是由方程 $`F\left(z + \dfrac{1}{x},\ z - \dfrac{1}{y}\right) = 0`$ 确定的隐函数，且具有连续的二阶偏导数，求证：

```math
x^2\frac{\partial z}{\partial x} - y^2\frac{\partial z}{\partial y} = 1 \quad\text{和}\quad x^3\frac{\partial^2 z}{\partial x^2} + xy(x-y)\frac{\partial^2 z}{\partial x\partial y} - y^3\frac{\partial^2 z}{\partial y^2} + 2 = 0.
```

> **解答（本解答由备考项目编写，非官方答案）**：
>
> **第一部分.** 记 $`u = z + \dfrac{1}{x}`$，$`v = z - \dfrac{1}{y}`$，则恒有 $`F(u,v) = 0`$。
> 对 $`x`$ 求偏导（$`F_u`$，$`F_v`$ 在 $`(u,v)`$ 处取值）：
>
> ```math
> F_u\left(z_x - \frac{1}{x^2}\right) + F_v z_x = 0 \quad\Longrightarrow\quad z_x\left(F_u + F_v\right) = \frac{F_u}{x^2}.
> ```
>
> 对 $`y`$ 求偏导：
>
> ```math
> F_u z_y + F_v\left(z_y + \frac{1}{y^2}\right) = 0 \quad\Longrightarrow\quad z_y\left(F_u + F_v\right) = -\frac{F_v}{y^2}.
> ```
>
> 两式分别乘以 $`x^2`$ 与 $`y^2`$ 后相加：
>
> ```math
> x^2 z_x - y^2 z_y = \frac{F_u}{F_u + F_v} + \frac{F_v}{F_u + F_v} = 1.
> ```
>
> **第二部分.** 对恒等式 $`x^2 z_x - y^2 z_y = 1`$ 的两端分别关于 $`x`$、$`y`$ 求偏导：
>
> ```math
> 2x z_x + x^2 z_{xx} - y^2 z_{xy} = 0, \qquad\text{(1)}
> ```
>
> ```math
> x^2 z_{xy} - 2y z_y - y^2 z_{yy} = 0. \qquad\text{(2)}
> ```
>
> 由 (1) 乘 $`x`$：$`\ 2x^2 z_x + x^3 z_{xx} - x y^2 z_{xy} = 0`$，得 $`x^3 z_{xx} = -2x^2 z_x + x y^2 z_{xy}`$。
> 由 (2) 乘 $`y`$：$`\ x^2 y z_{xy} - 2y^2 z_y - y^3 z_{yy} = 0`$，得 $`-y^3 z_{yy} = -x^2 y z_{xy} + 2y^2 z_y`$。
> 两式相加，并注意到 $`xy(x-y)z_{xy} = (x^2y - xy^2)z_{xy}`$ 恰好把 $`z_{xy}`$ 的系数补成零：
>
> ```math
> x^3 z_{xx} + xy(x-y) z_{xy} - y^3 z_{yy} = -2x^2 z_x + 2y^2 z_y + \left(xy^2 + x^2y - xy^2 - x^2y\right)z_{xy} = -2\left(x^2 z_x - y^2 z_y\right) = -2.
> ```
>
> 即 $`x^3\dfrac{\partial^2 z}{\partial x^2} + xy(x-y)\dfrac{\partial^2 z}{\partial x\partial y} - y^3\dfrac{\partial^2 z}{\partial y^2} + 2 = 0`$。
>
> **验算**（取 $`F(u,v) = u + v`$ 代入核对）：方程化为 $`2z + \dfrac{1}{x} - \dfrac{1}{y} = 0`$，即 $`z = \dfrac{1}{2}\left(\dfrac{1}{y} - \dfrac{1}{x}\right)`$。则 $`z_x = \dfrac{1}{2x^2}`$，$`z_y = -\dfrac{1}{2y^2}`$，$`x^2z_x - y^2z_y = \dfrac{1}{2} + \dfrac{1}{2} = 1`$ ✓；又 $`z_{xx} = -\dfrac{1}{x^3}`$，$`z_{xy} = 0`$，$`z_{yy} = \dfrac{1}{y^3}`$，代入第二式：$`x^3\left(-\dfrac{1}{x^3}\right) + 0 - y^3\cdot\dfrac{1}{y^3} = -2`$ ✓。
>
> **方法点评**：第二问的技巧在于根本不需要解出二阶偏导的显式表达式——把待证式看成"$`x^2z_x - y^2z_y = 1`$ 分别对 $`x`$、$`y`$ 求导的两个方程"的线性组合，$`z_{xy}`$ 项自动抵消。这是"恒等式 + 求导"型题目的标准手法。

### B5（第4届·一(3)，2012年）换元化简二阶偏微分方程 ｜ 难度：中

**题目**：已知函数 $`z = u(x,y)e^{ax+by}`$，且 $`\dfrac{\partial^2 u}{\partial x\partial y} = 0`$，确定常数 $`a`$，$`b`$，使函数 $`z = z(x,y)`$ 满足方程

```math
\frac{\partial^2 z}{\partial x\partial y} - \frac{\partial z}{\partial x} - \frac{\partial z}{\partial y} + z = 0.
```

> **解答（本解答由备考项目编写，非官方答案）**：
> 由 $`z = ue^{ax+by}`$ 逐次求偏导：
>
> ```math
> z_x = \left(u_x + au\right)e^{ax+by},\qquad z_y = \left(u_y + bu\right)e^{ax+by},
> ```
>
> ```math
> z_{xy} = \left(u_{xy} + b u_x + a u_y + ab\,u\right)e^{ax+by}.
> ```
>
> 全部代入左端，提取公因子 $`e^{ax+by}`$：
>
> ```math
> z_{xy} - z_x - z_y + z = e^{ax+by}\left[u_{xy} + (b-1)u_x + (a-1)u_y + (ab-a-b+1)\,u\right].
> ```
>
> 我们希望只要 $`u_{xy} = 0`$，上式就恒为 $`0`$。由于 $`u`$ 是满足 $`u_{xy}=0`$ 的任意函数（$`u_x`$、$`u_y`$、$`u`$ 不能假设为 0），必须且只需 $`u_x`$、$`u_y`$、$`u`$ 的系数全为 0：
>
> ```math
> b - 1 = 0,\qquad a - 1 = 0,\qquad ab - a - b + 1 = 0.
> ```
>
> 由前两式得 $`a = b = 1`$，此时第三式 $`1 - 1 - 1 + 1 = 0`$ 自动成立。
> **验算**：当 $`a = b = 1`$ 时 $`z = ue^{x+y}`$，直接计算得 $`z_{xy} - z_x - z_y + z = e^{x+y}u_{xy} = 0`$ ✓。
> 故 $`a = 1`$，$`b = 1`$。

### B6（第7届·一(2)，2015年）隐式曲面求组合偏导 ｜ 难度：中

**题目**：设 $`z=z(x,y)`$ 由方程 $`F\left(x+\dfrac{z}{y},\,y+\dfrac{z}{x}\right)=0`$ 所决定，其中 $`F(u,v)`$ 具有连续偏导数，且 $`xF_u+yF_v\neq 0`$，则（结果要求不显含有 $`F`$ 及其偏导数）$`x\dfrac{\partial z}{\partial x}+y\dfrac{\partial z}{\partial y}=\underline{\qquad}`$。

> **解答（本解答由备考项目编写，非官方答案）**：
> 记 $`u = x + \dfrac{z}{y}`$，$`v = y + \dfrac{z}{x}`$，则恒有 $`F(u,v) = 0`$。对 $`x`$ 求偏导：
>
> ```math
> F_u\left(1 + \frac{z_x}{y}\right) + F_v\left(\frac{z_x}{x} - \frac{z}{x^2}\right) = 0
> \quad\Longrightarrow\quad z_x\left(\frac{F_u}{y} + \frac{F_v}{x}\right) = \frac{F_v z}{x^2} - F_u.
> ```
>
> 对 $`y`$ 求偏导：
>
> ```math
> F_u\left(\frac{z_y}{y} - \frac{z}{y^2}\right) + F_v\left(1 + \frac{z_y}{x}\right) = 0
> \quad\Longrightarrow\quad z_y\left(\frac{F_u}{y} + \frac{F_v}{x}\right) = \frac{F_u z}{y^2} - F_v.
> ```
>
> 记 $`D = \dfrac{F_u}{y} + \dfrac{F_v}{x} = \dfrac{xF_u + yF_v}{xy}`$（由条件 $`xF_u + yF_v \neq 0`$，$`D \neq 0`$），则
>
> ```math
> z_x = \frac{xy\left(\dfrac{F_v z}{x^2} - F_u\right)}{xF_u + yF_v} = \frac{\dfrac{yF_v z}{x} - xyF_u}{xF_u + yF_v},\qquad
> z_y = \frac{xy\left(\dfrac{F_u z}{y^2} - F_v\right)}{xF_u + yF_v} = \frac{\dfrac{xF_u z}{y} - xyF_v}{xF_u + yF_v}.
> ```
>
> 于是
>
> ```math
> x z_x + y z_y = \frac{yF_v z - x^2yF_u + xF_u z - xy^2F_v}{xF_u + yF_v} = \frac{z\left(xF_u + yF_v\right) - xy\left(xF_u + yF_v\right)}{xF_u + yF_v} = z - xy.
> ```
>
> 故 $`x\dfrac{\partial z}{\partial x}+y\dfrac{\partial z}{\partial y} = z - xy`$（结果不显含 $`F`$）。
> **验算**（取特殊 $`F`$ 代入）：(i) $`F(u,v) = u`$（$`F_u = 1`$，$`F_v = 0`$，条件 $`x \neq 0`$ 满足）：方程化为 $`x + \dfrac{z}{y} = 0`$，即 $`z = -xy`$，此时 $`xz_x + yz_y = -xy - xy = -2xy`$，而 $`z - xy = -2xy`$ ✓。(ii) $`F(u,v) = v`$（$`F_u = 0`$，$`F_v = 1`$）：方程化为 $`y + \dfrac{z}{x} = 0`$，即 $`z = -xy`$，同上 ✓。(iii) $`F(u,v) = u + v`$：方程化为 $`x + y + z\left(\dfrac{1}{x}+\dfrac{1}{y}\right) = 0`$，即 $`z = -\dfrac{xy(x+y)}{x+y} = -xy`$，亦一致 ✓。

### B7（第8届·一(3)，2016年）复合偏导化为可分离变量方程 ｜ 难度：中

**题目**：设 $`f(x)`$ 有连续导数，且 $`f(1) = 2`$。记 $`z = f\left(e^x y^2\right)`$，若 $`\dfrac{\partial z}{\partial x} = z`$，$`f(x)`$ 在 $`x > 0`$ 的表达式为 $`\underline{\qquad}`$。

> 由链式法则，$`z = f(t)`$（$`t = e^x y^2`$），
>
> ```math

> ```
>
> 代入条件 $`\dfrac{\partial z}{\partial x} = z`$，得
>
> ```math
> f'\left(e^x y^2\right) e^x y^2 = f\left(e^x y^2\right).
> ```
>

>
> ```math
> t f'(t) = f(t).
> ```
>

### B8（第9届·一(3)，2017年）波动方程算子（d'Alembert 变换） ｜ 难度：易

**题目**：设 $`w = f(u,v)`$ 具有二阶连续偏导数，且 $`u = x - cy,\ v = x + cy`$，其中 $`c`$ 为非零常数，则 $`w_{xx} - \dfrac{1}{c^2}w_{yy} = \underline{\qquad\qquad}`$。

> **解答（本解答由备考项目编写，非官方答案）**：
> 由链式法则（$`u_x = 1`$，$`v_x = 1`$；$`u_y = -c`$，$`v_y = c`$）：
>
> ```math
> w_x = f_u + f_v,\qquad w_y = -c f_u + c f_v.
> ```
>
> 再对 $`x`$ 求导（此时 $`u, v`$ 的导数同上）：
>
> ```math
> w_{xx} = f_{uu} + 2f_{uv} + f_{vv}.
> ```
>
> 对 $`w_y`$ 再对 $`y`$ 求导：
>
> ```math
> w_{yy} = -c\left(-c f_{uu} + c f_{uv}\right) + c\left(-c f_{vu} + c f_{vv}\right) = c^2f_{uu} - 2c^2f_{uv} + c^2f_{vv}.
> ```
>
> 于是
>
> ```math
> w_{xx} - \frac{1}{c^2}w_{yy} = \left(f_{uu} + 2f_{uv} + f_{vv}\right) - \left(f_{uu} - 2f_{uv} + f_{vv}\right) = 4f_{uv}.
> ```
>
> 故 $`w_{xx} - \dfrac{1}{c^2}w_{yy} = 4\dfrac{\partial^2 f}{\partial u\partial v}`$（在 $`(u,v) = (x-cy,\ x+cy)`$ 处取值）。
> **说明**：这是波动方程 $`w_{xx} - \dfrac{1}{c^2}w_{yy} = 0 \iff f_{uv} = 0 \iff f = \varphi(u) + \psi(v)`$ 的算子分解（d'Alembert 变换），是一维波动方程通解的理论基础，务必熟练。

### B9（第9届·二，2017年）沿任意方向的方向导数证明极值 ｜ 难度：难

**题目**：设二元函数 $`f(x,y)`$ 在平面上有连续的二阶偏导数，对任意角度 $`\alpha`$，定义一元函数 $`g_\alpha(t) = f(t\cos\alpha,\,t\sin\alpha)`$，若对任何 $`\alpha`$ 都有 $`\dfrac{\mathrm{d}g_\alpha(0)}{\mathrm{d}t} = 0`$ 且 $`\dfrac{\mathrm{d}^2g_\alpha(0)}{\mathrm{d}t^2} > 0`$，证明：$`f(0,0)`$ 是 $`f(x,y)`$ 的极小值。

> **解答（本解答由备考项目编写，非官方答案）**：
>
> **第一步（链式法则表示两个条件）.** 设 $`g_\alpha(t) = f(t\cos\alpha,\ t\sin\alpha)`$，由链式法则
>
> ```math
> \frac{\mathrm{d}g_\alpha(t)}{\mathrm{d}t} = f_x\cos\alpha + f_y\sin\alpha,
> ```
>
> ```math
> \frac{\mathrm{d}^2g_\alpha(t)}{\mathrm{d}t^2} = f_{xx}\cos^2\alpha + 2f_{xy}\cos\alpha\sin\alpha + f_{yy}\sin^2\alpha
> ```
>
> （各偏导数在点 $`(t\cos\alpha, t\sin\alpha)`$ 处取值）。
>
> **第二步（一阶条件 ⇒ 梯度为零）.** 在 $`t = 0`$ 处，条件 $`\dfrac{\mathrm{d}g_\alpha(0)}{\mathrm{d}t} = 0`$ 对一切 $`\alpha`$ 成立：
>
> ```math
> f_x(0,0)\cos\alpha + f_y(0,0)\sin\alpha = 0\quad(\forall\alpha).
> ```
>
> 取 $`\alpha = 0`$ 得 $`f_x(0,0) = 0`$；取 $`\alpha = \dfrac{\pi}{2}`$ 得 $`f_y(0,0) = 0`$。
>
> **第三步（二阶条件 ⇒ 二次型正定）.** 记二次型
>
> ```math
> Q(h,k) = f_{xx}(0,0)h^2 + 2f_{xy}(0,0)hk + f_{yy}(0,0)k^2.
> ```
>
> 对任一单位向量 $`(h,k)`$（取 $`\cos\alpha = h`$，$`\sin\alpha = k`$），由条件 $`\dfrac{\mathrm{d}^2g_\alpha(0)}{\mathrm{d}t^2} > 0`$ 知 $`Q(h,k) > 0`$，即 $`Q`$ 在单位圆 $`h^2 + k^2 = 1`$ 上恒为正。单位圆是紧集、$`Q`$ 连续，故存在常数 $`m > 0`$，使单位圆上恒有 $`Q \geq m`$。由二次型的齐次性，对任意 $`(h,k) \neq (0,0)`$：
>
> ```math
> Q(h,k) = \left(h^2+k^2\right)Q\left(\frac{h}{\rho},\frac{k}{\rho}\right) \geq m\left(h^2+k^2\right),\qquad \rho = \sqrt{h^2+k^2}.
> ```
>
> 即 $`Q`$ 正定。
>
> **第四步（Taylor 展开收尾）.** 由 $`f`$ 二阶偏导连续，在 $`(0,0)`$ 处 Taylor 展开（Peano 余项）：
>
> ```math
> f(h,k) = f(0,0) + f_x(0,0)h + f_y(0,0)k + \frac{1}{2}Q(h,k) + o\left(h^2+k^2\right) = f(0,0) + \frac{1}{2}Q(h,k) + o\left(\rho^2\right).
> ```
>
> 于是当 $`0 < \rho`$ 充分小时，
>
> ```math
> f(h,k) - f(0,0) = \frac{1}{2}Q(h,k) + o(\rho^2) \geq \frac{m}{2}\rho^2 + o(\rho^2) > 0.
> ```
>
> 因此 $`f(0,0)`$ 是 $`f(x,y)`$ 的极小值。$`\blacksquare`$
>
> **方法点评**：本题把"沿任意方向的方向导数"条件翻译成了"梯度为零 + Hessian 二次型正定"，命题的两个条件恰好对应极小值的"一阶必要条件 + 二阶充分条件"。注意"对任何 $`\alpha`$ 一阶导为 0"已包含全部方向信息，不必另设其他条件。

### C1（第10届·五，2018年）多元函数的 Lipschitz 估计 ｜ 难度：中

> （跨专题：另见微分中值定理与不等式专题）

**题目**：设 $`f(x,y)`$ 在区域 $`D`$ 内可微，且

```math
\sqrt{\left(\frac{\partial f}{\partial x}\right)^2 + \left(\frac{\partial f}{\partial y}\right)^2} \le M,
```

$`A(x_1,y_1)`$，$`B(x_2,y_2)`$ 是 $`D`$ 内两点，线段 $`AB`$ 包含在 $`D`$ 内。证明：

```math
\left|f(x_1,y_1) - f(x_2,y_2)\right| \le M\left|AB\right|,
```

其中 $`|AB|`$ 表示线段 $`AB`$ 的长度。

> **解答（官方解答）**：作辅助函数 $`\varphi(t) = f\left(x_1 + t(x_2-x_1),\ y_1 + t(y_2-y_1)\right)`$，……（2 分）
>
> 显然 $`\varphi(t)`$ 在 $`[0,1]`$ 上可导。根据拉格朗日中值定理，存在 $`c \in (0,1)`$，使得
>
> ```math
> \varphi(1) - \varphi(0) = \varphi'(c) = \frac{\partial f(u,v)}{\partial u}(x_2-x_1) + \frac{\partial f(u,v)}{\partial v}(y_2-y_1)
> ```
>
> ……（8 分）
>
> ```math
> \left|\varphi(1)-\varphi(0)\right| = \left|f(x_2,y_2) - f(x_1,y_1)\right| = \left|\frac{\partial f(u,v)}{\partial u}(x_2-x_1) + \frac{\partial f(u,v)}{\partial v}(y_2-y_1)\right|
> ```
>
> ```math
> \le \left[\left(\frac{\partial f(u,v)}{\partial u}\right)^2 + \left(\frac{\partial f(u,v)}{\partial v}\right)^2\right]^{1/2}\left[(x_2-x_1)^2 + (y_2-y_1)^2\right]^{1/2} \le M\left|AB\right|
> ```
>
> ……（14 分）

**编者注**：官方解答中最后一步同时用了柯西不等式与梯度模条件：$`(u,v)`$ 为 $`[A,B]`$ 线段上的某点，$`\left[\left(\dfrac{\partial f}{\partial u}\right)^2+\left(\dfrac{\partial f}{\partial v}\right)^2\right]^{1/2} \le M`$，而 $`\left[(x_2-x_1)^2+(y_2-y_1)^2\right]^{1/2} = |AB|`$。本题结论即"梯度有界的可微函数是 Lipschitz 函数"，是把多元微分的局部信息升级为整体估计的标准范式：**沿线段把多元问题化为单元问题**。

### C2（第13届补赛·三，2021年）Δf 条件下的积分极限 ｜ 难度：难

> （跨专题：另见多元积分学专题）

**题目**：设函数 $`f(x,y)`$ 在闭区域 $`D = \{(x,y) \mid x^2 + y^2 \le 1\}`$ 上具有二阶连续偏导数，且 $`\dfrac{\partial^2 f}{\partial x^2} + \dfrac{\partial^2 f}{\partial y^2} = x^2 + y^2`$，求

```math
\lim_{r\to 0^+}\frac{\displaystyle\iint_{x^2+y^2\le r^2}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y}{(\tan r - \sin r)^2}.
```

> **解答（官方解答）**：【解】 对 $`\forall 0 < r \le 1`$，设 $`D_r := \left\{(x,y) \in R^2 \mid x^2 + y^2 \le r^2\right\}`$，由 Green 公式，得
>
> ```math
> \iint_{D_r}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y = -\frac{1}{2}\iint_{D_r}(x^2 + y^2)\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y
> ```
>
> ```math
> + \frac{1}{2}\int_{\partial D_r} -(x^2 + y^2)\frac{\partial f}{\partial y}\mathrm{d}x + (x^2 + y^2)\frac{\partial f}{\partial x}\mathrm{d}y
> ```
>
> ```math
> = \frac{r^2}{2}\iint_{D_r}\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y - \frac{1}{2}\iint_{D_r}(x^2 + y^2)\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y
> ```
>
> ```math
> = \pi r^2\int_0^r s^3\mathrm{d}s - \pi\int_0^r s^5\mathrm{d}s = \frac{\pi}{4}r^6 - \frac{\pi}{6}r^6 = \frac{\pi}{12}r^6.
> ```
>
> ……（8 分）
> 因此，由 Taylor 公式，得
>
> ```math
> \lim_{r\to 0^+}\frac{\displaystyle\iint_{D_r}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y}{(\tan r - \sin r)^2} = \lim_{r\to 0^+}\frac{\dfrac{\pi}{12}r^6}{\left[\left(r + \dfrac{r^3}{3} + o(r^3)\right) - \left(r - \dfrac{r^3}{3!} + o(r^3)\right)\right]^2}
> ```
>
> ```math
> = \lim_{r\to 0^+}\frac{\dfrac{\pi}{12}r^6}{\dfrac{r^6}{4} + o(r^6)} = \frac{1}{3}\pi.
> ```
>
> ……（6 分）

**编者注**：官方解答两次使用 Green 公式——第一次把 $`\iint\left(xf_x + yf_y\right)`$ 化为 $`-\dfrac{1}{2}\iint(x^2+y^2)\Delta f + \dfrac{1}{2}\oint\left[-(x^2+y^2)f_y\,\mathrm{d}x + (x^2+y^2)f_x\,\mathrm{d}y\right]`$（这是散度形式下"分部积分/Leibniz 恒等式"的二维版本）；边界积分中在 $`\partial D_r`$ 上 $`x^2+y^2 = r^2`$ 可提出，再用一次 Green 公式化回 $`\dfrac{r^2}{2}\iint_{D_r}\Delta f`$。两条路径合并后把 $`f`$ 完全消去，只剩已知的 $`\Delta f = x^2+y^2`$。注意 $`\Delta f`$ 的特殊形式使得结果与 $`f`$ 的具体形状无关——这正是本题设计的巧妙之处。

### C3（第14届·五，2022年）全微分定义 + 交换积分次序求极限 ｜ 难度：难

> （跨专题：另见多元积分学、极限专题）

**题目**：设 $`z = f(x,y)`$ 是区域 $`D = \{(x,y)\mid 0\le x\le 1,\,0\le y\le 1\}`$ 上的可微函数，$`f(0,0) = 0`$，且 $`\mathrm{d}z\big|_{(0,0)} = 3\mathrm{d}x + 2\mathrm{d}y`$，求极限

```math
\lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u}{1-\sqrt[4]{1-x^4}}.
```

> **解答（官方解答）**：【解】 交换二次积分的次序，得
>
> ```math
> \int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u = -\int_0^x\mathrm{d}u\int_0^{u^2}f(t,u)\,\mathrm{d}t. \qquad（3 分）
> ```
>
> 由于 $`f(x,y)`$ 在 $`D`$ 上可微，所以 $`f(x,y)`$ 在点 $`(0,0)`$ 的半径为 1 的扇形域内连续，从而 $`\varphi(u) = \displaystyle\int_0^{u^2}f(t,u)\,\mathrm{d}t`$ 在 $`u = 0`$ 的某邻域内连续，因此
>
> ```math
> I = \lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u}{1-\sqrt[4]{1-x^4}} = \lim_{x\to 0^+}\frac{-\displaystyle\int_0^x\varphi(u)\,\mathrm{d}u}{\dfrac{x^4}{4}} = -\lim_{x\to 0^+}\frac{\varphi(x)}{x^3} = -\lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}f(t,x)\,\mathrm{d}t}{x^3}
> ```
>
> ```math
> = -\lim_{x\to 0^+}\frac{f(\xi,x)x^2}{x^3} = -\lim_{x\to 0^+}\frac{f(\xi,x)}{x},\qquad 0<\xi<x^2. \qquad（6 分）
> ```
>
> 因为 $`\mathrm{d}z\big|_{(0,0)} = 3\mathrm{d}x + 2\mathrm{d}y`$，所以 $`f_x(0,0) = 3`$，$`f_y(0,0) = 2`$。又 $`f(0,0) = 0`$，于是
>
> ```math
> f(\xi,x) = f(0,0) + f_x(0,0)\xi + f_y(0,0)x + o\left(\sqrt{\xi^2+x^2}\right) = 3\xi + 2x + o\left(\sqrt{\xi^2+x^2}\right).
> ```
>
> 注意到 $`0 < \dfrac{\xi}{x} < x`$，故由夹逼准则知 $`\lim\limits_{x\to 0^+}\dfrac{\xi}{x} = 0`$，从而
>
> ```math
> \lim_{x\to 0^+}\frac{o\left(\sqrt{\xi^2+x^2}\right)}{x} = \lim_{x\to 0^+}\frac{o\left(\sqrt{\xi^2+x^2}\right)}{\sqrt{\xi^2+x^2}}\cdot\sqrt{1+\left(\frac{\xi}{x}\right)^2} = 0.
> ```
>
> 所以
>
> ```math
> I = -\lim_{x\to 0^+}\frac{f(\xi,x)}{x} = -\lim_{x\to 0^+}\frac{3\xi + 2x + o\left(\sqrt{\xi^2+x^2}\right)}{x} = -2. \qquad（5 分）
> ```
>

**编者注**：交换次序时注意内层积分 $`\displaystyle\int_x^{\sqrt{t}}`$ 在 $`t < x^2`$（积分区域的绝大部分）时是"反向"区间（$`x > \sqrt{t}`$），这正是官方式子出现负号的原因：把反向区间改回正向（$`\int_x^{\sqrt{t}} = -\int_{\sqrt{t}}^{x}`$）再交换次序，得 $`-\displaystyle\int_0^x\mathrm{d}u\int_0^{u^2}f(t,u)\mathrm{d}t`$。后续用一次积分中值定理（$`\xi \in (0, x^2)`$）与全微分展开 $`f(\xi,x) = 3\xi + 2x + o(\rho)`$；由于 $`0 < \dfrac{\xi}{x} < x \to 0`$ 使 $`\xi`$ 比 $`x`$ 更高阶，最终只剩 $`-2x/x`$ 的贡献，答案为 $`-2`$。
