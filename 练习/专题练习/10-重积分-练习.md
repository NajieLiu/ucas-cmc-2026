## A 组 · 近年真题（第 10-17 届）

### A1（第10届·四，2018年）两球体交叠区域的三重积分 ｜ 难度：难

**题目**：计算三重积分 $\displaystyle\iiint_{(V)}\left(x^2+y^2\right)\mathrm{d}V$，其中 $(V)$ 是由
$$x^2+y^2+(z-2)^2 \ge 4,\quad x^2+y^2+(z-1)^2 \le 9$$
及 $z \ge 0$ 所围成的空间图形。

> **解答（官方解答）**：（1）$(V_1): \begin{cases} x = r\sin\varphi\cos\theta,\ y = r\sin\varphi\sin\theta,\ z-1 = r\cos\varphi \\ 0 \le r \le 3,\ 0 \le \varphi \le \pi,\ 0 \le \theta \le 2\pi \end{cases}$
> $$\iiint_{(V_1)}\left(x^2+y^2\right)\mathrm{d}V = \int_0^{2\pi}\mathrm{d}\theta\int_0^\pi\mathrm{d}\varphi\int_0^3 r^2\sin^2\varphi\cdot r^2\sin\varphi\,\mathrm{d}r = \frac{8}{15}\cdot 3^5\cdot\pi$$
> ……（4 分）
>
> （2）$(V_2): \begin{cases} x = r\sin\varphi\cos\theta,\ y = r\sin\varphi\sin\theta,\ z-2 = r\cos\varphi \\ 0 \le r \le 2,\ 0 \le \varphi \le \pi,\ 0 \le \theta \le 2\pi \end{cases}$
> $$\iiint_{(V_2)}\left(x^2+y^2\right)\mathrm{d}V = \int_0^{2\pi}\mathrm{d}\theta\int_0^\pi\mathrm{d}\varphi\int_0^2 r^2\sin^2\varphi\cdot r^2\sin\varphi\,\mathrm{d}r = \frac{8}{15}\cdot 2^5\cdot\pi$$
> ……（8 分）
>
> （3）$(V_3): \begin{cases} x = r\cos\theta,\ y = r\sin\theta,\ 1-\sqrt{9-r^2} \le z \le 0 \\ 0 \le r \le 2\sqrt{2},\ 0 \le \theta \le 2\pi \end{cases}$
> $$\iiint_{(V_3)}\left(x^2+y^2\right)\mathrm{d}V = \iint_{r\le 2\sqrt{2}} r\,\mathrm{d}r\,\mathrm{d}\theta\int_{1-\sqrt{9-r^2}}^0 r^2\,\mathrm{d}z = \int_0^{2\pi}\mathrm{d}\theta\int_0^{2\sqrt{2}} r^3\left(\sqrt{9-r^2}-1\right)\mathrm{d}r = \left(124 - \frac{2}{5}\cdot 3^5 + \frac{2}{5}\right)\pi$$
>
> $$\iiint_{(V)}\left(x^2+y^2\right)\mathrm{d}V = \iiint_{(V_1)}\left(x^2+y^2\right)\mathrm{d}V - \iiint_{(V_2)}\left(x^2+y^2\right)\mathrm{d}V - \iiint_{(V_3)}\left(x^2+y^2\right)\mathrm{d}V = \frac{256}{3}\pi$$
> ……（12 分）

**编者注**：所求区域是「大球（心 $(0,0,1)$、半径 3）挖去小球（心 $(0,0,2)$、半径 2）、再挖去大球的 $z<0$ 下半部分」：小球恰好切平面 $z=0$ 于原点，故 $z\ge0$ 只对挖去部分有影响——$V_3$ 就是大球在 $z<0$ 的球缺（柱坐标下 $z$ 从 $1-\sqrt{9-r^2}$ 到 $0$）。三段解答最后的数值化简：$\frac{8}{15}(3^5-2^5)\pi-\frac{136}{5}\pi=\frac{256}{3}\pi$。此题是「区域相减分解 + 两种坐标混用」的模板题。

### A2（第11届·二，2019年）曲面 $(x^2+y^2+z^2)^2=2xy$ 围成区域上的三重积分 ｜ 难度：难

**题目**：计算三重积分 $\displaystyle\iiint_\Omega \frac{xyz}{x^2+y^2}\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z$，其中 $\Omega$ 是由曲面 $(x^2+y^2+z^2)^2 = 2xy$ 围成的区域在第一卦限部分。

> **解答（官方解答）**：采用「球面坐标」计算，并利用对称性，得
> $$I = 2\int_0^{\frac{\pi}{4}}\mathrm{d}\theta\int_0^{\frac{\pi}{2}}\mathrm{d}\varphi\int_0^{\sqrt{2}\sin\varphi\sqrt{\sin\theta\cos\theta}} \frac{\rho^3\sin^2\varphi\cos\theta\sin\theta\cos\varphi}{\rho^2\sin^2\varphi}\,\rho^2\sin\varphi\,\mathrm{d}\rho$$
> ……（5 分）
> $$= 2\int_0^{\frac{\pi}{4}}\sin\theta\cos\theta\,\mathrm{d}\theta\int_0^{\frac{\pi}{2}}\sin\varphi\cos\varphi\,\mathrm{d}\varphi\int_0^{\sqrt{2}\sin\varphi\sqrt{\sin\theta\cos\theta}}\rho^3\,\mathrm{d}\rho$$
> $$= 2\int_0^{\frac{\pi}{4}}\sin^3\theta\cos^3\theta\,\mathrm{d}\theta\int_0^{\frac{\pi}{2}}\sin^5\varphi\cos\varphi\,\mathrm{d}\varphi$$
> ……（10 分）
> $$= \frac{1}{4}\int_0^{\frac{\pi}{4}}\sin^3 2\theta\,\mathrm{d}\theta\int_0^{\frac{\pi}{2}}\sin^5\varphi\,\mathrm{d}(\sin\varphi)$$
> $$= \frac{1}{48}\int_0^{\frac{\pi}{2}}\sin^3 t\,\mathrm{d}t = \frac{1}{48}\cdot\frac{2}{3} = \frac{1}{72}.$$
> ……（14 分）

**编者注**：两道关键方程——曲面的球坐标方程：$\rho^4 = 2\rho^2\sin^2\varphi\sin\theta\cos\theta$，即 $\rho = \sqrt{2}\sin\varphi\sqrt{\sin\theta\cos\theta}$；被积函数：$\frac{xyz}{x^2+y^2} = \rho\sin\varphi\cos\theta\sin\theta\cos\varphi$。第一卦限中 $\theta\in[0,\tfrac{\pi}{2}]$，被积函数与半径极限关于 $\theta=\tfrac{\pi}{4}$ 对称，故写 $2\int_0^{\pi/4}$ 并把 $\theta$ 限制在半区间。最后一步 $\int_0^{\pi/4}\sin^3 2\theta\,\mathrm{d}\theta = \frac{1}{2}\int_0^{\pi/2}\sin^3 t\,\mathrm{d}t = \frac{1}{3}$，$\int_0^{\pi/2}\sin^5\varphi\,\mathrm{d}(\sin\varphi) = \frac{1}{6}$，乘积 $\times\frac{1}{4}$ 得 $\frac{1}{72}$。

### A3（第12届·一(4)，2020年）无穷区域上的二重积分换元 ｜ 难度：中

**题目**：已知 $\displaystyle\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x = \frac{\pi}{2}$，则 $\displaystyle\int_0^{+\infty}\!\!\int_0^{+\infty}\frac{\sin x\sin(x+y)}{x(x+y)}\,\mathrm{d}x\mathrm{d}y = \underline{\qquad}$。

> **解答（官方解答）**：令 $u = x+y$，得
> $$I = \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_0^{+\infty}\frac{\sin(x+y)}{x+y}\,\mathrm{d}y = \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_x^{+\infty}\frac{\sin u}{u}\,\mathrm{d}u$$
> $$= \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\left(\int_0^{+\infty}\frac{\sin u}{u}\,\mathrm{d}u - \int_0^x\frac{\sin u}{u}\,\mathrm{d}u\right) = \left(\int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\right)^2 - \int_0^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x\int_0^x\frac{\sin u}{u}\,\mathrm{d}u.$$
> 令 $F(x) = \displaystyle\int_0^x\frac{\sin u}{u}\,\mathrm{d}u$，则 $F'(x) = \dfrac{\sin x}{x}$，$\lim\limits_{x\to+\infty}F(x) = \dfrac{\pi}{2}$，所以
> $$I = \frac{\pi^2}{4} - \int_0^{+\infty}F(x)F'(x)\,\mathrm{d}x = \frac{\pi^2}{4} - \left.\frac{1}{2}[F(x)]^2\right|_0^{+\infty} = \frac{\pi^2}{4} - \frac{1}{2}\left(\frac{\pi}{2}\right)^2 = \frac{\pi^2}{8}.$$

**答案**：$\dfrac{\pi^2}{8}$。

**编者注**：本题是「二重积分化一元已知积分」的典范：对 $y$ 作换元 $u=x+y$ 把内层积分变成 $\int_x^{+\infty}\frac{\sin u}{u}\mathrm{d}u$，再用 $\int_x^\infty = \int_0^\infty - \int_0^x$ 拆项，最终出现 $F(x)F'(x)$ 型凑微分。命题信号：被积函数形如 $\frac{\sin x}{x}\cdot\frac{\sin(x+y)}{x+y}$、积分区域为第一象限——优先考虑 $u=x+y$ 换元。

### A4（第13届·一(5)，2021年）圆域上的二重积分（对称性 + 极坐标） ｜ 难度：中

**题目**：记 $D=\{(x,y)\,|\,x^2+y^2\leq\pi\}$，则 $\displaystyle\iint_D\left(\sin x^2\cos y^2+x\sqrt{x^2+y^2}\right)\mathrm{d}x\mathrm{d}y=\underline{\qquad}$。

> **解答（官方解答）**：根据重积分的对称性，得
> $$\text{原式}=\iint_D\sin x^2\cos y^2\,\mathrm{d}x\mathrm{d}y=\iint_D\sin y^2\cos x^2\,\mathrm{d}x\mathrm{d}y$$
> $$=\frac{1}{2}\iint_D\left(\sin x^2\cos y^2+\sin y^2\cos x^2\right)\mathrm{d}x\mathrm{d}y$$
> $$=\frac{1}{2}\iint_D\sin(x^2+y^2)\,\mathrm{d}x\mathrm{d}y=\frac{1}{2}\int_0^{2\pi}\mathrm{d}\theta\int_0^{\sqrt{\pi}}r\sin r^2\,\mathrm{d}r$$
> $$=\frac{\pi}{2}\left.(-\cos r^2)\right|_0^{\sqrt{\pi}}=\pi.$$

**答案**：$\pi$。

**编者注**：两步对称性——① 第二项 $x\sqrt{x^2+y^2}$ 关于 $x$ 为奇函数、$D$ 关于 $y$ 轴对称，积分为 0；② 第一项在 $x\leftrightarrow y$ 轮换下区域 $D$ 不变，与轮换后的 $\sin y^2\cos x^2$ 相加得 $\sin(x^2+y^2)$（用和角公式），再换极坐标。这是「奇偶砍项 + 轮换对称配对」的标准流程。

### A5（第14届·一(5)，2022年）斜带形区域上的二重积分 ｜ 难度：中

**题目**：记 $D = \left\{(x,y)\,\middle|\,0\le x+y\le\dfrac{\pi}{2},\,0\le x-y\le\dfrac{\pi}{2}\right\}$，则
$$\iint_D y\sin(x+y)\,\mathrm{d}x\mathrm{d}y = \underline{\qquad}.$$

> **解答（官方解答）**（方法 1）利用三角公式：$\sin(x+y) = \sin x\cos y + \cos x\sin y$，并根据重积分的对称性，得
> 原式 $= 2\displaystyle\int_0^{\frac{\pi}{4}}y\sin y\,\mathrm{d}y\int_y^{\frac{\pi}{2}-y}\cos x\,\mathrm{d}x = 2\int_0^{\frac{\pi}{4}}y\sin y(\cos y-\sin y)\,\mathrm{d}y$
> $$= \int_0^{\frac{\pi}{4}}y\sin 2y\,\mathrm{d}y + \int_0^{\frac{\pi}{4}}y\cos 2y\,\mathrm{d}y - \int_0^{\frac{\pi}{4}}y\,\mathrm{d}y$$
> $$= \frac{1}{4} + \left(\frac{\pi}{8}-\frac{1}{4}\right) - \frac{\pi^2}{32} = \frac{\pi}{8} - \frac{\pi^2}{32}.$$
>
> （方法 2）利用二元变量替换，令 $\begin{cases}u = x+y, \\ v = x-y,\end{cases}$ 则 $\begin{cases}x = \dfrac{1}{2}(u+v) \\ y = \dfrac{1}{2}(u-v)\end{cases}$。因为
> $$J = \begin{vmatrix}\dfrac{\partial x}{\partial u} & \dfrac{\partial x}{\partial v} \\[6pt] \dfrac{\partial y}{\partial u} & \dfrac{\partial y}{\partial v}\end{vmatrix} = \begin{vmatrix}\dfrac{1}{2} & \dfrac{1}{2} \\[6pt] \dfrac{1}{2} & -\dfrac{1}{2}\end{vmatrix} = -\frac{1}{2},$$
> 所以
> 原式 $= |J|\displaystyle\int_0^{\frac{\pi}{2}}\int_0^{\frac{\pi}{2}}\frac{1}{2}(u-v)\sin u\,\mathrm{d}u\mathrm{d}v = \frac{1}{4}\int_0^{\frac{\pi}{2}}\mathrm{d}v\int_0^{\frac{\pi}{2}}u\sin u\,\mathrm{d}u - \frac{1}{4}\int_0^{\frac{\pi}{2}}v\,\mathrm{d}v\int_0^{\frac{\pi}{2}}\sin u\,\mathrm{d}u$
> $$= \frac{1}{4}\times\frac{\pi}{2}\times 1 - \frac{1}{4}\times\frac{\pi^2}{8}\times 1 = \frac{\pi}{8} - \frac{\pi^2}{32}.$$

**答案**：$\dfrac{\pi}{8} - \dfrac{\pi^2}{32}$。

**编者注**：区域 $D$ 是四条直线 $x\pm y = 0,\ \tfrac{\pi}{2}$ 围成的正方形（在原坐标下是斜置的），方法 2 的 $u = x+y,\ v = x-y$ 换元是「带角区域」的第一反应，直接把域拉直成 $[0,\tfrac{\pi}{2}]^2$；方法 1 则利用被积函数与区域在 $(x,y)\to(-y,-x)$ 下的对称性砍掉一半再累次积分。两条路都要会。

### A6（第15届·三，2023年）圆锥面与椭球面所围体积 ｜ 难度：中

> （跨专题：另见空间解析几何专题——旋转曲面与切线）

**题目**：设 $\Sigma_1$ 是以 $(0,4,0)$ 为顶点且与曲面 $\Sigma_2: \dfrac{x^2}{3}+\dfrac{y^2}{4}+\dfrac{z^2}{3}=1\ (y>0)$ 相切的圆锥面, 求曲面 $\Sigma_1$ 与 $\Sigma_2$ 所围成的空间区域的体积.

> **解答（官方解答）**：设 $L$ 是 $xOy$ 平面上过点 $(0,4)$ 且与 $\dfrac{x^2}{3}+\dfrac{y^2}{4}=1$ 相切于点 $(x_0,y_0)$ 的直线, 则
> $$\frac{x_0^2}{3}+\frac{y_0^2}{4} = 1 \ \text{且切线斜率}\ \frac{y_0-4}{x_0} = -\frac{4x_0}{3y_0}, \ \text{解得}\ x_0 = \pm\frac{3}{2},\, y_0 = 1.$$
> ……（5 分）
>
> 显然, $\Sigma_1$ 与 $\Sigma_2$ 分别是切线 $L$ 和曲线 $\dfrac{x^2}{3}+\dfrac{y^2}{4}=1$ 绕 $y$ 轴旋转而成的曲面, 它们的交线位于平面 $y_0 = 1$ 上. ……（8 分）
>
> 记该平面与 $\Sigma_1$, $\Sigma_2$ 围成的空间区域分别记为 $\Omega_1$ 和 $\Omega_2$.
>
> 由于 $\Sigma_1$ 是底面圆的半径为 $\dfrac{3}{2}$, 高为 3 的圆锥体, 所以其体积 $V_1 = \dfrac{1}{3}\cdot\pi\cdot\left(\dfrac{3}{2}\right)^2\cdot 3 = \dfrac{9\pi}{4}$. 又 $\Omega_2$ 的体积为
> $$V_2 = \iiint_{\Omega_2}\mathrm{d}V = \int_1^2 \mathrm{d}y\iint_{x^2+z^2 \leqslant 3\left(1-\frac{y^2}{4}\right)}\mathrm{d}x\,\mathrm{d}z = \pi\int_1^2 3\left(1-\frac{y^2}{4}\right)\mathrm{d}y = \frac{5\pi}{4}.$$
> 因此, 曲面 $\Sigma_1$ 与 $\Sigma_2$ 所围成的空间区域的体积为 $\dfrac{9\pi}{4}-\dfrac{5\pi}{4} = \pi$. ……（14 分）

**答案**：$\pi$。

**编者注**：切点也可用切线方程 $\frac{x_0x}{3}+\frac{y_0y}{4}=1$ 过点 $(0,4)$ 直接得 $y_0=1$，再回代入椭球方程得 $x_0=\pm\frac{3}{2}$，比斜率条件更快。体积计算的关键：两个曲面都是绕 $y$ 轴的旋转曲面，交线落在 $y=1$，故区域可分解为「圆锥体（截面半径 $r=\frac{3}{2}\cdot\frac{4-y}{3}$）减去椭球段」——后者用切片法（先二后一，截面为圆 $x^2+z^2\le 3(1-\frac{y^2}{4})$）一击而中。

### A7（第16届·一(2)，2024年）二重积分与极限（极坐标 + Taylor） ｜ 难度：中

**题目**：设 $D: x^2+y^2 \leqslant r^2$，其中 $r > 0$。则
$$\lim_{r\to 0^+}\frac{\displaystyle\iint_D \left(\mathrm{e}^{x^2+y^2}-1\right)\mathrm{d}x\,\mathrm{d}y}{r^4} = \underline{\qquad}.$$

> **解答（官方解答）**：利用极坐标变换 $x = \rho\cos\theta$，$y = \rho\sin\theta$，则
> $$\iint_D \left(\mathrm{e}^{x^2+y^2}-1\right)\mathrm{d}x\,\mathrm{d}y = 2\pi\int_0^r \left(\mathrm{e}^{\rho^2}-1\right)\rho\,\mathrm{d}\rho = \pi\left(\mathrm{e}^{r^2}-1-r^2\right).$$
> 注意，$r \to 0^+$ 时，$\mathrm{e}^{r^2}-1-r^2 = \dfrac{r^4}{2} + o(r^4)$，故原式 $= \dfrac{\pi}{2}$。

**答案**：$\dfrac{\pi}{2}$。

**编者注**：标准流水线——极坐标后内层积分的原函数是 $\frac{1}{2}\mathrm{e}^{\rho^2}-\frac{\rho^2}{2}$（由 $\int(\mathrm{e}^{\rho^2}-1)\rho\,\mathrm{d}\rho$ 换元 $t=\rho^2$ 得 $=\frac{1}{2}(\mathrm{e}^{r^2}-1-r^2)$），再用 Taylor 展开比较阶数。「区域半径区域上积分的极限」是近年来填补空的固定套路（另见 A4、C1）。

### A8（第17届·四，2025年）三重积分·先二后一 ｜ 难度：中

**题目**：设 $\Omega$ 是由平面 $\Pi_1: x = 0$，$\Pi_2: x = y$，$\Pi_3: y = z$，$\Pi_4: z = 1$，$\Pi_5: z = 2$ 围成的空间区域，求三重积分
$$\iiint_\Omega \frac{\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z}{\sqrt{y^2 + z^2}}.$$

> **解答（官方解答）**：采用**先二后一法**。设 $1 \leqslant z \leqslant 2$，用平面 $Z = z$ 截 $\Omega$ 得平面区域：$D_z = \{(x,y) \mid 0 \leqslant x \leqslant z,\ 0 \leqslant y \leqslant x\}$，则
> $$\iiint_\Omega \frac{\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z}{\sqrt{y^2+z^2}} = \int_1^2 \mathrm{d}z \iint_{D_z}\frac{\mathrm{d}x\,\mathrm{d}y}{\sqrt{y^2+z^2}}.$$
> ……（5 分）
> $$= \int_1^2 \mathrm{d}z \int_0^z \mathrm{d}y \int_0^y \frac{\mathrm{d}x}{\sqrt{y^2+z^2}} = \int_1^2 \mathrm{d}z \int_0^z \frac{y}{\sqrt{y^2+z^2}}\,\mathrm{d}y$$
> ……（10 分）
> $$= \int_1^2 \left.\sqrt{y^2+z^2}\right|_0^z \mathrm{d}z = (\sqrt{2}-1)\int_1^2 z\,\mathrm{d}z = \frac{3(\sqrt{2}-1)}{2}.$$
> ……（14 分）

**答案**：$\dfrac{3(\sqrt{2}-1)}{2}$。

**编者注**：切片方向的选择信号——被积函数 $1/\sqrt{y^2+z^2}$ 不含 $x$，且先对 $x$ 积分只贡献长度因子，剩下 $y\,\mathrm{d}y/\sqrt{y^2+z^2}$ 可直接凑微分。区域理解：$z\in[1,2]$ 上截得三角形 $0\le y\le x\le z$；另一个方向（先一后二）会出现难以处理的 $\ln$ 型积分，故切片法是最优路线。

### B1（第1届·一(1)，2009年）三角形区域上的二重积分换元 ｜ 难度：中

**题目**：计算 $\displaystyle\iint_D \frac{(x+y)\ln\left(1+\dfrac{y}{x}\right)}{\sqrt{1-x-y}}\,\mathrm{d}x\,\mathrm{d}y = \underline{\qquad}$，其中区域 $D$ 由直线 $x + y = 1$ 与两坐标轴所围三角形区域。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> 被积函数中同时出现 $x+y$、$\dfrac{y}{x}$ 与 $1-x-y$，提示作换元
> $$u = x+y,\qquad v = \frac{y}{x},$$
> 其逆变换为 $x = \dfrac{u}{1+v},\ y = \dfrac{uv}{1+v}$，区域 $D$ 对应于 $0\le u\le 1,\ 0\le v<+\infty$。雅可比行列式为
> $$\left|\frac{\partial(x,y)}{\partial(u,v)}\right| = \left|\begin{vmatrix}\dfrac{1}{1+v} & -\dfrac{u}{(1+v)^2}\\[6pt] \dfrac{v}{1+v} & \dfrac{u}{(1+v)^2}\end{vmatrix}\right| = \frac{u}{(1+v)^2}.$$
> 此时 $x+y = u$，$\ln\left(1+\dfrac{y}{x}\right) = \ln(1+v)$，$\dfrac{1}{\sqrt{1-x-y}} = \dfrac{1}{\sqrt{1-u}}$，于是
> $$I = \int_0^1\!\!\int_0^{+\infty} \frac{u\ln(1+v)}{\sqrt{1-u}}\cdot\frac{u}{(1+v)^2}\,\mathrm{d}v\,\mathrm{d}u = \left(\int_0^1 \frac{u^2}{\sqrt{1-u}}\,\mathrm{d}u\right)\left(\int_0^{+\infty}\frac{\ln(1+v)}{(1+v)^2}\,\mathrm{d}v\right).$$
> 第一个积分（令 $t = 1-u$）：
> $$\int_0^1 \frac{u^2}{\sqrt{1-u}}\,\mathrm{d}u = \int_0^1 \frac{(1-t)^2}{\sqrt{t}}\,\mathrm{d}t = \int_0^1\left(t^{-1/2}-2t^{1/2}+t^{3/2}\right)\mathrm{d}t = 2-\frac{4}{3}+\frac{2}{5} = \frac{16}{15}.$$
> 第二个积分（令 $w = 1+v$，分部积分）：
> $$\int_0^{+\infty}\frac{\ln(1+v)}{(1+v)^2}\,\mathrm{d}v = \int_1^{+\infty}\frac{\ln w}{w^2}\,\mathrm{d}w = \left[-\frac{\ln w+1}{w}\right]_1^{+\infty} = 1.$$
> 因此 $I = \dfrac{16}{15}\times 1 = \dfrac{16}{15}$。
>
> **答案**：$\dfrac{16}{15}$。

**编者注**：换元的选取逻辑——$\sqrt{1-x-y}$ 指向 $u=x+y$，$\ln(1+y/x)$ 指向 $v=y/x$，两者恰好使雅可比行列式分解为 $\frac{u}{(1+v)^2}$，整个二重积分裂成两个一元积分。参考答案另用 $u=\sqrt{1-x-y},\ v=1+\frac{y}{x}$，化为 $2\int_0^1(1-u^2)^2\mathrm{d}u\int_1^{+\infty}\frac{\ln v}{v^2}\mathrm{d}v$，答案同为 $\frac{16}{15}$。

### B2（第2届·第五题，2010年）椭球绕任意方向轴的转动惯量 ｜ 难度：难

**题目**：设 $l$ 是过原点、方向为 $(\alpha, \beta, \gamma)$（其中 $\alpha^2 + \beta^2 + \gamma^2 = 1$）的直线，均匀椭球
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} \leqslant 1$$
（其中 $0 < c < b < a$，密度为 1）绕 $l$ 旋转。

**(1)** 求其转动惯量；

**(2)** 求其转动惯量关于方向 $(\alpha, \beta, \gamma)$ 的最大值和最小值。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> **(1)** 记椭球区域为 $E$，单位方向向量 $\mathbf{n}=(\alpha,\beta,\gamma)$。点 $(x,y,z)$ 到直线 $l$ 的距离平方为
> $$d^2 = x^2+y^2+z^2-(\alpha x+\beta y+\gamma z)^2,$$
> 转动惯量为
> $$J = \iiint_E d^2\,\mathrm{d}V = \iiint_E\left(x^2+y^2+z^2\right)\mathrm{d}V - \iiint_E(\alpha x+\beta y+\gamma z)^2\,\mathrm{d}V.$$
> 作换元 $x = au,\ y = bv,\ z = cw$，把 $E$ 变为单位球 $B$，则 $\mathrm{d}x\mathrm{d}y\mathrm{d}z = abc\,\mathrm{d}u\mathrm{d}v\mathrm{d}w$，且
> $$\iiint_E x^2\,\mathrm{d}V = a^2\cdot abc\iiint_B u^2\,\mathrm{d}V = \frac{4\pi}{15}a^3bc,$$
> 其中用到 $\iiint_B(u^2+v^2+w^2)\mathrm{d}V = \int_0^1 r^2\cdot 4\pi r^2\mathrm{d}r = \frac{4\pi}{5}$ 及轮换对称 $\iiint_B u^2 = \frac{1}{3}\cdot\frac{4\pi}{5} = \frac{4\pi}{15}$。同理 $\iiint_E y^2\mathrm{d}V = \frac{4\pi}{15}ab^3c$，$\iiint_E z^2\mathrm{d}V = \frac{4\pi}{15}abc^3$。
> 对第二项展开：交叉项如 $\iiint_E xy\,\mathrm{d}V = 0$（区域关于平面 $x=0$ 对称），故
> $$\iiint_E(\alpha x+\beta y+\gamma z)^2\mathrm{d}V = \frac{4\pi}{15}abc\left(a^2\alpha^2+b^2\beta^2+c^2\gamma^2\right).$$
> 于是
> $$J = \frac{4\pi abc}{15}\left[(a^2+b^2+c^2)-\left(a^2\alpha^2+b^2\beta^2+c^2\gamma^2\right)\right].$$
>
> **(2)** 记 $F = a^2\alpha^2+b^2\beta^2+c^2\gamma^2$，利用 $\alpha^2+\beta^2+\gamma^2=1$ 配方：
> $$F = c^2+(a^2-c^2)\alpha^2+(b^2-c^2)\beta^2.$$
> 因 $a^2>c^2,\ b^2>c^2$，在约束 $\alpha^2+\beta^2\le 1$ 下得 $c^2\le F\le c^2+(a^2-c^2)=a^2$：左端等号在 $(\alpha,\beta,\gamma)=(0,0,\pm 1)$ 取到，右端等号在 $(\pm 1,0,0)$ 取到。因此
> $$J_{\max} = \frac{4\pi abc}{15}\left(a^2+b^2+c^2-c^2\right) = \frac{4\pi abc}{15}(a^2+b^2),$$
> 绕**短轴**（$z$ 轴）时转动惯量最大；
> $$J_{\min} = \frac{4\pi abc}{15}\left(a^2+b^2+c^2-a^2\right) = \frac{4\pi abc}{15}(b^2+c^2),$$
> 绕**长轴**（$x$ 轴）时转动惯量最小。
>
> **答案**：(1) $J = \dfrac{4\pi abc}{15}\left[(a^2+b^2+c^2)-\left(a^2\alpha^2+b^2\beta^2+c^2\gamma^2\right)\right]$；(2) 最大值 $\dfrac{4\pi abc}{15}(a^2+b^2)$（方向 $(0,0,\pm 1)$），最小值 $\dfrac{4\pi abc}{15}(b^2+c^2)$（方向 $(\pm 1,0,0)$）。

**编者注**：核对口径——普通物理中转动惯量 $I = \iiint r_\perp^2\,\rho\,\mathrm{d}V$，密度 $\rho=1$ 时即题中的 $J$。绕坐标轴的现成结论可作快速核算：$I_x = \frac{m}{5}(b^2+c^2) = \frac{4\pi abc}{15}(b^2+c^2)$（$m$ 为椭球体积）。条件极值不必上 Lagrange 乘子法：配方成 $c^2+(a^2-c^2)\alpha^2+(b^2-c^2)\beta^2$ 后，最大值最小值一目了然。

### B3（第3届·一(3)，2011年）符号函数二重积分（分区域） ｜ 难度：中

**题目**：求 $\displaystyle\iint_D \operatorname{sgn}(xy-1)\,\mathrm{d}x\,\mathrm{d}y$，其中 $D = \{(x,y) \mid 0 \leqslant x \leqslant 2,\ 0 \leqslant y \leqslant 2\}$。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> $\operatorname{sgn}(xy-1)$ 在 $xy>1$ 处取 $1$，在 $xy<1$ 处取 $-1$，在双曲线 $xy=1$ 上取 $0$（零测集不影响积分值）。把 $D$ 用双曲线分割：记
> $$S_- = \iint_{\{xy\le 1\}\cap D}\mathrm{d}x\mathrm{d}y,\qquad S_+ = \iint_{\{xy\ge 1\}\cap D}\mathrm{d}x\mathrm{d}y,\qquad S_-+S_+ = 4.$$
> 求 $S_-$：当 $0\le x\le \frac{1}{2}$ 时 $xy\le 2\cdot\frac{1}{2}=1$ 恒成立，$y$ 可取遍 $[0,2]$；当 $\frac{1}{2}\le x\le 2$ 时 $y\in\left[0,\frac{1}{x}\right]$。故
> $$S_- = \frac{1}{2}\cdot 2+\int_{\frac{1}{2}}^{2}\frac{1}{x}\,\mathrm{d}x = 1+\ln 2-\ln\frac{1}{2} = 1+2\ln 2.$$
> 于是 $S_+ = 4-(1+2\ln 2) = 3-2\ln 2$，所求积分
> $$\iint_D \operatorname{sgn}(xy-1)\,\mathrm{d}x\,\mathrm{d}y = S_+-S_- = (3-2\ln 2)-(1+2\ln 2) = 2-4\ln 2.$$
>
> **答案**：$2-4\ln 2$（$\approx -0.773$，负值合理：$\{xy<1\}$ 的面积大于 $\{xy>1\}$）。

**编者注**：分割区域的边界是双曲线——注意 $x=\frac{1}{2}$ 这个分点（双曲线与上边界 $y=2$ 的交点横坐标），漏掉它会错算 $S_-$。校验：$S_++S_- = (3-2\ln2)+(1+2\ln2) = 4$ ✓。

### B4（第4届·第六题，2012年）变域三重积分 $F(t)$ 的导数 ｜ 难度：难

> （跨专题：另见多元函数微分学专题——含参变限积分的求导）

**题目**：设 $f(x)$ 为连续函数，$t > 0$。$\Omega$ 是由抛物面 $z = x^2 + y^2$ 和球面 $x^2 + y^2 + z^2 = t^2\,(t > 0)$ 所围成起来的部分。定义
$$F(t) = \iiint_\Omega f\left(x^2 + y^2 + z^2\right)\mathrm{d}V,$$
求 $F'(t)$。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> **区域理解**：$\Omega$ 取「抛物面在下、球面在上」的冰激凌形区域，即
> $$\Omega_t = \left\{(x,y,z): x^2+y^2\le z,\ x^2+y^2+z^2\le t^2\right\}.$$
> 记 $\rho^2 = x^2+y^2$，由 $\rho^2\le z$ 与 $\rho^2+z^2\le t^2$ 得 $\rho^4+\rho^2\le t^2$，故 $\Omega_t$ 在 $xOy$ 面上的投影为 $\rho^2\le z_0$，其中
> $$z_0 = z_0(t) = \frac{\sqrt{1+4t^2}-1}{2}\qquad\left(z_0^2+z_0 = t^2,\ 0<z_0<t\right),$$
> 两曲面的交线是柱面 $\rho^2 = z_0$ 上的圆周 $\{z = z_0\}$。
>
> **解法一（先二后一 + 含参变限求导）**：用柱坐标把 $F(t)$ 写成
> $$F(t) = 2\pi\int_0^{\sqrt{z_0}} r\,\mathrm{d}r\int_{r^2}^{\sqrt{t^2-r^2}} f\left(r^2+z^2\right)\mathrm{d}z.$$
> 对 $t$ 求导：积分上限 $\sqrt{z_0}$ 处的边界项为 $2\pi\sqrt{z_0}\int_{z_0}^{z_0}f\,\mathrm{d}z\cdot\frac{\mathrm{d}\sqrt{z_0}}{\mathrm{d}t} = 0$（因为 $z_0+z_0^2 = t^2$ 使 $r = \sqrt{z_0}$ 时内层积分上下限同为 $z_0$），仅内层上限贡献：
> $$F'(t) = 2\pi\int_0^{\sqrt{z_0}} r\cdot f\left(t^2\right)\cdot\frac{t}{\sqrt{t^2-r^2}}\,\mathrm{d}r = 2\pi t\,f(t^2)\int_0^{\sqrt{z_0}}\frac{r}{\sqrt{t^2-r^2}}\,\mathrm{d}r.$$
> 而 $\int_0^{\sqrt{z_0}}\frac{r\,\mathrm{d}r}{\sqrt{t^2-r^2}} = \left[-\sqrt{t^2-r^2}\right]_0^{\sqrt{z_0}} = t-\sqrt{t^2-z_0}$，又 $\sqrt{t^2-z_0} = z_0$（由 $z_0^2+z_0 = t^2$），故
> $$F'(t) = 2\pi t\left(t-z_0\right)f(t^2).$$
>
> **解法二（球壳增量法）**：把 $t$ 增大到 $t+\Delta t$，新增部分位于球壳 $t\le r\le t+\Delta t$ 内、且只在「球面为外边界」的方向上（设与 $z$ 轴夹角为 $\theta$）：由 $r\cos\theta\ge r^2\sin^2\theta$ 的临界条件 $t\cos\theta = t^2\sin^2\theta$ 解得 $\cos\theta_t = z_0/t$。由积分中值，$F(t+\Delta t)-F(t) = 2\pi(1-\cos\alpha)\int_t^{t+\Delta t}f(r^2)r^2\,\mathrm{d}r$（$\alpha\in[\theta_{t+\Delta t},\theta_t]$），除以 $\Delta t$ 并令 $\Delta t\to 0$（左、右导数同法），得
> $$F'(t) = 2\pi\left(1-\frac{z_0}{t}\right)t^2f(t^2) = 2\pi t(t-z_0)f(t^2).$$
> 两种解法一致。把 $z_0 = \frac{\sqrt{1+4t^2}-1}{2}$ 代入：
> $$F'(t) = 2\pi t\left(t-\frac{\sqrt{1+4t^2}-1}{2}\right)f(t^2) = \pi t\left(2t+1-\sqrt{1+4t^2}\right)f(t^2).$$
>
> **答案**：$F'(t) = \pi t\left(2t+1-\sqrt{1+4t^2}\right)f(t^2)$，等价形式 $2\pi t\left(t-z_0\right)f(t^2)$，$z_0 = \dfrac{\sqrt{1+4t^2}-1}{2}$。

**编者注**：快速自检（$f\equiv 1$ 时 $F(t)$ 即区域体积）：$F(t) = \pi\left[\frac{2}{3}t^3-t^2z_0+\frac{z_0^2}{2}+\frac{z_0^3}{3}\right]$，利用 $z_0^2+z_0 = t^2$ 求导得 $F'(t) = 2\pi t(t-z_0)$，与上一致。**注意**：网络流传的部分参考解答把结果误印为 $\pi(2t+1-\sqrt{1+4t^2})f(t^2)$（漏乘因子 $t$），用上面的 $f\equiv1$ 体积检验即可识破（例如 $t=2$ 时正确值为 $2\pi\cdot2\cdot(2-\frac{\sqrt{17}-1}{2})\approx 5.51$）。

### B5（第7届·一(3)，2015年）切平面与抛物面所围体积 ｜ 难度：易

**题目**：曲面 $z=x^2+y^2+1$ 在点 $M(1,-1,3)$ 的切平面与曲面 $z=x^2+y^2$ 所围区域的体积为 $\underline{\qquad}$。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> 记 $z_1 = x^2+y^2+1$，则 $z_{1x} = 2x,\ z_{1y} = 2y$，在 $M(1,-1,3)$ 处 $z_{1x} = 2,\ z_{1y} = -2$，切平面方程为
> $$z-3 = 2(x-1)-2(y+1),\qquad \text{即}\qquad z = 2x-2y-1.$$
> 切平面与抛物面 $z = x^2+y^2$ 的交线在 $xOy$ 面上的投影为
> $$x^2+y^2 = 2x-2y-1\iff (x-1)^2+(y+1)^2 = 1,$$
> 记该单位圆盘为 $D$（圆心 $(1,-1)$）。在 $D$ 内，
> $$(2x-2y-1)-\left(x^2+y^2\right) = 1-(x-1)^2-(y+1)^2\ge 0,$$
> 即切平面在抛物面之上，所求体积
> $$V = \iint_D\left[1-(x-1)^2-(y+1)^2\right]\mathrm{d}x\mathrm{d}y.$$
> 作平移 $u = x-1,\ v = y+1$（雅可比为 1），再化为极坐标：
> $$V = \iint_{u^2+v^2\le 1}\left(1-u^2-v^2\right)\mathrm{d}u\mathrm{d}v = \int_0^{2\pi}\mathrm{d}\theta\int_0^1\left(1-r^2\right)r\,\mathrm{d}r = 2\pi\left(\frac{1}{2}-\frac{1}{4}\right) = \frac{\pi}{2}.$$
>
> **答案**：$\dfrac{\pi}{2}$。

**编者注**：这类「切平面与曲面围成的体积」的标准流程：切平面方程 → 交线投影（一般是圆）→ 在投影圆盘上积「两曲面之差」。本题的结构密码：$M$ 处的切平面恰好是 $z=x^2+y^2$ 在 $(1,-1)$ 处的切平面 $z=2x-2y-2$ 沿 $z$ 方向**平移 1 个单位**所得，平移后差式为 $1-u^2-v^2$——所以该体积与「$z=x^2+y^2$ 被平面 $z=1$ 截出的抛物面帽」体积相同（同为 $\frac{\pi}{2}$），可用「$\frac{1}{2}\pi r^2 \cdot h$，$r=h=1$」快速心算。

### B6（第7届·第六题，2015年）二重积分的估计不等式 ｜ 难度：难

> （跨专题：另见多元函数微分学专题——二阶泰勒展开）

**题目**：设 $f(x,y)$ 在 $x^2+y^2\le 1$ 上有连续的二阶导数，$f_{xx}^2+2f_{xy}^2+f_{yy}^2\le M$。若
$$f(0,0)=f_x(0,0)=f_y(0,0)=0,$$
证明：
$$\left|\iint_{x^2+y^2\le 1} f(x,y)\,\mathrm{d}x\,\mathrm{d}y\right|\le\dfrac{\pi\sqrt{M}}{4}.$$

> **解答**：（本解答由备考项目编写，非官方答案）
>
> 由 $f(0,0) = f_x(0,0) = f_y(0,0) = 0$，对 $f$ 在原点作带 Lagrange 余项的二阶泰勒展开：对任意 $(x,y)\in x^2+y^2\le 1$，存在 $\theta\in(0,1)$，使
> $$f(x,y) = \frac{1}{2}\left[x^2f_{xx}(\theta x,\theta y)+2xyf_{xy}(\theta x,\theta y)+y^2f_{yy}(\theta x,\theta y)\right].$$
> 记 $(u,v,w) = \left(f_{xx},f_{xy},f_{yy}\right)(\theta x,\theta y)$，则 $f(x,y) = \frac{1}{2}\left(ux^2+2vxy+wy^2\right)$。由 Cauchy–Schwarz 不等式，
> $$\left|ux^2+2vxy+wy^2\right| = \left|(u,\sqrt{2}v,w)\cdot(x^2,\sqrt{2}xy,y^2)\right|\le\sqrt{u^2+2v^2+w^2}\cdot\sqrt{x^4+2x^2y^2+y^4}.$$
> 注意 $\sqrt{u^2+2v^2+w^2}\le\sqrt{M}$，且 $x^4+2x^2y^2+y^4 = (x^2+y^2)^2$，所以
> $$\left|f(x,y)\right|\le\frac{\sqrt{M}}{2}\left(x^2+y^2\right).$$
> 于是
> $$\left|\iint_{x^2+y^2\le 1} f(x,y)\,\mathrm{d}x\,\mathrm{d}y\right|\le\frac{\sqrt{M}}{2}\iint_{x^2+y^2\le 1}\left(x^2+y^2\right)\mathrm{d}x\,\mathrm{d}y = \frac{\sqrt{M}}{2}\cdot 2\pi\int_0^1 r^3\,\mathrm{d}r = \frac{\sqrt{M}}{2}\cdot\frac{\pi}{2} = \frac{\pi\sqrt{M}}{4}. \qquad\blacksquare$$
>
> **答案**：不等式得证；其中 $\iint_{x^2+y^2\le 1}(x^2+y^2)\,\mathrm{d}x\mathrm{d}y = \dfrac{\pi}{2}$。

**编者注**：证明的三个技术点——① 二阶泰勒的 Lagrange 余项只需用到 $f$ 二阶连续（每题必查：$f(0,0)=f_x(0,0)=f_y(0,0)=0$ 使一阶项消失）；② 把 $(f_{xx},f_{xy},f_{yy})$ 与 $(x^2,2xy,y^2)$ 配对时，给第二分量各配一个 $\sqrt{2}$，Cauchy–Schwarz 的分母恰好对上条件中的 $f_{xx}^2+2f_{xy}^2+f_{yy}^2\le M$ 与 $(x^2+y^2)^2$；③ 常数 $\frac{\pi\sqrt{M}}{4}$ 中 $\frac{\pi}{2}$ 来自 $\iint r^2 = 2\pi\cdot\frac{1}{4}$。

### B7（第8届·第三题，2016年）椭球体密度积分（配方 + 平移换元 + 对称性） ｜ 难度：中

**题目**：某物体所在的空间区域为 $\Omega: x^2 + y^2 + 2z^2 \leqslant x + y + 2z$，密度函数为 $x^2 + y^2 + z^2$，求质量
$$M = \iiint_\Omega \left(x^2 + y^2 + z^2\right)\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z.$$

> **解答**：（本解答由备考项目编写，非官方答案）
>
> 配方：$x^2-x+y^2-y+2z^2-2z\le 0$，即
> $$\left(x-\frac{1}{2}\right)^2+\left(y-\frac{1}{2}\right)^2+2\left(z-\frac{1}{2}\right)^2\le 1,$$
> $\Omega$ 是中心在 $\left(\frac{1}{2},\frac{1}{2},\frac{1}{2}\right)$ 的椭球。作平移伸缩换元
> $$u = x-\frac{1}{2},\qquad v = y-\frac{1}{2},\qquad w = \sqrt{2}\left(z-\frac{1}{2}\right),$$
> 则 $\Omega$ 变为单位球 $\Sigma: u^2+v^2+w^2\le 1$，且 $\mathrm{d}u\,\mathrm{d}v\,\mathrm{d}w = \sqrt{2}\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z$。密度函数化为
> $$x^2+y^2+z^2 = \left(u+\frac{1}{2}\right)^2+\left(v+\frac{1}{2}\right)^2+\left(\frac{w}{\sqrt{2}}+\frac{1}{2}\right)^2 = u^2+v^2+\frac{w^2}{2}+\left(u+v+\frac{w}{\sqrt{2}}\right)+\frac{3}{4}.$$
> 由对称性，一次项 $u,\ v,\ w$ 在单位球上的积分都为 $0$；又
> $$\iiint_\Sigma u^2\,\mathrm{d}V = \iiint_\Sigma v^2\,\mathrm{d}V = \frac{1}{3}\iiint_\Sigma\left(u^2+v^2+w^2\right)\mathrm{d}V = \frac{1}{3}\cdot 4\pi\int_0^1 r^4\,\mathrm{d}r = \frac{4\pi}{15},$$
> 于是
> $$M = \frac{1}{\sqrt{2}}\iiint_\Sigma\left(u^2+v^2+\frac{w^2}{2}+\frac{3}{4}\right)\mathrm{d}V = \frac{1}{\sqrt{2}}\left[\frac{4\pi}{15}+\frac{4\pi}{15}+\frac{2\pi}{15}+\frac{3}{4}\cdot\frac{4\pi}{3}\right] = \frac{1}{\sqrt{2}}\left(\frac{2\pi}{3}+\pi\right) = \frac{5\pi}{3\sqrt{2}} = \frac{5\sqrt{2}\pi}{6}.$$
>
> **答案**：$M = \dfrac{5\sqrt{2}\,\pi}{6}$。

**编者注**：三步走——配方认区域（椭球）、平移伸缩消中心（雅可比 $\frac{1}{\sqrt{2}}$ 别丢）、对称性砍一次项。核算：椭球体积 $V = \frac{4\pi}{3}\cdot\frac{1}{\sqrt{2}} = \frac{2\sqrt{2}\pi}{3}$，密度平均值若按中心视为 $x^2+y^2+z^2\approx \frac{3}{4}+$（各向同性部分）——数量级核对 $M\approx 3.70$ 合理。

### B8（第9届·一(6)，2017年）锥面与球面所围区域的三重积分 ｜ 难度：易

**题目**：记曲面 $z^2 = x^2 + y^2$ 和 $z = \sqrt{4-x^2-y^2}$ 围成的空间区域为 $V$，则三重积分 $\displaystyle\iiint_V z\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z = \underline{\qquad}$。

> **解答**：（本解答由备考项目编写，非官方答案）
>
> 两曲面的交线：$z^2 = x^2+y^2$ 且 $x^2+y^2+z^2 = 4$ 得 $2z^2 = 4$，即 $z = \sqrt{2},\ x^2+y^2 = 2$。区域 $V$ 在柱坐标 $x = r\cos\theta,\ y = r\sin\theta$ 下为
> $$0\le\theta\le 2\pi,\qquad 0\le r\le\sqrt{2},\qquad r\le z\le\sqrt{4-r^2}.$$
> 于是
> $$I = \int_0^{2\pi}\mathrm{d}\theta\int_0^{\sqrt{2}}r\,\mathrm{d}r\int_r^{\sqrt{4-r^2}}z\,\mathrm{d}z = 2\pi\int_0^{\sqrt{2}}r\cdot\frac{1}{2}\left[\left(4-r^2\right)-r^2\right]\mathrm{d}r = \pi\int_0^{\sqrt{2}}\left(4r-2r^3\right)\mathrm{d}r.$$
> $$= \pi\left[2r^2-\frac{r^4}{2}\right]_0^{\sqrt{2}} = \pi(4-2) = 2\pi.$$
>
> **另解（球坐标）**：$V$ 在球坐标下为 $0\le\theta\le 2\pi,\ 0\le\varphi\le\dfrac{\pi}{4},\ 0\le\rho\le 2$，故
> $$I = \int_0^{2\pi}\mathrm{d}\theta\int_0^{\pi/4}\mathrm{d}\varphi\int_0^{2}\left(\rho\cos\varphi\right)\rho^2\sin\varphi\,\mathrm{d}\rho = 2\pi\cdot\frac{\rho^4}{4}\Big|_0^2\cdot\frac{\sin^2\varphi}{2}\Big|_0^{\pi/4} = 8\pi\cdot\frac{1}{4} = 2\pi.$$
>
> **答案**：$2\pi$。

**编者注**：这是「锥面 + 球面」围成区域的标准题：柱坐标下 $z$ 从锥面 $r$ 穿到球面 $\sqrt{4-r^2}$，被积函数 $z$ 使内层积分直接得 $\frac{1}{2}[(4-r^2)-r^2]$；球坐标下 $\varphi\le\frac{\pi}{4}$（锥面半顶角 45°）也一步到位。两种坐标都要顺手。

### C1（第13届补赛·三，2021年）Δf 条件下的二重积分与极限 ｜ 难度：难

> （跨专题：另见曲线积分与格林公式专题——本题用 Green 公式把二重积分与边界积分互换）

**题目**：设函数 $f(x,y)$ 在闭区域 $D = \{(x,y) \mid x^2 + y^2 \le 1\}$ 上具有二阶连续偏导数，且 $\dfrac{\partial^2 f}{\partial x^2} + \dfrac{\partial^2 f}{\partial y^2} = x^2 + y^2$，求

$$\lim_{r\to 0^+}\frac{\displaystyle\iint_{x^2+y^2\le r^2}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y}{(\tan r - \sin r)^2}.$$

> **解答（官方解答）**：【解】 对 $\forall 0 < r \le 1$，设 $D_r := \left\{(x,y) \in R^2 \mid x^2 + y^2 \le r^2\right\}$，由 Green 公式，得
> $$\iint_{D_r}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y = -\frac{1}{2}\iint_{D_r}(x^2 + y^2)\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y$$
> $$+ \frac{1}{2}\int_{\partial D_r} -(x^2 + y^2)\frac{\partial f}{\partial y}\mathrm{d}x + (x^2 + y^2)\frac{\partial f}{\partial x}\mathrm{d}y$$
> $$= \frac{r^2}{2}\iint_{D_r}\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y - \frac{1}{2}\iint_{D_r}(x^2 + y^2)\left(\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\right)\mathrm{d}x\mathrm{d}y$$
> $$= \pi r^2\int_0^r s^3\mathrm{d}s - \pi\int_0^r s^5\mathrm{d}s = \frac{\pi}{4}r^6 - \frac{\pi}{6}r^6 = \frac{\pi}{12}r^6.$$
> ……（8 分）
> 因此，由 Taylor 公式，得
> $$\lim_{r\to 0^+}\frac{\displaystyle\iint_{D_r}\left(x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y}\right)\mathrm{d}x\mathrm{d}y}{(\tan r - \sin r)^2} = \lim_{r\to 0^+}\frac{\dfrac{\pi}{12}r^6}{\left[\left(r + \dfrac{r^3}{3} + o(r^3)\right) - \left(r - \dfrac{r^3}{3!} + o(r^3)\right)\right]^2}$$
> $$= \lim_{r\to 0^+}\frac{\dfrac{\pi}{12}r^6}{\dfrac{r^6}{4} + o(r^6)} = \frac{1}{3}\pi.$$
> ……（6 分）

**答案**：$\dfrac{\pi}{3}$。

**编者注**：官方解的第一步用了一个「分部积分 + Green」的恒等式（对 $P = -(x^2+y^2)\frac{\partial f}{\partial y}$，$Q = (x^2+y^2)\frac{\partial f}{\partial x}$ 用 Green 公式即得）：$x f_x+y f_y = \left[\frac{r^2}{2}\Delta f\right]$ 型的边界项与面积分项之差；在 $\partial D_r$ 上 $x^2+y^2\equiv r^2$，于是边界项再次用 Green 化成 $\frac{r^2}{2}\iint\Delta f$（边界的曲线积分 $\frac{1}{2}\oint_{\partial D_r}(-f_y\mathrm{d}x+f_x\mathrm{d}y) = \frac{1}{2}\iint_{D_r}\Delta f$）。剩下就是极坐标下的两次一元积分：$\iint_{D_r}(x^2+y^2) = 2\pi\int_0^r s^3\mathrm{d}s$，$\iint_{D_r}(x^2+y^2)^2 = 2\pi\int_0^r s^5\mathrm{d}s$。最后 $\tan r-\sin r\sim \frac{r^3}{2}$。

### C2（第14届·五，2022年）交换积分次序 + 全微分求极限 ｜ 难度：难

> （跨专题：另见多元函数微分学专题——全微分定义与可微展开）

**题目**：设 $z = f(x,y)$ 是区域 $D = \{(x,y)\mid 0\le x\le 1,\,0\le y\le 1\}$ 上的可微函数，$f(0,0) = 0$，且 $\mathrm{d}z\big|_{(0,0)} = 3\mathrm{d}x + 2\mathrm{d}y$，求极限
$$\lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u}{1-\sqrt[4]{1-x^4}}.$$

> **解答（官方解答）**：【解】 交换二次积分的次序，得
> $$\int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u = -\int_0^x\mathrm{d}u\int_0^{u^2}f(t,u)\,\mathrm{d}t.$$
> ……（3 分）
> 由于 $f(x,y)$ 在 $D$ 上可微，所以 $f(x,y)$ 在点 $(0,0)$ 的半径为 1 的扇形域内连续，从而 $\varphi(u) = \displaystyle\int_0^{u^2}f(t,u)\,\mathrm{d}t$ 在 $u = 0$ 的某邻域内连续，因此
> $$I = \lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}\mathrm{d}t\int_x^{\sqrt{t}}f(t,u)\,\mathrm{d}u}{1-\sqrt[4]{1-x^4}} = \lim_{x\to 0^+}\frac{-\displaystyle\int_0^x\varphi(u)\,\mathrm{d}u}{\dfrac{x^4}{4}} = -\lim_{x\to 0^+}\frac{\varphi(x)}{x^3} = -\lim_{x\to 0^+}\frac{\displaystyle\int_0^{x^2}f(t,x)\,\mathrm{d}t}{x^3}$$
> $$= -\lim_{x\to 0^+}\frac{f(\xi,x)x^2}{x^3} = -\lim_{x\to 0^+}\frac{f(\xi,x)}{x},\qquad 0<\xi<x^2.$$
> ……（6 分）
> 因为 $\mathrm{d}z\big|_{(0,0)} = 3\mathrm{d}x + 2\mathrm{d}y$，所以 $f_x(0,0) = 3$，$f_y(0,0) = 2$。又 $f(0,0) = 0$，于是
> $$f(\xi,x) = f(0,0) + f_x(0,0)\xi + f_y(0,0)x + o\left(\sqrt{\xi^2+x^2}\right) = 3\xi + 2x + o\left(\sqrt{\xi^2+x^2}\right).$$
> 注意到 $0 < \dfrac{\xi}{x} < x$，故由夹逼准则知 $\lim\limits_{x\to 0^+}\dfrac{\xi}{x} = 0$，从而
> $$\lim_{x\to 0^+}\frac{o\left(\sqrt{\xi^2+x^2}\right)}{x} = \lim_{x\to 0^+}\frac{o\left(\sqrt{\xi^2+x^2}\right)}{\sqrt{\xi^2+x^2}}\cdot\sqrt{1+\left(\frac{\xi}{x}\right)^2} = 0.$$
> 所以
> $$I = -\lim_{x\to 0^+}\frac{f(\xi,x)}{x} = -\lim_{x\to 0^+}\frac{3\xi + 2x + o\left(\sqrt{\xi^2+x^2}\right)}{x} = -2.$$
> ……（5 分）

**答案**：$-2$。

**编者注**：三个动作——① 换序：原积分域是 $\{x\le u\le\sqrt{t},\ 0\le t\le x^2\}$（注意外参数与积分变量同名 $x$ 的干扰，先画域再用 $u$ 为主序）；② 换序后分母与分子都出现 $x^4$ 量级，用 $\varphi(x)/x^3$ 的洛必达化到 $\int_0^{x^2}f(t,x)\mathrm{d}t$；③ 积分中值 + 全微分展开，注意余项 $o(\sqrt{\xi^2+x^2})/x\to 0$ 的关键是 $\xi/x\to 0$（夹逼）。
