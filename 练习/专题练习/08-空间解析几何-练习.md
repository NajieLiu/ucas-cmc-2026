## A 组 · 近年真题（第 10-17 届）

### A1 ｜（第11届·一(5)，2019年）｜ 难度：中

设 $a,b,c,\mu>0$，曲面 $xyz = \mu$ 与曲面 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2} = 1$ 相切，则 $\mu = \underline{\qquad}$。

> **解答**（官方解法，答案：$\dfrac{abc}{3\sqrt{3}}$）：根据题意有：$yz = \dfrac{2x}{a^2}\lambda$，$xz = \dfrac{2y}{b^2}\lambda$，$xy = \dfrac{2z}{c^2}\lambda$，以及
> $$\mu = 2\lambda\frac{x^2}{a^2},\qquad \mu = 2\lambda\frac{y^2}{b^2},\qquad \mu = 2\lambda\frac{z^2}{c^2},$$
> 从而得：$\mu = \dfrac{8\lambda^3}{a^2b^2c^2}$，$3\mu = 2\lambda$，
> 联立解得：$\mu = \dfrac{abc}{3\sqrt{3}}$。
>
> （式中 $(x,y,z)$ 为切点坐标：第一组等式由"两曲面在切点处法向量平行"得到；第二组等式由第一组两端同乘对应坐标、再用切点在曲面 $xyz=\mu$ 上得到；"$3\mu=2\lambda$"由切点在椭球面上（$x^2/a^2+y^2/b^2+z^2/c^2=1$）得到。）

### A2 ｜（第13届·一(4)，2021年）｜ 难度：难

过三条直线 $L_1:\begin{cases}x=0,\\ y-z=2,\end{cases}$ $L_2:\begin{cases}x=0,\\ x+y-z+2=0,\end{cases}$ 与 $L_3:\begin{cases}x=\sqrt{2},\\ y-z=0\end{cases}$ 的圆柱面方程为 $\underline{\qquad}$。

> **解答**（官方解法，答案：$2x^2+y^2+z^2-2yz=4$）：三条直线的对称式方程分别为
> $$L_1:\ \frac{x}{0}=\frac{y-1}{1}=\frac{z+1}{1},\qquad L_2:\ \frac{x}{0}=\frac{y-0}{1}=\frac{z-2}{1},\qquad L_3:\ \frac{x-\sqrt{2}}{0}=\frac{y-1}{1}=\frac{z-1}{1},$$
> 所以三条直线平行。（注：原卷第三个对称式方程对应的应是直线 $L_3$，原卷标签印为 $L_2$。）
>
> 在 $L_1$ 上取点 $P_1(0,1,-1)$，过该点作与三直线都垂直的平面 $y+z=0$，分别交 $L_2$，$L_3$ 于点 $P_2(0,-1,1)$，$P_3(\sqrt{2},0,0)$。易知经过这三点的圆的圆心为 $O(0,0,0)$。这样，所求圆柱面的中心轴线方程为 $\dfrac{x}{0}=\dfrac{y}{1}=\dfrac{z}{1}$。
>
> 设圆柱面上任意点的坐标为 $Q(x,y,z)$，因为点 $Q$ 到轴线的距离均为 $\sqrt{2}$，所以有
> $$\frac{\left|(x,y,z)\times(0,1,1)\right|}{\sqrt{0^2+1^2+1^2}}=\sqrt{2},$$
> 化简即得所求圆柱面的方程为 $2x^2+y^2+z^2-2yz=4$。

### A3 ｜（第13届补赛·一(3)，2021年）｜ 难度：中

已知直线 $L$：$\begin{cases}2x - 4y + z = 0\\ 3x - y - 2z = 9\end{cases}$ 和平面 $\pi$：$4x - y + z = 1$，则直线 $L$ 在平面 $\pi$ 上的投影直线方程为 ______。

> **解答**（官方解法，答案：$\begin{cases}17x+31y-37z=117\\ 4x-y+z=1\end{cases}$）：所求投影直线为过 $L$ 且垂直于 $\pi$ 的平面 $\pi_1$ 与 $\pi$ 的交线，因此需要先求出过 $L$ 且垂直于 $\pi$ 的平面 $\pi_1$ 的方程.
>
> 过 $L$ 的平面束方程为
> $$\lambda(2x - 4y + z) + \mu(3x - y - 2z - 9) = 0,$$
> 即
> $$(2\lambda + 3\mu)x - (4\lambda + \mu)y + (\lambda - 2\mu)z - 9\mu = 0. \qquad \cdots\cdots (1)$$
>
> 平面 $\pi$ 的法向量为 $\vec{n} = (4,\ -1,\ 1)$. 因平面 $\pi_1$ 与平面 $\pi$ 垂直，则必须有
> $$4(2\lambda + 3\mu) + (-1)(-4\lambda - \mu) + 1\cdot(\lambda - 2\mu) = 0.$$
> 解之，得 $\dfrac{\lambda}{\mu} = -\dfrac{11}{13}$，由 (1)，得到平面 $\pi_1$ 的方程
> $$17x + 31y - 37z - 117 = 0.$$
> 故所求投影直线为
> $$\begin{cases}17x + 31y - 37z - 117 = 0\\ 4x - y + z - 1 = 0\end{cases}$$
> （即答案所给 $\begin{cases}17x+31y-37z=117\\ 4x-y+z=1\end{cases}$。）

### A4 ｜（第14届·二，2022年）｜ 难度：中（跨专题：另见「向量代数与最值」相关训练）

记向量 $\overrightarrow{OA}$ 与 $\overrightarrow{OB}$ 的夹角为 $\alpha$，$|\overrightarrow{OA}| = 1$，$|\overrightarrow{OB}| = 2$，$\overrightarrow{OP} = (1-\lambda)\overrightarrow{OA}$，$\overrightarrow{OQ} = \lambda\overrightarrow{OB}$，$0\le\lambda\le 1$。

**(1)** 问当 $\lambda$ 为何值时，$|\overrightarrow{PQ}|$ 取得最小值；

**(2)** 设（1）中的 $\lambda$ 满足 $0 < \lambda < \dfrac{1}{5}$，求夹角 $\alpha$ 的取值范围。

> **解答**（官方解法）：
>
> （1）根据余弦定理，并注意到 $0\le\alpha\le\pi$，得
> $$f(\lambda) = |\overrightarrow{PQ}|^2 = (1-\lambda)^2 + 4\lambda^2 - 4\lambda(1-\lambda)\cos\alpha$$
> $$= (5+4\cos\alpha)\lambda^2 - 2(1+2\cos\alpha)\lambda + 1$$
> $$= (5+4\cos\alpha)\left(\lambda - \frac{1+2\cos\alpha}{5+4\cos\alpha}\right)^2 + 1 - \frac{(1+2\cos\alpha)^2}{5+4\cos\alpha},$$
> 因此，当 $\lambda = \dfrac{1+2\cos\alpha}{5+4\cos\alpha}$ 时，$0\le\lambda\le 1$，$|\overrightarrow{PQ}|$ 取得最小值。
>
> （2）令 $y = \cos\alpha$，则 $\lambda = \dfrac{1+2y}{5+4y}$ 的反函数为 $g(\lambda) = -\dfrac{1}{2}\times\dfrac{5\lambda-1}{2\lambda-1}$。易知 $g(\lambda)$ 在 $\left(0,\ \dfrac{1}{5}\right)$ 单调增加，其值域为 $\left(-\dfrac{1}{2},\ 0\right)$，所以 $-\dfrac{1}{2} < \cos\alpha < 0$，注意到 $\cos\alpha$ 在 $[0,\pi]$ 上单调减，解得 $\dfrac{\pi}{2} < \alpha < \dfrac{2\pi}{3}$，即夹角 $\alpha$ 的取值范围为 $\left(\dfrac{\pi}{2},\ \dfrac{2\pi}{3}\right)$。
>
> **备考注（踩坑提醒）**：（1）的官方结论需补一个边界讨论——$\lambda_* = \dfrac{1+2\cos\alpha}{5+4\cos\alpha}$ 的取值范围实为 $\left[-1,\ \dfrac13\right]$（对 $\cos\alpha\in[-1,1]$ 单调递增），当 $\cos\alpha < -\dfrac{1}{2}$（即 $\alpha > \dfrac{2\pi}{3}$）时 $\lambda_* < 0$ 不在 $[0,1]$ 内，此时 $f(\lambda)$ 在 $[0,1]$ 上单调递增，最小值在 $\lambda = 0$ 处取得。完整答案：$\cos\alpha \ge -\dfrac{1}{2}$ 时取 $\lambda = \dfrac{1+2\cos\alpha}{5+4\cos\alpha}$；$\cos\alpha \le -\dfrac{1}{2}$ 时取 $\lambda = 0$。第（2）问结论不受影响（其条件 $0 < \lambda < \dfrac15$ 已强制 $\cos\alpha \in \left(-\dfrac12, 0\right)$）。

### A5 ｜（第15届·三，2023年）｜ 难度：难（跨专题：另见「重积分（旋转体体积）」专题）

设 $\Sigma_1$ 是以 $(0,4,0)$ 为顶点且与曲面 $\Sigma_2: \dfrac{x^2}{3}+\dfrac{y^2}{4}+\dfrac{z^2}{3}=1\ (y>0)$ 相切的圆锥面, 求曲面 $\Sigma_1$ 与 $\Sigma_2$ 所围成的空间区域的体积.

> **解答**（官方解法，答案：$\pi$）：设 $L$ 是 $xOy$ 平面上过点 $(0,4)$ 且与 $\dfrac{x^2}{3}+\dfrac{y^2}{4}=1$ 相切于点 $(x_0,y_0)$ 的直线, 则
> $$\frac{x_0^2}{3}+\frac{y_0^2}{4} = 1 \ \text{且切线斜率}\ \frac{y_0-4}{x_0} = -\frac{4x_0}{3y_0}, \ \text{解得}\ x_0 = \pm\frac{3}{2},\, y_0 = 1.$$
>
> 显然, $\Sigma_1$ 与 $\Sigma_2$ 分别是切线 $L$ 和曲线 $\dfrac{x^2}{3}+\dfrac{y^2}{4}=1$ 绕 $y$ 轴旋转而成的曲面, 它们的交线位于平面 $y_0 = 1$ 上.
>
> 记该平面与 $\Sigma_1$, $\Sigma_2$ 围成的空间区域分别记为 $\Omega_1$ 和 $\Omega_2$.
>
> 由于 $\Sigma_1$ 是底面圆的半径为 $\dfrac{3}{2}$, 高为 3 的圆锥体, 所以其体积 $V_1 = \dfrac{1}{3}\cdot\pi\cdot\left(\dfrac{3}{2}\right)^2\cdot 3 = \dfrac{9\pi}{4}$. 又 $\Omega_2$ 的体积为
> $$V_2 = \iiint_{\Omega_2}\mathrm{d}V = \int_1^2 \mathrm{d}y\iint_{x^2+z^2 \leqslant 3\left(1-\frac{y^2}{4}\right)}\mathrm{d}x\,\mathrm{d}z = \pi\int_1^2 3\left(1-\frac{y^2}{4}\right)\mathrm{d}y = \frac{5\pi}{4}.$$
> 因此, 曲面 $\Sigma_1$ 与 $\Sigma_2$ 所围成的空间区域的体积为 $\dfrac{9\pi}{4}-\dfrac{5\pi}{4} = \pi$.

### A6 ｜（第16届·一(4)，2024年）｜ 难度：中

直线 $L: \dfrac{x-1}{1} = \dfrac{y}{1} = \dfrac{z-1}{-1}$ 在平面 $\pi: x - y + 2z - 1 = 0$ 上的投影直线 $L_0$ 的单位方向向量为 $\underline{\qquad}$。

> **解答**（官方解法，答案：$\pm\left(-\dfrac{4}{\sqrt{21}},\ -\dfrac{2}{\sqrt{21}},\ \dfrac{1}{\sqrt{21}}\right)$）：直线 $L$ 的一般式方程为 $\begin{cases} x - y - 1 = 0, \\ y + z - 1 = 0. \end{cases}$ 这样，过 $L$ 的平面束方程为
> $$x - y - 1 + \lambda(y + z - 1) = 0, \qquad 即 \qquad x + (\lambda-1)y + \lambda z - 1 - \lambda = 0,$$
> 其中 $\lambda$ 为参数。平面的法向量为 $(1,\, \lambda-1,\, \lambda)$。此法向量与平面 $\pi$ 的法向量垂直当且仅当 $(1,\, \lambda-1,\, \lambda)\cdot(1,\, -1,\, 2) = 0$，即 $\lambda = -2$。
>
> 从而，过 $L$ 且与平面 $\pi$ 垂直的平面为 $x - 3y - 2z + 1 = 0$。于是，投影直线 $L_0$ 的方程为
> $$\begin{cases} x - 3y - 2z + 1 = 0, \\ x - y + 2z - 1 = 0. \end{cases}$$
> 由此，$L_0$ 的方向向量为 $(-4,\, -2,\, 1)$。故单位方向向量为 $\pm\left(-\dfrac{4}{\sqrt{21}},\ -\dfrac{2}{\sqrt{21}},\ \dfrac{1}{\sqrt{21}}\right)$。
> （原卷注：单位方向向量有两个，得到一个即可。）
>
> **另解（方向投影法，仅求方向向量时更快）**：$L$ 的方向向量 $\vec{d} = (1,1,-1)$，$\pi$ 的法向量 $\vec{n} = (1,-1,2)$。投影直线的方向向量就是 $\vec{d}$ 在 $\pi$ 上的投影向量
> $$\vec{d}_0 = \vec{d} - \frac{\vec{d}\cdot\vec{n}}{|\vec{n}|^2}\vec{n} = (1,1,-1) - \frac{-2}{6}(1,-1,2) = \left(\frac43,\ \frac23,\ -\frac13\right) \propto (4,\,2,\,-1),$$
> 与官方答案 $(-4,-2,1)$ 相差一个符号，单位化后一致。（注：此法只给出方向；若要求完整直线方程，仍需用平面束法求"过 $L$ 且垂直于 $\pi$ 的平面"。）

### A7 ｜（第17届·一(2)，2025年）｜ 难度：易

设平面过原点与点 $(6,-3,2)$，且与平面 $4x - y + 2z - 8 = 0$ 垂直，则此平面方程为 $\underline{\qquad}$。

> **解答**（官方答案：$2x + 2y - 3z = 0$；原卷注：答案不唯一，系数差个倍数都对，例如 $-2x - 2y + 3z = 0$ 或 $x + y - \dfrac{3}{2}z = 0$ 也对）：
>
> **补充推导**：所求平面的法向量 $\vec{n}$ 同时垂直于：
> ① 平面内的向量 $\overrightarrow{OM} = (6,-3,2)$（$M$ 为已知点，平面过原点 $O$）；② 已知平面的法向量 $(4,-1,2)$（两平面垂直 ⇔ 法向量互相垂直）。取
> $$\vec{n} = (6,-3,2)\times(4,-1,2) = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 6 & -3 & 2 \\ 4 & -1 & 2 \end{vmatrix} = (-4,\ -4,\ 6) \propto (2,\ 2,\ -3).$$
> 平面过原点，故方程为 $2x + 2y - 3z = 0$。
> （验证：$(2,2,-3)\cdot(6,-3,2) = 12-6-6 = 0$，$(2,2,-3)\cdot(4,-1,2) = 8-2-6 = 0$。）

## B 组 · 早期真题（第 1-9 届）

> 说明：第 1–9 届的参考解答已收录于转录库/答案册（除第 7 届为非官方流传版外均为官方版）；本组 7 题的解答均由备考项目编写并逐题验算。

### B1 ｜（第01届·一(3)，2009年）｜ 难度：易

曲面 $z = \dfrac{x^2}{2} + y^2 - 2$ 平行平面 $2x + 2y - z = 0$ 的切平面方程是 $\underline{\qquad}$。

> **解答**（本解答由备考项目编写，非官方答案）：设切点为 $P(x_0,y_0,z_0)$。记 $F(x,y,z) = \dfrac{x^2}{2} + y^2 - z - 2 = 0$，则曲面在 $P$ 处的法向量为 $\nabla F(P) = (x_0,\ 2y_0,\ -1)$。
>
> 切平面与已知平面平行 ⇔ 法向量成比例：
> $$(x_0,\ 2y_0,\ -1) = \lambda(2,\ 2,\ -1).$$
> 由第三分量 $-1 = -\lambda$ 得 $\lambda = 1$，于是 $x_0 = 2$，$y_0 = 1$；回代曲面方程得 $z_0 = \dfrac{4}{2} + 1 - 2 = 1$（切点必须回代求 $z_0$，这是本题最容易出错的一步）。
>
> 所求切平面为
> $$2(x-2) + 2(y-1) - (z-1) = 0, \quad \text{即} \quad 2x + 2y - z = 5.$$
> （验证：切点 $(2,1,1)$ 满足 $2\cdot2+2\cdot1-1 = 5$；且将 $z = 2x+2y-5$ 代入曲面得 $\dfrac{(x-2)^2}{2} + (y-1)^2 = 0$，仅交于一点，确为切平面。）

### B2 ｜（第02届·一(5)，2010年）｜ 难度：中

求直线 $l_1 : \begin{cases} x - y = 0 \\ z = 0 \end{cases}$ 与直线 $l_2 : \dfrac{x - 2}{4} = \dfrac{y - 1}{-2} = \dfrac{z - 3}{-1}$ 的距离。

> **解答**（本解答由备考项目编写，非官方答案）：$l_1$ 过点 $A(0,0,0)$，方向向量 $\vec{d}_1 = (1,1,0)$；$l_2$ 过点 $B(2,1,3)$，方向向量 $\vec{d}_2 = (4,-2,-1)$。
>
> 先判断位置关系：混合积
> $$\left(\overrightarrow{AB},\ \vec{d}_1,\ \vec{d}_2\right) = \begin{vmatrix} 2 & 1 & 3 \\ 1 & 1 & 0 \\ 4 & -2 & -1 \end{vmatrix} = 2\cdot(1\cdot(-1) - 0\cdot(-2)) - 1\cdot(1\cdot(-1) - 0\cdot4) + 3\cdot(1\cdot(-2) - 1\cdot4) = -19 \neq 0,$$
> 故两直线异面（不共面；亦可通过解交点方程组 $t(1,1,0) = (2,1,3)+s(4,-2,-1)$ 矛盾验证）。
>
> 由异面直线距离公式
> $$d = \frac{\left|\left(\overrightarrow{AB},\ \vec{d}_1,\ \vec{d}_2\right)\right|}{\left|\vec{d}_1 \times \vec{d}_2\right|},$$
> 其中 $\vec{d}_1 \times \vec{d}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 1 & 0 \\ 4 & -2 & -1 \end{vmatrix} = (-1,\ 1,\ -6)$，$|\vec{d}_1 \times \vec{d}_2| = \sqrt{1+1+36} = \sqrt{38}$。
>
> 所以
> $$d = \frac{|-19|}{\sqrt{38}} = \frac{19}{\sqrt{38}} = \frac{\sqrt{38}}{2}.$$
> （验证：解交点方程组 $t(1,1,0) = (2,1,3)+s(4,-2,-1)$——由 $z$ 分量得 $s = 3$、由 $y$ 分量得 $t = -5$、由 $x$ 分量得 $t = 14$，相互矛盾，两直线确为异面；$\frac{19}{\sqrt{38}} = \frac{19\sqrt{38}}{38} = \frac{\sqrt{38}}{2} \approx 3.08$。）

### B3 ｜（第04届·一(2)，2012年）｜ 难度：中

求通过直线 $L:\begin{cases}2x + y - 3z + 2 = 0,\\ 5x + 5y - 4z + 3 = 0\end{cases}$ 的两个相互垂直的平面 $\pi_1$，$\pi_2$，使其中一个平面过点 $(4, -3, 1)$。

> **解答**（本解答由备考项目编写，非官方答案）：过 $L$ 的平面束为
> $$2x + y - 3z + 2 + \lambda(5x + 5y - 4z + 3) = 0,$$
> 即
> $$(2+5\lambda)x + (1+5\lambda)y + (-3-4\lambda)z + (2+3\lambda) = 0,$$
> 其法向量为 $\vec{n}(\lambda) = (2+5\lambda,\ 1+5\lambda,\ -3-4\lambda)$。
>
> **定 $\pi_1$**：把点 $(4,-3,1)$ 代入平面束方程：
> $$(8 - 3 - 3 + 2) + \lambda(20 - 15 - 4 + 3) = 4 + 4\lambda = 0 \ \Longrightarrow\ \lambda = -1,$$
> 此时 $\vec{n}(-1) = (-3,-4,1)$，得
> $$\pi_1:\ -3x - 4y + z - 1 = 0, \quad \text{即} \quad 3x + 4y - z + 1 = 0.$$
>
> **定 $\pi_2$**：设 $\pi_2$ 对应参数 $\lambda_2$，由 $\pi_1 \perp \pi_2$ 得 $\vec{n}(-1)\cdot\vec{n}(\lambda_2) = 0$：
> $$(-3)(2+5\lambda_2) + (-4)(1+5\lambda_2) + 1\cdot(-3-4\lambda_2) = -13 - 39\lambda_2 = 0 \ \Longrightarrow\ \lambda_2 = -\frac13,$$
> 此时平面为 $\dfrac13 x - \dfrac23 y - \dfrac53 z + 1 = 0$，即
> $$\pi_2:\ x - 2y - 5z + 3 = 0.$$
>
> （验证：两平面均为平面束成员故都含 $L$——$L$ 的方向向量 $(11,-7,5)$ 与两者的法向量均正交；$(3,4,-1)\cdot(1,-2,-5) = 3 - 8 + 5 = 0$，故两平面互相垂直；点 $(4,-3,1)$ 在 $\pi_1$ 上：$12 - 12 - 1 + 1 = 0$。）

### B4 ｜（第06届·一(2)，2014年）｜ 难度：易

设有曲面 $S: z = x^2 + 2y^2$ 和平面 $\pi: 2x + 2y + z = 0$，则与 $\pi$ 平行的 $S$ 的切平面方程是 $\underline{\qquad}$。

> **解答**（本解答由备考项目编写，非官方答案）：设切点为 $P(x_0,y_0,z_0)$。记 $F(x,y,z) = x^2 + 2y^2 - z = 0$，则 $\nabla F(P) = (2x_0,\ 4y_0,\ -1)$，与 $\pi$ 的法向量 $(2,2,1)$ 平行：
> $$(2x_0,\ 4y_0,\ -1) = t(2,\ 2,\ 1).$$
> 由第三分量 $-1 = t$ 得 $t = -1$，于是 $x_0 = -1$，$y_0 = -\dfrac12$，回代得 $z_0 = 1 + \dfrac12 = \dfrac32$。
>
> 所求切平面为
> $$-2(x+1) - 2\left(y + \dfrac12\right) - \left(z - \dfrac32\right) = 0,$$
> 化简得
> $$2x + 2y + z = -\dfrac{3}{2} \quad \left(\text{即} \quad 4x + 4y + 2z + 3 = 0\right).$$
> （验证：切点 $\left(-1,-\frac12,\frac32\right)$ 满足 $2(-1) + 2\left(-\frac12\right) + \frac32 = -\frac32$；法向量 $(2,2,1)$ 与 $\pi$ 平行。）

### B5 ｜（第07届·一(3)，2015年）｜ 难度：中（跨专题：另见「二重积分」专题）

曲面 $z=x^2+y^2+1$ 在点 $M(1,-1,3)$ 的切平面与曲面 $z=x^2+y^2$ 所围区域的体积为 $\underline{\qquad}$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **第一步：切平面**。记 $F = x^2 + y^2 + 1 - z$，$\nabla F(M) = (2x,\ 2y,\ -1)\big|_{(1,-1,3)} = (2,\ -2,\ -1)$。切平面方程为
> $$2(x-1) - 2(y+1) - (z-3) = 0, \quad \text{即} \quad z = 2x - 2y - 1.$$
>
> **第二步：定投影区域**。两曲面的交线满足 $2x - 2y - 1 = x^2 + y^2$，配方得
> $$(x-1)^2 + (y+1)^2 = 1,$$
> 即交线投影为圆域 $D: (x-1)^2 + (y+1)^2 \le 1$。在 $D$ 上，切平面在抛物面之上，高度为
> $$h = (2x - 2y - 1) - (x^2 + y^2) = 1 - (x-1)^2 - (y+1)^2 \geqslant 0.$$
>
> **第三步：体积**。令 $u = x-1$，$v = y+1$，用极坐标：
> $$V = \iint_D \left[1 - (x-1)^2 - (y+1)^2\right]\mathrm{d}x\,\mathrm{d}y = \iint_{u^2+v^2\le 1}(1-u^2-v^2)\,\mathrm{d}u\,\mathrm{d}v = \int_0^{2\pi}\mathrm{d}\theta\int_0^1 (1-r^2)\,r\,\mathrm{d}r$$
> $$= 2\pi\left(\frac12 - \frac14\right) = \frac{\pi}{2}.$$
> （验证：两曲面恰切于交线圆上各点，区域为"抛物面被斜切平面削下的一顶帽子"，$h\ge0$ 且仅在圆上为 $0$；答案 $\dfrac{\pi}{2}$。）

### B6 ｜（第07届·第二题，2015年）｜ 难度：难

设 $M$ 是以三个正半轴为母线的半圆锥面，求其方程。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **解法一（对称性 + 等角条件）**：圆锥面是直圆锥面，三条母线（三条正半轴）交于原点，故顶点为原点 $O$。三条母线两两夹角为 $90^\circ$，由对称性，锥轴必在三条坐标轴的"正中间"，即沿方向 $\vec{a} = (1,1,1)$。母线（如 $x$ 轴正方向 $(1,0,0)$）与轴的夹角（半顶角 $\theta$）满足
> $$\cos\theta = \frac{(1,1,1)\cdot(1,0,0)}{\sqrt{3}\cdot 1} = \frac{1}{\sqrt{3}}.$$
> 设 $Q(x,y,z)$ 为锥面上任一点（$Q \neq O$），则 $\overrightarrow{OQ}$ 与轴的夹角为 $\theta$：
> $$\frac{x+y+z}{\sqrt{3}\,\sqrt{x^2+y^2+z^2}} = \frac{1}{\sqrt{3}},$$
> 即 $(x+y+z)^2 = x^2+y^2+z^2$，展开化简得
> $$xy + yz + zx = 0.$$
> 取含三条正半轴的一支（即 $x+y+z \geqslant 0$ 的半支），所求半圆锥面方程为
> $$\boxed{xy + yz + zx = 0 \quad (x+y+z \geqslant 0)}.$$
>
> **解法二（待定系数，更简）**：顶点在原点的锥面方程为齐次二次方程
> $$ax^2 + by^2 + cz^2 + 2fyz + 2gzx + 2hxy = 0.$$
> 三条正半轴为母线，即 $x$ 轴上的直线 $(t,0,0)$ 满足方程：$at^2 \equiv 0$，故 $a = 0$；同理 $b = c = 0$。又三条母线地位对称（任一坐标置换把三条母线整体映为自身，而由三条母线确定的直圆锥面唯一），故方程关于 $x,y,z$ 对称，$f = g = h$，得 $xy + yz + zx = 0$，取 $x+y+z\ge0$ 的一支。
>
> （验证：$(1,0,0)$、$(0,1,0)$、$(0,0,1)$ 都满足 $xy+yz+zx = 0$ 且 $x+y+z = 1 > 0$，三条正半轴确在曲面上；而 $(-1,0,0)$ 一侧 $x+y+z = -1<0$，不含正半轴，需舍去。）

### B7 ｜（第08届·一(5)，2016年）｜ 难度：易

曲面 $z = \dfrac{x^2}{2} + y^2$ 平行于平面 $2x + 2y - z = 0$ 的切平面方程为 $\underline{\qquad}$。

> **解答**（本解答由备考项目编写，非官方答案）：设切点 $P(x_0,y_0,z_0)$，法向量 $(x_0,\ 2y_0,\ -1)$ 与 $(2,2,-1)$ 平行，同样由第三分量得 $x_0 = 2$，$y_0 = 1$，回代得 $z_0 = \dfrac{4}{2} + 1 = 3$。
>
> 切平面：$2(x-2) + 2(y-1) - (z-3) = 0$，即
> $$2x + 2y - z = 3.$$
> （验证：切点 $(2,1,3)$ 满足 $4+2-3 = 3$。本题与第 01 届一(3) 同型——曲面只差常数 $-2$，答案常数随之差 2，可对比记忆。）

## 本专题训练建议

**1. 做题顺序（由易到难、按方法成串，建议首轮按此顺序）**

- ① 热身·平面与切平面（目标：每题 ≤3 分钟）：**A7 → B1 → B4 → B7**（其中 B1、B4、B7 为切平面三连）——体会"法向量成比例 → 回代求切点 → 写点法式"的固定三步；重点比对第 01/06/08 届三题的差异（曲面不同、平面符号不同、答案常数不同）。
- ② 平面与直线（平面束同一套路）：**B3 → A3 → A6**——连做三题，"求投影直线 = 过直线作垂直平面 ∩ 原平面"这个套路会刻进肌肉记忆；A6 顺带复习向量积与单位化。
- ③ 距离与向量：**B2 → A4**——异面直线距离公式 + 数量积展开二次函数，都是"算得稳就得分"。
- ④ 曲面方程（本专题的"难区"）：**A1 → A2 → B6**——分别对应"相切消元""柱面 = 到轴等距""锥面 = 母线与轴等角"三种构造，做不出先看方法，隔天重做。
- ⑤ 综合收官（几何 + 积分）：**B5 → A5**——切平面/锥面 + 体积，注意重积分的跨专题衔接。

**2. 目标正确率**：A 组（近年真题，考场同款）**100%**——这是全卷最该拿满的 6 分板块；B 组 ≥ 85%；三道难题（A2、B6、A5）首轮允许做不出，但方法框架必须能复述。

**3. 易错提醒（按出错频率排序）**

- **切平面丢常数**：由法向量成比例解出 $x_0,y_0$ 后，**务必回代曲面求 $z_0$**，再用点法式/代入定常数；第 01/06/08 届三道题是同一套路、仅曲面与平面略有不同，答案分别是 $2x+2y-z=5$、$4x+4y+2z+3=0$、$2x+2y-z=3$——错一步常数就是 0 分。
- **平面束形式**：过两平面交线的平面束用 $\lambda F + \mu G = 0$（两参数，"全"）；若写成 $F + \lambda G = 0$ 会漏掉平面 $G = 0$。垂直条件是**法向量点积为 0**。
- **投影直线**：投影直线 = "过 $L$ 且垂直于 $\pi$ 的平面" ∩ $\pi$；只把方向向量投影到 $\pi$ 上只能得方向、得不了直线位置（见 A6 另解注）。填空答案写成两个平面方程的交线即可。
- **异面直线距离**：先算混合积验证 ≠ 0（否则退化为平行/相交）；公式 $d = \dfrac{|(\overrightarrow{AB},\vec{d}_1,\vec{d}_2)|}{|\vec{d}_1\times\vec{d}_2|}$，最后别忘化简（$\frac{19}{\sqrt{38}} = \frac{\sqrt{38}}{2}$）。
- **相切问题**：切点同时满足两个曲面方程 + 法向量平行（引入比例系数），用"方程两边同乘坐标凑出 $\mu = xyz$"消元（A1 的核心技巧）；A5 则先降维到 $xOy$ 平面找切线，再绕轴旋转还原。
- **最值型向量题的范围检验**：配方求出的最值点要**检验是否在题给范围内**（A4 备考注：$\cos\alpha<-\frac12$ 时最值点在 $[0,1]$ 外，取端点）。
