## A 组 · 近年真题（第 10-17 届）

### A1（第10届·第三题，2018年）｜难度：中

**方法标签**：柯西积分不等式（下界）+ 均值不等式（上界）双向估计

设 $f(x)$ 在区间 $[0,1]$ 上连续，且 $1 \le f(x) \le 3$。证明：
$$1 \le \int_0^1 f(x)\,\mathrm{d}x\int_0^1\frac{1}{f(x)}\,\mathrm{d}x \le \frac{4}{3}.$$

> **解答**（官方参考答案）：由柯西不等式
> $$\int_0^1 f(x)\,\mathrm{d}x\int_0^1\frac{1}{f(x)}\,\mathrm{d}x \ge \left(\int_0^1\sqrt{f(x)}\sqrt{\frac{1}{f(x)}}\,\mathrm{d}x\right)^2 = 1.$$
> ……（4 分）
>
> 又由于 $(f(x)-1)(f(x)-3) \le 0$，则 $(f(x)-1)(f(x)-3)/f(x) \le 0$，
> 即 $f(x) + \dfrac{3}{f(x)} \le 4$，$\displaystyle\int_0^1\left(f(x) + \frac{3}{f(x)}\right)\mathrm{d}x \le 4$。
> ……（10 分）
>
> 由于 $\displaystyle\int_0^1 f(x)\,\mathrm{d}x\int_0^1\frac{3}{f(x)}\,\mathrm{d}x \le \frac{1}{4}\left(\int_0^1 f(x) + \int_0^1\frac{3}{f(x)}\,\mathrm{d}x\right)^2$，
> 故 $1 \le \displaystyle\int_0^1 f(x)\,\mathrm{d}x\int_0^1\frac{1}{f(x)}\,\mathrm{d}x \le \frac{4}{3}$。
> ……（14 分）
>
> （整理注：最后一步即对两个正数 $A = \int_0^1 f$、$B = \int_0^1\frac{3}{f}$ 用均值不等式 $AB \le \left(\frac{A+B}{2}\right)^2$，再由 $A + B \le 4$ 得 $AB \le 4$，即 $\int_0^1 f\int_0^1\frac{1}{f} \le \frac{4}{3}$。下界处的柯西不等式即"$\sqrt{a}\cdot\frac{1}{\sqrt{a}} = 1$"型配对，是这类"$\int f \cdot \int \frac{1}{f}$"题的固定套路。）

### A2（第10届·第六题，2018年）｜难度：中

**方法标签**：定积分定义（黎曼和）+ 均值不等式（Jensen 思想）+ 取极限

证明：对于连续函数 $f(x) > 0$，有
$$\ln\int_0^1 f(x)\,\mathrm{d}x \ge \int_0^1\ln f(x)\,\mathrm{d}x.$$

> **解答**（官方参考答案）：由于 $f(x)$ 在 $[0,1]$ 上连续，所以 $\displaystyle\int_0^1 f(x)\,\mathrm{d}x = \lim_{n\to+\infty}\frac{1}{n}\sum_{k=1}^n f(x_k)$，其中 $x_k \in \left[\frac{k-1}{n}, \frac{k}{n}\right]$。
> ……（4 分）
>
> 由不等式 $\left(f(x_1)f(x_2)\cdots f(x_n)\right)^{\frac{1}{n}} \le \dfrac{1}{n}\sum_{k=1}^n f(x_k)$，根据 $\ln x$ 的单调性
> $$\frac{1}{n}\sum_{k=1}^n \ln f(x_k) \le \ln\left(\frac{1}{n}\sum_{k=1}^n f(x_k)\right),$$
> ……（12 分）
>
> 根据 $\ln x$ 的连续性，两边取极限
> $$\lim_{n\to+\infty}\left(\frac{1}{n}\sum_{k=1}^n \ln f(x_k)\right) \le \lim_{n\to+\infty}\ln\left(\frac{1}{n}\sum_{k=1}^n f(x_k)\right)$$
> 得 $\displaystyle\int_0^1\ln f(x)\,\mathrm{d}x \le \ln\int_0^1 f(x)\,\mathrm{d}x$。
> ……（14 分）
>
> （整理注：本题是 Jensen 不等式的"离散证明"——$[0,1]$ 上 $\int_0^1 f$ 是平均值，对凹函数 $\varphi = \ln$ 有 $\varphi\left(\int_0^1 f\right) \ge \int_0^1 \varphi(f)$（凹函数方向；凸函数则反向）。标准手法是"先对黎曼和用均值不等式，再令 $n \to \infty$"。$\ln$ 在两端式中连续，故极限可移入。）

### A3（第12届·第七题，2020年）｜难度：难

**方法标签**：含参积分序列极限 + 条件收敛 + 分部积分裂项（跨专题：级数）

设 $u_n = \displaystyle\int_0^1\frac{\mathrm{d}t}{(1+t^4)^n}$（$n\geq 1$）。

（1）证明数列 $\{u_n\}$ 收敛，并求极限 $\lim\limits_{n\to\infty}u_n$；

（2）证明级数 $\displaystyle\sum_{n=1}^\infty(-1)^nu_n$ 条件收敛；

（3）证明当 $p\geq 1$ 时级数 $\displaystyle\sum_{n=1}^\infty\frac{u_n}{n^p}$ 收敛，并求级数 $\displaystyle\sum_{n=1}^\infty\frac{u_n}{n}$ 的和。

**（跨专题：另见级数专题）**

> **解答**（官方参考答案）：
>
> （1）对任意 $\varepsilon > 0$，取 $0 < a < \dfrac{\varepsilon}{2}$，将积分区间分成两段，得
> $$u_n = \int_0^1\frac{\mathrm{d}t}{(1+t^4)^n} = \int_0^a\frac{\mathrm{d}t}{(1+t^4)^n} + \int_a^1\frac{\mathrm{d}t}{(1+t^4)^n}.$$
> 因为
> $$\int_a^1\frac{\mathrm{d}t}{(1+t^4)^n} \leq \frac{1-a}{(1+a^4)^n} < \frac{1}{(1+a^4)^n}\to 0\quad(n\to\infty),$$
> 所以存在正整数 $N$，当 $n > N$ 时，$\displaystyle\int_a^1\frac{\mathrm{d}t}{(1+t^4)^n} < \frac{\varepsilon}{2}$，从而
> $$0 \leq u_n < a + \int_a^1\frac{\mathrm{d}t}{(1+t^4)^n} < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon,$$
> 所以 $\lim\limits_{n\to\infty}u_n = 0$。……（4 分）
>
> （2）显然 $0 < u_{n+1} = \displaystyle\int_0^1\frac{\mathrm{d}t}{(1+t^4)^{n+1}} \leq \int_0^1\frac{\mathrm{d}t}{(1+t^4)^n} = u_n$，即 $u_n$ 单调递减，又 $\lim\limits_{n\to\infty}u_n = 0$，故由莱布尼兹判别法知，$\displaystyle\sum_{n=1}^\infty(-1)^nu_n$ 收敛。……（3 分）
>
> 另一方面，当 $n\geq 2$ 时，有
> $$u_n = \int_0^1\frac{\mathrm{d}t}{(1+t^4)^n} \geq \int_0^1\frac{\mathrm{d}t}{(1+t)^n} = \frac{1}{n-1}\left(1-2^{1-n}\right),$$
> 由于 $\displaystyle\sum_{n=2}^\infty\frac{1}{n-1}$ 发散，$\displaystyle\sum_{n=2}^\infty\frac{1}{n-1}\frac{1}{2^{n-1}}$ 收敛，所以 $\displaystyle\sum_{n=2}^\infty\frac{1}{n-1}\left(1-\frac{1}{2^{n-1}}\right)$ 发散，从而 $\displaystyle\sum_{n=1}^\infty u_n$ 发散。因此 $\displaystyle\sum_{n=1}^\infty(-1)^nu_n$ 条件收敛。……（3 分）
>
> （3）先求级数 $\displaystyle\sum_{n=1}^\infty\frac{u_n}{n}$ 的和。因为
> $$u_n = \int_0^1\frac{\mathrm{d}t}{(1+t^4)^n} = \left.\frac{t}{(1+t^4)^n}\right|_0^1 + n\int_0^1\frac{4t^4}{(1+t^4)^{n+1}}\,\mathrm{d}t = \frac{1}{2^n} + 4n\int_0^1\frac{t^4}{(1+t^4)^{n+1}}\,\mathrm{d}t$$
> $$= \frac{1}{2^n} + 4n\int_0^1\frac{1+t^4-1}{(1+t^4)^{n+1}}\,\mathrm{d}t = \frac{1}{2^n} + 4n\left(u_n - u_{n+1}\right),$$
> 所以
> $$\sum_{n=1}^\infty\frac{u_n}{n} = \sum_{n=1}^\infty\frac{1}{n2^n} + 4\sum_{n=1}^\infty\left(u_n - u_{n+1}\right) = \sum_{n=1}^\infty\frac{1}{n2^n} + 4u_1.$$
> 利用展开式 $\ln(1+x) = \displaystyle\sum_{n=1}^\infty(-1)^{n-1}\frac{x^n}{n}$，取 $x = -\dfrac{1}{2}$，得 $\displaystyle\sum_{n=1}^\infty\frac{1}{n2^n} = \ln 2$。而
> $$u_1 = \int_0^1\frac{\mathrm{d}t}{1+t^4} = \frac{\sqrt{2}}{8}\left[\pi + 2\ln\left(1+\sqrt{2}\right)\right].$$
> 因此
> $$\sum_{n=1}^\infty\frac{u_n}{n} = \ln 2 + \frac{\sqrt{2}}{2}\left[\pi + 2\ln\left(1+\sqrt{2}\right)\right].$$
> 最后，当 $p\geq 1$ 时，因为 $\dfrac{u_n}{n^p} \leq \dfrac{u_n}{n}$，且 $\displaystyle\sum_{n=1}^\infty\frac{u_n}{n}$ 收敛，所以 $\displaystyle\sum_{n=1}^\infty\frac{u_n}{n^p}$ 收敛。……（4 分）
>
> （整理注：本题的"引擎"是（3）中的分部积分恒等式 $u_n = \dfrac{1}{2^n} + 4n(u_n - u_{n+1})$——它把一个"看不出可求和"的积分序列改写成了可裂项（telescoping）的形式，这是"分部积分配恒等式"的典型用法。（1）中"剪去尾巴 $[a,1]$、留住头部 $[0,a]$"的两段估计，是含参积分序列 $\int_0^1 g^n \to 0$ 的标准证法。）

### A4（第13届·第五题，2021年）｜难度：难

**方法标签**：中点矩形公式误差估计 + Taylor 展开 + 夹逼

设函数 $f(x)$ 在闭区间 $[a,b]$ 上有连续的二阶导数，证明：
$$\lim_{n\to\infty}n^2\left[\int_a^b f(x)\,\mathrm{d}x-\frac{b-a}{n}\sum_{k=1}^n f\left(a+\frac{2k-1}{2n}(b-a)\right)\right]=\frac{(b-a)^2}{24}\left[f'(b)-f'(a)\right].$$

> **证明**（官方参考答案）：记 $x_k=a+\dfrac{k(b-a)}{n}$，$\xi_k=a+\dfrac{(2k-1)(b-a)}{2n}$，$k=1,2,\cdots,n$。将 $f(x)$ 在 $[x_{k-1},x_k]$ 上展开成泰勒公式，得
> $$f(x)=f(\xi_k)+f'(\xi_k)(x-\xi_k)+\frac{f''(\eta_k)}{2}(x-\xi_k)^2,$$
> 其中 $x\in[x_{k-1},x_k]$，$\eta_k$ 介于 $\xi_k$ 和 $x$ 之间。
>
> 于是 ……（4 分）
> $$B_n=\int_a^b f(x)\,\mathrm{d}x-\frac{b-a}{n}\sum_{k=1}^n f\left(a+\frac{2k-1}{2n}(b-a)\right)=\sum_{k=1}^n\int_{x_{k-1}}^{x_k}\left(f(x)-f(\xi_k)\right)\mathrm{d}x$$
> $$=\sum_{k=1}^n\int_{x_{k-1}}^{x_k}\left[f'(\xi_k)(x-\xi_k)+\frac{f''(\eta_k)}{2}(x-\xi_k)^2\right]\mathrm{d}x=\frac{1}{2}\sum_{k=1}^n\int_{x_{k-1}}^{x_k}f''(\eta_k)(x-\xi_k)^2\,\mathrm{d}x.$$
> 设 $f''(x)$ 在 $[x_{k-1},x_k]$ 上的最大值和最小值分别为 $M_k$，$m_k$，因为
> $$\int_{x_{k-1}}^{x_k}(x-\xi_k)^2\,\mathrm{d}x=\frac{(b-a)^3}{12n^3},$$
> 所以
> $$\frac{(b-a)^2}{24}\sum_{k=1}^n m_k\frac{b-a}{n}\leq n^2B_n\leq\frac{(b-a)^2}{24}\sum_{k=1}^n M_k\frac{b-a}{n}.$$
> ……（6 分）
>
> 因为 $f''(x)$ 在 $[a,b]$ 上连续，所以 $f''(x)$ 在 $[a,b]$ 上可积。根据定积分 $\displaystyle\int_a^b f''(x)\,\mathrm{d}x$ 的定义，及牛顿-莱布尼兹公式，得
> $$\lim_{n\to\infty}\sum_{k=1}^n m_k\frac{b-a}{n}=\lim_{n\to\infty}\sum_{k=1}^n M_k\frac{b-a}{n}=\int_a^b f''(x)\,\mathrm{d}x=f'(b)-f'(a).$$
> 再根据夹逼准则，得
> $$\lim_{n\to\infty}n^2B_n=\frac{(b-a)^2}{24}\left[f'(b)-f'(a)\right].$$
> ……（4 分）
>
> （整理注 1：第一行"$\sum\int(f-f(\xi_k))$ 中一次项 $\int(x-\xi_k)\mathrm{d}x = 0$"是关键——中点 $\xi_k$ 对称，一次项自动抵消，所以误差由二阶项主导，这正是"中点公式比一般黎曼和精确一阶"的原因。原卷在 $\eta_k$ 的区间与积分上下限处有笔误，已照上下文订正。）
>
> （整理注 2：将本题与 B8（第 06 届六）、B11（第 08 届四）对照，可得到完整的"矩形公式误差谱"：右（左）端点和误差一阶为 $\frac{(b-a)}{2}[f(b)-f(a)]$ 型（$n^{-1}$ 阶），中点公式误差一阶为 $\frac{(b-a)^2}{24}[f'(b)-f'(a)]$ 型（$n^{-2}$ 阶），后者恰好精确一整阶——这是数值积分中"中点法优于端点法"的定量表述。）

### A5（第14届·第四题，2022年）｜难度：难

**方法标签**：归纳法 + 分段估计 + 放缩 $\sin x \geqslant \frac{2}{\pi}x$

证明：对任意正整数 $n$，恒有：
$$\int_0^{\frac{\pi}{2}}x\left(\frac{\sin nx}{\sin x}\right)^4\mathrm{d}x \le \left(\frac{n^2}{4}-\frac{1}{8}\right)\pi^2.$$

> **证明**（官方参考答案）：首先，利用归纳法易证：对 $n\ge 1$，$|\sin nx|\le n\sin x$（$0\le x\le \dfrac{\pi}{2}$）。……（2 分）
>
> 又由于 $|\sin nx|\le 1$，及 $\sin x\ge \dfrac{2}{\pi}x$（$0\le x\le \dfrac{\pi}{2}$），……（2 分）
>
> 所以当 $n>1$ 时，得
> $$\int_0^{\frac{\pi}{2}}x\left(\frac{\sin nx}{\sin x}\right)^4\mathrm{d}x = \int_0^{\frac{\pi}{2n}}x\left(\frac{\sin nx}{\sin x}\right)^4\mathrm{d}x + \int_{\frac{\pi}{2n}}^{\frac{\pi}{2}}x\left(\frac{\sin nx}{\sin x}\right)^4\mathrm{d}x$$
> $$\le n^4\int_0^{\frac{\pi}{2n}}x\,\mathrm{d}x + \int_{\frac{\pi}{2n}}^{\frac{\pi}{2}}x\left(\frac{1}{2x/\pi}\right)^4\mathrm{d}x = \frac{n^4}{2}\left(\frac{\pi}{2n}\right)^2 + \frac{\pi^4}{16}\int_{\frac{\pi}{2n}}^{\frac{\pi}{2}}\frac{\mathrm{d}x}{x^3}$$
> $$= \frac{n^2\pi^2}{8} + \frac{\pi^4}{16}\cdot\left.\frac{1}{(-2x^2)}\right|_{\frac{\pi}{2n}}^{\frac{\pi}{2}} = \frac{n^2\pi^2}{8} - \frac{\pi^4}{16}\left(\frac{2}{\pi^2}-\frac{2n^2}{\pi^2}\right) = \left(\frac{n^2}{4}-\frac{1}{8}\right)\pi^2.$$
> ……（8 分）
>
> 当 $n = 1$ 时，$\displaystyle\int_0^{\frac{\pi}{2}}x\,\mathrm{d}x = \frac{\pi^2}{8}$，等号成立。……（2 分）
>
> （整理注：两个分界手法值得记住——① 在"贴近原点"的小区间 $\left(0,\frac{\pi}{2n}\right)$ 上用 $|\sin nx|\le n\sin x$（分子可用 $n\sin x$ 顶格放大）；② 在其余小区间上用 $|\sin nx|\le 1$ 配合正弦的下界 $\sin x\ge \frac{2}{\pi}x$ 把分母"顶格缩小"。两招合起来才得到 $\left(\frac{n^2}{4}-\frac{1}{8}\right)\pi^2$ 这个常数。）

### A6（第15届·第四题，2023年）｜难度：中

**方法标签**：含参积分序列极限：换元 + 分部积分 + 夹逼

设 $I_n = n\displaystyle\int_1^a \frac{\mathrm{d}x}{1+x^n}$，其中 $a > 1$。求极限 $\lim\limits_{n\to\infty} I_n$。

> **解答**（官方参考答案）：记 $b = \dfrac{1}{a}$，则 $0 < b < 1$。作变量替换 $x = \dfrac{1}{t}$，得到
> $$I_n = \int_b^1 \frac{nt^{n-1}}{t(1+t^n)}\mathrm{d}t = \int_b^1 \frac{\mathrm{d}\left(\ln(1+t^n)\right)}{t}.$$
> 分部积分得
> $$I_n = \ln 2 - \frac{\ln(1+b^n)}{b} + \int_b^1 \frac{\ln(1+t^n)}{t^2}\mathrm{d}t. \qquad\cdots\cdots\cdots\cdots \quad（8 分）$$
> 当 $t \in [b,1]$ 时，$\dfrac{\ln(1+t^n)}{t^2} \leqslant t^{n-2}$，
> $$0 \leqslant \int_b^1 \frac{\ln(1+t^n)}{t^2}\mathrm{d}t \leqslant \int_b^1 t^{n-2}\mathrm{d}t = \frac{1-b^{n-1}}{n-1}.$$
> 显然，$\lim\limits_{n\to\infty}\dfrac{1-b^{n-1}}{n-1} = 0$。由夹逼准则，$\lim\limits_{n\to\infty}\displaystyle\int_b^1 \frac{\ln(1+t^n)}{t^2}\mathrm{d}t = 0$。
> 又 $\lim\limits_{n\to\infty}\dfrac{\ln(1+b^n)}{b} = 0$，$\lim\limits_{n\to\infty} I_n = \ln 2$。……（14 分）
>
> （整理注：换元 $x = 1/t$ 把积分区间 $[1,a]$ 变成 $[b,1]$（$b<1$），这是让"$\frac{nt^{n-1}}{1+t^n}$ 这个恰当导数"显形的关键一步；$\frac{\ln(1+t^n)}{t^2} \le t^{n-2}$ 用了 $\ln(1+s)\le s$。可对照 A3（1）"剪尾估头"法，两者都是含参积分序列极限的标准武器。）

### A7（第15届·第五题，2023年）｜难度：中

**方法标签**：分部积分恒等式 + 柯西积分不等式 + 等号条件（化微分方程）

设 $f(x)$ 在 $[0,1]$ 上有连续的导数且 $f(0) = 0$. 求证:
$$\int_0^1 f^2(x)\,\mathrm{d}x \leqslant 4\int_0^1 (1-x)^2|f'(x)|^2\,\mathrm{d}x,$$
并求使上式成为等式的 $f(x)$.

> **解答**（官方参考答案）：由分部积分法
> $$\int_0^1 f^2(x)\mathrm{d}x = (x-1)f^2(x)\Big|_0^1 - \int_0^1 (x-1)2f(x)f'(x)\mathrm{d}x = 2\int_0^1 (1-x)f'(x)\cdot f(x)\mathrm{d}x.$$
> ……（4 分）
>
> 由 Cauchy 积分不等式, 有
> $$\int_0^1 (1-x)f'(x)\cdot f(x)\mathrm{d}x \leqslant \left(\int_0^1 (1-x)^2\left(f'(x)\right)^2\mathrm{d}x\right)^{\frac{1}{2}}\left(\int_0^1 f^2(x)\mathrm{d}x\right)^{\frac{1}{2}}.$$
> 于是
> $$\int_0^1 f^2(x)\mathrm{d}x \leqslant 4\int_0^1 (1-x)^2|f'(x)|^2\mathrm{d}x. \qquad\cdots\cdots\cdots\cdots \quad（10 分）$$
>
> 等式成立时应有常数 $c$ 使得 $(1-x)f'(x) = cf(x)$. 因此当 $x \in (0,1)$ 时, 有
> $$\left((1-x)^c f(x)\right)' = (1-x)^{c-1}\left((1-x)f'(x) - cf(x)\right) = 0.$$
> 因而存在常数 $d$ 使得 $f(x) = d(1-x)^{-c}$ $(0 < x < 1)$.
> 当 $x \to 0$ 时, $f(x) \to 0$, 故 $d = 0$. 于是 $f = 0$. 所以使得题中不等式成为等式的函数是 $f(x) = 0$. ……（14 分）
>
> （整理注：第一步分部积分中，把 $f^2$ 的"一个因子"配给 $\mathrm{d}(x-1)$，端点的 $(x-1)f^2(x)|_0^1 = 0$ 恰好由 $f(0) = 0$ 与 $x = 1$ 处的因子 $(1-x)$ 同时保证——这是"配权函数分部积分"的标准设计。等号条件 $(1-x)f' = cf$ 是一阶线性方程，凑全导数 $\left((1-x)^c f\right)' = 0$ 即可。）

### A8（第17届·第六题，2025年）｜难度：难

**方法标签**：分部积分配恒等式 + 二重积分转化 + 单调性

设函数 $f(x)$，$g(x)$ 在 $[a,b]$ 上连续可导且满足以下三个条件：

1. $\displaystyle\int_a^b f(x)\,\mathrm{d}x = \int_a^b g(x)\,\mathrm{d}x = 0$；
2. $f'(x)g(x) - f(x)g'(x) > 0$，$x \in [a,b]$；
3. $g(x)$ 在 $(a,b)$ 上有唯一零点 $\xi$。

证明：

**(1)** $\displaystyle\int_a^b f(x)\left(\int_a^x g(s)\,\mathrm{d}s\right)\mathrm{d}x = -\int_a^b g(x)\left(\int_a^x f(s)\,\mathrm{d}s\right)\mathrm{d}x$。

**(2)** $\displaystyle\int_a^b f(x)\left(\int_a^x g(s)\,\mathrm{d}s\right)\mathrm{d}x > 0$。

> **证明**（官方参考答案）：
>
> **(1)** 记 $F(x) = \displaystyle\int_a^x f(s)\,\mathrm{d}s$，$G(x) = \displaystyle\int_a^x g(s)\,\mathrm{d}s$，则由分部积分
> $$\int_a^b f(x)G(x)\,\mathrm{d}x = \int_a^b G(x)\,\mathrm{d}F(x) = -\int_a^b F(x)g(x)\,\mathrm{d}x,$$
> 这里用到了条件 $F(b) = G(b) = 0$。……（4 分）
>
> **(2)** 显然，$g'(\xi) \neq 0$，不妨设 $g'(\xi) > 0$，则在 $[a,\xi)$ 上 $g(x) < 0$，在 $(\xi, b]$ 上 $g(x) > 0$。
> $$\int_a^b f(x)\left(\int_a^x g(s)\,\mathrm{d}s\right)\mathrm{d}x = \frac{1}{2}\iint_D \left(f(x)g(s) - f(s)g(x)\right)\mathrm{d}x\,\mathrm{d}s,$$
> 其中 $D = \{(x,s) \mid a \leqslant s \leqslant x \leqslant b\}$。……（8 分）
>
> 把 $D$ 分成三部分：$D = D_1 \cup D_2 \cup D_3$，其中
> $$D_1 = \{(x,s) \mid a \leqslant s \leqslant x \leqslant \xi\},\quad D_2 = \{(x,s) \mid a \leqslant s \leqslant \xi \leqslant x \leqslant b\},\quad D_3 = \{(x,s) \mid \xi \leqslant s \leqslant x \leqslant b\}.$$
> 由条件 $f'(x)g(x) - f(x)g'(x) > 0$ 知 $\dfrac{f(x)}{g(x)}$ 在 $[a,\xi)$ 和 $(\xi, b]$ 上严格单调递增，从而在 $D_1$ 和 $D_3$ 上，$f(x)g(s) - f(s)g(x) \geqslant 0$ 且不恒等于 0，故
> $$\iint_{D_1\cup D_3}\left(f(x)g(s) - f(s)g(x)\right)\mathrm{d}x\,\mathrm{d}s > 0.$$
> ……（12 分）
>
> 又
> $$\iint_{D_2}\left(f(x)g(s) - f(s)g(x)\right)\mathrm{d}x\,\mathrm{d}s = \int_\xi^b f(x)\,\mathrm{d}x\int_a^\xi g(s)\,\mathrm{d}s - \int_\xi^b g(x)\,\mathrm{d}x\int_a^\xi f(s)\,\mathrm{d}s = 0,$$
> 最后一个等式用到了 $\displaystyle\int_\xi^b f(x)\,\mathrm{d}x = -\int_a^\xi f(s)\,\mathrm{d}s$，$\displaystyle\int_\xi^b g(x)\,\mathrm{d}x = -\int_a^\xi g(s)\,\mathrm{d}s$。
>
> 综上，$\displaystyle\int_a^b f(x)\left(\int_a^x g(s)\,\mathrm{d}s\right)\mathrm{d}x > 0$。……（14 分）
>
> （整理注 1：从"单重积分"到"二重积分"的转化是本题的枢纽。记 $L = \int_a^b f(x)G(x)\mathrm{d}x = \iint_{s \le x} f(x)g(s)$，交换 $x,s$ 得 $\iint_{s\le x} f(s)g(x) = \int_a^b g(x)F(x)\mathrm{d}x \overset{(1)}{=} -L$，于是
> $$L = \frac{1}{2}\left[L - (-L)\right] = \frac{1}{2}\iint_{D}\left(f(x)g(s) - f(s)g(x)\right).$$
> 这一步"凑出 $\frac{1}{2}$ 与反对称核"的技巧，与第 11 届第四题（球面按平面族分割、$\mathrm{d}S = 2\pi\,\mathrm{d}t$）中的对称化思想一脉相承。）
>
> （整理注 2：在 $D_1$ 上 $f(x)g(s) - f(s)g(x) = g(x)g(s)\left[\dfrac{f(x)}{g(x)} - \dfrac{f(s)}{g(s)}\right] \geqslant 0$（因 $x \ge s$、$g(x)g(s) > 0$ 且 $\frac{f}{g}$ 严格增）；$D_3$ 同理；而 $D_2$ 上的"对角"交叉项正好由条件 $\int_a^b f = \int_a^b g = 0$ 消掉——三个条件各司其职，缺一不可。）

### B1（第01届·第六题，2009年）｜难度：中

**方法标签**：旋转体体积最小 + 面积约束消元化二次函数

设抛物线 $y = ax^2 + bx + 2\ln c$ 过原点，当 $0 \leqslant x \leqslant 1$ 时，$y \geqslant 0$，又已知该抛物线与 $x$ 轴及直线 $x = 1$ 所围图形的面积为 $\dfrac{1}{3}$。试确定 $a, b, c$ 使此图形绕 $x$ 轴旋转一周而成的旋转体的体积 $V$ 最小。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：三个参数中 $c$ 由"过原点"直接定死；$a, b$ 被"面积 $= \frac{1}{3}$"绑成一条一次约束，于是体积 $V(a,b)$ 化为一元二次函数求最值；最后回验 $y \geqslant 0$ 在最优点处成立。
>
> **第一步：由"过原点"定 $c$。** $y(0) = 2\ln c = 0 \Rightarrow c = 1$（$c > 0$ 使 $\ln c$ 有意义）。
>
> **第二步：用面积写出约束。** 所围图形（曲线、$x$ 轴、$x = 1$，且题设 $y \geqslant 0$）的面积为
> $$\int_0^1\left(ax^2+bx\right)\mathrm{d}x = \frac{a}{3} + \frac{b}{2} = \frac{1}{3},\qquad 即\qquad 2a + 3b = 2. \tag{☆}$$
>
> **第三步：体积的最小化。** 绕 $x$ 轴旋转一周的体积为
> $$V = \pi\int_0^1\left(ax^2+bx\right)^2\mathrm{d}x = \pi\left(\frac{a^2}{5} + \frac{ab}{2} + \frac{b^2}{3}\right).$$
> 由 (☆) 解出 $a = 1 - \dfrac{3}{2}b$，代入得
> $$\frac{V}{\pi} = \frac{1}{5} - \frac{b}{10} + \frac{b^2}{30} = \frac{1}{30}\left(b - \frac{3}{2}\right)^2 + \frac{1}{8}.$$
> 故当 $b = \dfrac{3}{2}$ 时 $V$ 取最小值 $V_{\min} = \dfrac{\pi}{8}$，此时 $a = 1 - \dfrac{9}{4} = -\dfrac{5}{4}$。
>
> **第四步：回验 $y \geqslant 0$。** 在候选点，$y(x) = x\left(-\dfrac{5}{4}x + \dfrac{3}{2}\right)$，括号内关于 $x$ 线性递减，在 $x = 1$ 处取最小值 $-\dfrac{5}{4} + \dfrac{3}{2} = \dfrac{1}{4} > 0$，故 $0 \leqslant x \leqslant 1$ 时 $y \geqslant 0$ 成立，候选点合法。
>
> **结论**：$a = -\dfrac{5}{4}$，$b = \dfrac{3}{2}$，$c = 1$；此时 $V_{\min} = \dfrac{\pi}{8}$。$\blacksquare$
>
> （点评：消元方向自由（也可先解 $b$），要点是"约束是一次式"时最值必化为一元二次函数；最后一步"回验不等式条件"常被忽略但在竞赛里是必写步骤。）

### B2（第03届·第四题，2011年）｜难度：中

**方法标签**：物理应用（引力）+ 微元法 + 反常积分

在平面上，有一条从点 $(a, 0)$ 向右的射线，线密度为 $\rho$。在点 $(0, h)$ 处（其中 $h > 0$）有一质量为 $m$ 的质点。求射线对该质点的引力。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：微元法——射线上"一小段"对质点的引力按万有引力定律写出，水平、竖直分量分别积分。记引力常数为 $G$。
>
> **建模。** 射线为 $L: \{(x,0) \mid x \geqslant a\}$。取微元 $[x, x+\mathrm{d}x]$，其质量 $\mathrm{d}M = \rho\,\mathrm{d}x$，到质点 $P(0,h)$ 的距离 $r = \sqrt{x^2+h^2}$。该微元对 $P$ 的引力大小为
> $$\mathrm{d}F = \frac{Gm\,\mathrm{d}M}{r^2} = \frac{Gm\rho\,\mathrm{d}x}{x^2+h^2},$$
> 方向由 $P$ 指向 $(x,0)$，即沿向量 $(x,-h)$，故
> $$\mathrm{d}F_x = \frac{Gm\rho\,x}{(x^2+h^2)^{3/2}}\,\mathrm{d}x,\qquad \mathrm{d}F_y = -\frac{Gm\rho\,h}{(x^2+h^2)^{3/2}}\,\mathrm{d}x.$$
>
> **水平分量。**
> $$F_x = Gm\rho\int_a^{+\infty}\frac{x\,\mathrm{d}x}{(x^2+h^2)^{3/2}} = Gm\rho\left[-\frac{1}{\sqrt{x^2+h^2}}\right]_a^{+\infty} = \frac{Gm\rho}{\sqrt{a^2+h^2}}.$$
>
> **竖直分量。** 由 $\displaystyle\int\frac{\mathrm{d}x}{(x^2+h^2)^{3/2}} = \frac{x}{h^2\sqrt{x^2+h^2}}$，
> $$F_y = -Gm\rho h\int_a^{+\infty}\frac{\mathrm{d}x}{(x^2+h^2)^{3/2}} = -Gm\rho h\left(\frac{1}{h^2} - \frac{a}{h^2\sqrt{a^2+h^2}}\right) = -\frac{Gm\rho}{h}\left(1 - \frac{a}{\sqrt{a^2+h^2}}\right).$$
>
> **结论**：射线对质点的引力为
> $$\vec{F} = \left(\frac{Gm\rho}{\sqrt{a^2+h^2}},\ -\frac{Gm\rho}{h}\left(1-\frac{a}{\sqrt{a^2+h^2}}\right)\right) = \left(\frac{Gm\rho}{\sqrt{a^2+h^2}},\ -\frac{Gm\rho\,h}{\left(a+\sqrt{a^2+h^2}\right)\sqrt{a^2+h^2}}\right).$$
>
> **验算**：取 $a = 0$（射线从原点出发），得 $\vec{F} = \left(\dfrac{Gm\rho}{h}, -\dfrac{Gm\rho}{h}\right)$——方向恰为 $45°$（正右下方），与"半直线关于出发点对称"的直觉一致；又 $a \to +\infty$ 时 $\vec{F} \to \vec{0}$，也合理。$\blacksquare$
>
> （点评：第二分量用了等价变形 $\dfrac{\sqrt{a^2+h^2}-a}{h^2} = \dfrac{1}{\sqrt{a^2+h^2}\left(\sqrt{a^2+h^2}+a\right)}$，两种形式都可作答案；若题目给出 $a = 0$ 的特例，答案即为 $(Gm\rho/h)(1,-1)$，可用来快速核对。）

### B3（第04届·第五题，2012年）｜难度：中

**方法标签**：最佳常数：换元 + 放缩 + 取等（逼近）分析

求最小实数 $C$，使得满足 $\displaystyle\int_0^1 |f(x)|\,\mathrm{d}x = 1$ 的连续的函数 $f(x)$ 都有
$$\int_0^1 f(\sqrt{x})\,\mathrm{d}x \le C.$$

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**："求最小常数"分两步：先用放缩证明某个 $C$ 可行（上界），再构造逼近族证明任何更小的常数都不行（最优性）。
>
> **第一步：换元。** 令 $t = \sqrt{x}$（$x = t^2$，$\mathrm{d}x = 2t\,\mathrm{d}t$），则
> $$\int_0^1 f(\sqrt{x})\,\mathrm{d}x = \int_0^1 f(t)\cdot 2t\,\mathrm{d}t.$$
>
> **第二步：证明 $C = 2$ 可行。** 对任意满足 $\int_0^1|f| = 1$ 的连续函数，
> $$\int_0^1 f(t)\cdot 2t\,\mathrm{d}t \le \int_0^1|f(t)|\cdot 2t\,\mathrm{d}t \le 2\int_0^1|f(t)|\,\mathrm{d}t = 2,$$
> 其中用了 $0 \le 2t \le 2$（$t \in [0,1]$）。即 $C = 2$ 满足要求。
>
> **第三步：证明比 2 小不行。** 对任意 $\varepsilon \in (0,1)$，取连续函数 $f_\varepsilon \geqslant 0$，使 $\int_0^1 f_\varepsilon = 1$ 且 $f_\varepsilon$ 在 $[0, 1-\varepsilon]$ 上恒为 $0$（在 $[1-\varepsilon, 1]$ 上取值阶跃的连续磨光，例如线性插值的"高台"）。则 $\int_0^1|f_\varepsilon| = 1$，且
> $$\int_0^1 f_\varepsilon(t)\cdot 2t\,\mathrm{d}t \ge 2(1-\varepsilon)\int_0^1 f_\varepsilon(t)\,\mathrm{d}t = 2(1-\varepsilon).$$
> 令 $\varepsilon \to 0^+$，得上确界 $\geqslant 2$。故任何 $C < 2$ 都不满足要求。
>
> **结论**：最小实数 $C = 2$。$\blacksquare$
>
> （点评：等号对连续函数取不到——达到 2 要求 $|f|$ 的全部"质量"集中在 $t = 1$ 一点（即 $\delta$ 函数），连续函数只能逼近；但"最小实数 $C$"取的是上确界，故仍为 2。这类"最佳常数"题的固定答法是：换元 → 权函数取极值给上界 → 质量集中逼近给最优性。可对照 A1 的"双向估计"共同体会"两头卡"的思想。）

### B4（第05届·一(4)，2013年）｜难度：易

**方法标签**：切线 + 曲边图形面积（反解参数）

过曲线 $y=\sqrt[3]{x}\ (x\geqslant 0)$ 上的点 $A$ 作切线，使得该切线与曲线及 $x$ 轴所围成的平面图形的面积为 $\dfrac{3}{4}$。求点 $A$ 的坐标。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> 设 $A = \left(t,\ t^{1/3}\right)$（$t > 0$）。由 $y' = \dfrac{1}{3}x^{-2/3}$，切线斜率为 $k = \dfrac{1}{3}t^{-2/3}$，切线方程为
> $$y - t^{1/3} = \frac{1}{3}t^{-2/3}(x - t).$$
> 令 $y = 0$，解得 $x = -2t$，即切线与 $x$ 轴交于点 $B(-2t,\ 0)$。
>
> 所围图形由 $x$ 轴上的线段 $BO$、曲线弧 $OA$、切线段 $AB$ 围成，其面积为
> $$S = \underbrace{\frac{1}{2}\cdot 3t \cdot t^{1/3}}_{切线下[(-2t,0)\to(t,0)]的三角形} - \underbrace{\int_0^t x^{1/3}\,\mathrm{d}x}_{曲线下方区域} = \frac{3}{2}t^{4/3} - \frac{3}{4}t^{4/3} = \frac{3}{4}t^{4/3}.$$
> （切线是直线，其在 $[-2t, t]$ 上的"线下面积"就是直角三角形面积 $\frac{1}{2}\times 3t \times t^{1/3}$；又 $y = x^{1/3}$ 在 $x>0$ 上严格上凸，切线段位于曲线弧之上，故直接相减即得所围图形面积。）
>
> 由 $\dfrac{3}{4}t^{4/3} = \dfrac{3}{4}$ 得 $t^{4/3} = 1$，故 $t = 1$。
>
> **结论**：$A = (1,\ 1)$。$\blacksquare$
>
> （点评：求"切线与曲线围成面积"的题，先定切线与 $x$ 轴交点（$-2t$ 这个"两倍反向"是 $y = \sqrt[3]{x}$ 的专属性质），再把面积写成"三角形减曲边"；面积式是 $t$ 的单项幂函数，反解极易，属于本专题必须拿满分的送分题。）

### B5（第05届·第四题，2013年）｜难度：难

**方法标签**：换元 $t = f(x)$ + 按 $\sin$ 的符号分段估计

设 $|f(x)|\leqslant\pi$，$f'(x)\geqslant m>0\ (a\leqslant x\leqslant b)$，证明：$\left|\displaystyle\int_a^b\sin f(x)\,\mathrm{d}x\right|\leqslant\dfrac{2}{m}$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：$f' \geqslant m > 0$ 使 $f$ 严格递增、可逆，换元 $t = f(x)$ 后 $\mathrm{d}x = \dfrac{\mathrm{d}t}{f'(x)} \leqslant \dfrac{\mathrm{d}t}{m}$，把问题化为"$\int|\sin t|\,\mathrm{d}t$ 但被切成至多两块"。注意 $|\sin t|$ 在 $[-π,π]$ 任一单侧（$[−π,0]$ 或 $[0,π]$）上的总积分都不超过 2，且两块符号相反——这正是 $2/m$（而不是 $4/m$）的来源。
>
> **约定与准备。** 记反函数 $x = g(t)$（$t \in [f(a), f(b)]$），则 $g'(t) = \dfrac{1}{f'(x)} \leqslant \dfrac{1}{m}$，且由 $|f|\leqslant\pi$ 知 $[f(a), f(b)] \subseteq [-\pi, \pi]$。
>
> **情形一：$\sin f$ 在 $[a,b]$ 上不变号**（即 $f(a)$ 与 $f(b)$ 同号，或其中一个端点处 $f = 0$）。此时
> $$\left|\int_a^b\sin f(x)\,\mathrm{d}x\right| = \int_a^b|\sin f(x)|\,\mathrm{d}x \xrightarrow{\ t = f(x)\ } \int_{f(a)}^{f(b)}|\sin t|\,g'(t)\,\mathrm{d}t \leqslant \frac{1}{m}\int_{f(a)}^{f(b)}|\sin t|\,\mathrm{d}t.$$
> 若 $0 \leqslant f(a) < f(b) \leqslant \pi$，则 $\displaystyle\int_{f(a)}^{f(b)}|\sin t|\,\mathrm{d}t \leqslant \int_0^{\pi}\sin t\,\mathrm{d}t = 2$；若 $-\pi \leqslant f(a) < f(b) \leqslant 0$，同理 $\leqslant \displaystyle\int_{-\pi}^{0}(-\sin t)\,\mathrm{d}t = 2$。两种情形都给出 $\left|\int_a^b\sin f\right| \leqslant \dfrac{2}{m}$。
>
> **情形二：$f(a) < 0 < f(b)$。** 由 $f$ 严格递增，存在唯一 $x_0 \in (a, b)$ 使 $f(x_0) = 0$，且 $[f(a), 0] \subseteq [-\pi, 0]$，$[0, f(b)] \subseteq [0, \pi]$。分两段：
> $$A := \int_a^{x_0}\sin f(x)\,\mathrm{d}x \leqslant 0 \quad (\text{在 } [a,x_0] \text{ 上 } \sin f \leqslant 0), \qquad B := \int_{x_0}^b\sin f(x)\,\mathrm{d}x \geqslant 0.$$
> 对两段分别用情形一的换元估计（各段上 $\sin f$ 不变号）：
> $$|A| \leqslant \frac{1}{m}\int_{f(a)}^{0}|\sin t|\,\mathrm{d}t \leqslant \frac{2}{m},\qquad B \leqslant \frac{1}{m}\int_{0}^{f(b)}|\sin t|\,\mathrm{d}t \leqslant \frac{2}{m}.$$
> 于是 $-2/m \leqslant A + B \leqslant 2/m$（右端用 $A \leqslant 0$，左端用 $B \geqslant 0$），即 $\left|\displaystyle\int_a^b\sin f(x)\,\mathrm{d}x\right| \leqslant \dfrac{2}{m}$。$\blacksquare$
>
> **点评（最佳性）**：取 $f(x) = \pi x$，$[a, b] = [0, 1]$，则 $m = \pi$，$\left|\int_0^1\sin(\pi x)\,\mathrm{d}x\right| = \dfrac{2}{\pi} = \dfrac{2}{m}$，等号可取——常数 $2/m$ 不能再改进。本题是"换元 + 按符号分段 + 反向利用符号相消"的组合拳模板：若只机械地放大为 $\int|\sin f|$，会得到偏松的 $4/m$，务必体会"两块符号相反"这一免费折扣。

### B6（第06届·第四题，2014年）｜难度：中

**方法标签**：球缺体积 / 球冠面积公式推导 + 补面 Gauss（跨专题：曲面积分）

**(1)** 设一球缺高为 $h$，所在球半径为 $R$。证明该球缺的体积为
$$\frac{\pi}{3}(3R - h)h^2,$$
球冠的面积为 $2\pi R h$。

**(2)** 设球体 $(x-1)^2 + (y-1)^2 + (z-1)^2 \leq 12$ 被平面 $P: x + y + z = 6$ 所截的小球缺为 $\Omega$。记球缺上的球冠为 $\Sigma$，方向指向球外，求第二型曲面积分
$$I = \iint_{\Sigma} x\,\mathrm{d}y\,\mathrm{d}z + y\,\mathrm{d}z\,\mathrm{d}x + z\,\mathrm{d}x\,\mathrm{d}y.$$

**（跨专题：第二问另见曲面积分专题）**

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **（1）体积公式。** 取球心为原点、球缺以 $z$ 轴为对称轴（球缺为 $z \in [R-h, R]$ 与球体相交的部分），用垂直于 $z$ 轴的平面截：高度 $z$ 处截面是半径 $\sqrt{R^2-z^2}$ 的圆盘，故
> $$V = \int_{R-h}^{R}\pi\left(R^2 - z^2\right)\mathrm{d}z = \pi\left[R^2z - \frac{z^3}{3}\right]_{R-h}^{R} = \frac{\pi}{3}h^2(3R-h).$$
> （展开验证：$\pi\left[ \frac{2R^3}{3} - R^2(R-h) + \frac{(R-h)^3}{3} \right] = \pi\left[Rh^2 - \frac{h^3}{3}\right] = \frac{\pi}{3}h^2(3R-h)$。）
>
> **球冠面积。** 用球面面积微元 $\mathrm{d}S = R^2\sin\varphi\,\mathrm{d}\varphi\,\mathrm{d}\theta$（$\varphi$ 为球心角，自球缺顶端量起）。设球冠对应 $\varphi \in [0, \varphi_0]$，则 $h = R(1 - \cos\varphi_0)$。于是
> $$S = \int_0^{2\pi}\!\!\int_0^{\varphi_0} R^2\sin\varphi\,\mathrm{d}\varphi\,\mathrm{d}\theta = 2\pi R^2(1 - \cos\varphi_0) = 2\pi R^2\cdot\frac{h}{R} = 2\pi R h.$$
>
> **（2）** 球心 $C(1,1,1)$，半径 $R = 2\sqrt{3}$；平面 $P$ 到球心的距离
> $$d = \frac{|1+1+1-6|}{\sqrt{1^2+1^2+1^2}} = \sqrt{3}.$$
> 小球缺为 $x+y+z \geqslant 6$ 一侧（不含球心），由 (1)，球缺高 $h = R - d = \sqrt{3}$。
>
> 记 $\Sigma_0$ 为平面 $x+y+z = 6$ 上被球截得的圆盘（半径 $\sqrt{R^2 - d^2} = 3$，面积 $S_0 = 9\pi$），取指向球缺外部的方向（即 $-\dfrac{(1,1,1)}{\sqrt{3}}$）为其正向。对闭曲面 $\Sigma + \Sigma_0$ 围成的球缺体 $\Omega$ 用 Gauss 公式：
> $$I + \iint_{\Sigma_0} x\,\mathrm{d}y\,\mathrm{d}z + y\,\mathrm{d}z\,\mathrm{d}x + z\,\mathrm{d}x\,\mathrm{d}y = \iiint_{\Omega} 3\,\mathrm{d}V = 3V.$$
> 而
> $$V = \frac{\pi}{3}h^2(3R - h) = \frac{\pi}{3}\cdot 3\cdot\left(6\sqrt{3} - \sqrt{3}\right) = 5\sqrt{3}\,\pi,$$
> 在 $\Sigma_0$ 上 $x + y + z \equiv 6$ 且外法向为 $-\dfrac{(1,1,1)}{\sqrt{3}}$，故
> $$\iint_{\Sigma_0} x\,\mathrm{d}y\,\mathrm{d}z + y\,\mathrm{d}z\,\mathrm{d}x + z\,\mathrm{d}x\,\mathrm{d}y = \iint_{\Sigma_0}(x,y,z)\cdot\frac{-(1,1,1)}{\sqrt{3}}\,\mathrm{d}S = -\frac{6\cdot 9\pi}{\sqrt{3}} = -18\sqrt{3}\,\pi.$$
> 因此
> $$I = 3V + 18\sqrt{3}\,\pi = 15\sqrt{3}\,\pi + 18\sqrt{3}\,\pi = 33\sqrt{3}\,\pi.$$
>
> （验算：也可直接参数化——球冠上外法向 $\vec{n} = \dfrac{(x-1,y-1,z-1)}{R}$，$I = \dfrac{1}{R}\iint_\Sigma\left[(x^2+y^2+z^2) - (x+y+z)\right]\mathrm{d}S$，在球面上化得被积函数 $= \dfrac{9 + (x+y+z)}{R}$；再用"球冠等距切片面积微元 $\mathrm{d}S = 2\pi R\,\mathrm{d}t$"及对称性算得 $\iint_\Sigma (x+y+z)\,\mathrm{d}S = 90\pi$、$\iint_\Sigma \mathrm{d}S = 12\pi$，代入同样得 $I = 33\sqrt{3}\,\pi$。两法一致。）$\blacksquare$
>
> （点评：(1) 的两个公式是常备结论（分片/切片法各管一个）；(2) 中"平面截球得球缺，高 $h = R - d$"要按"小缺在不含球心的一侧"判断方向，补面 Gauss 时该圆盘的外法向取 $-n_0$ 别搞反——这是本题最易失分处。）

### B7（第06届·第五题，2014年）｜难度：中

**方法标签**：$[f]^n$ 积分平均值 + 夹逼（积分中值思想）

设 $f$ 在 $[a,b]$ 上非负连续，严格单增，且存在 $x_n \in [a,b]$ 使得
$$[f(x_n)]^n = \frac{1}{b-a}\int_a^b [f(x)]^n\,\mathrm{d}x,$$
求 $\lim\limits_{n\to\infty} x_n$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：$[f(x_n)]^n$ 是 $f^n$ 在 $[a,b]$ 上的"平均值"。对严格单增的 $f$，平均值被最大值 $[f(b)]^n$ 严格控制（这给出 $x_n < b$）；而随着 $n$ 增大，平均值又被 $b$ 附近的贡献快速支配（这给出 $x_n$ 任意接近 $b$）。两头夹出 $x_n \to b$。
>
> **第一步：任何满足条件的 $x_n$ 都满足 $x_n < b$。** 因 $f$ 严格单增，$x < b$ 时 $f(x) < f(b)$，故 $[f]^n$ 在 $[a,b]$ 上严格单增，于是
> $$\frac{1}{b-a}\int_a^b [f(x)]^n\,\mathrm{d}x < [f(b)]^n,$$
> 即 $[f(x_n)]^n < [f(b)]^n$，故 $f(x_n) < f(b)$，再由 $f$ 严格单增得 $x_n < b$。
>
> **第二步：对任意 $c \in (a,b)$，当 $n$ 充分大时 $x_n > c$。** 取 $t = \dfrac{c+b}{2} \in (c, b)$。因 $f$ 严格单增且非负，有 $f(t) > f(c) > 0$。注意 $[f]^n$ 单增，故在 $[t, b]$ 上 $[f]^n \geqslant [f(t)]^n$，于是
> $$\frac{1}{b-a}\int_a^b [f(x)]^n\,\mathrm{d}x \geqslant \frac{1}{b-a}\int_t^b [f(x)]^n\,\mathrm{d}x \geqslant \frac{b-t}{b-a}[f(t)]^n = \frac{b-t}{b-a}\left[\frac{f(t)}{f(c)}\right]^n[f(c)]^n.$$
> 因 $\dfrac{f(t)}{f(c)} > 1$，存在 $N$，当 $n > N$ 时 $\dfrac{b-t}{b-a}\left[\dfrac{f(t)}{f(c)}\right]^n > 1$。此时平均值 $> [f(c)]^n$，即 $[f(x_n)]^n > [f(c)]^n$，故 $x_n > c$。
>
> **第三步：结论。** 对任意 $c \in (a,b)$，当 $n$ 充分大时 $c < x_n < b$，故 $\lim\limits_{n\to\infty} x_n = b$。（结论与 $x_n$ 的具体选取无关。）$\blacksquare$
>
> （点评：本题与 A4 的"剪尾估头"恰好互补——那里把质量留在原点附近的小区间，这里把信息集中在右端点附近的大值区间。核心技术是"用 $\left[\frac{f(t)}{f(c)}\right]^n \to \infty$ 把任意固定水平的贡献放大到大于 1"。）

### B8（第06届·第六题，2014年）｜难度：中

**方法标签**：黎曼和（右端点）误差的高阶估计 + 夹逼

设
$$A_n = \frac{n}{n^2+1} + \frac{n}{n^2+2^2} + \cdots + \frac{n}{n^2+n^2},$$
求 $\lim\limits_{n\to\infty} n\left(\frac{\pi}{4} - A_n\right)$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：$A_n = \frac{1}{n}\sum\limits_{k=1}^n g\!\left(\frac{k}{n}\right)$ 是 $g(x) = \dfrac{1}{1+x^2}$ 的右端点黎曼和。误差 $n\left(\int_0^1 g - A_n\right)$ 的主项来自每个小区间上"$g$ 与其右端点值的偏差"——先对 $g$ 作线性化把主项提出来，再用一致连续性把高阶余项压到零。
>
> **第一步：写出黎曼和与极限。** $A_n = \dfrac{1}{n}\sum\limits_{k=1}^n \dfrac{1}{1 + (k/n)^2}$，故 $A_n \to \displaystyle\int_0^1\frac{\mathrm{d}x}{1+x^2} = \frac{\pi}{4}$。
>
> **第二步：误差的线性化。** 记 $g(x) = \dfrac{1}{1+x^2}$，$I_k = \left[\dfrac{k-1}{n}, \dfrac{k}{n}\right]$。则
> $$n\left(\frac{\pi}{4} - A_n\right) = n\sum_{k=1}^n\left[\int_{I_k} g(x)\,\mathrm{d}x - \frac{1}{n}g\!\left(\frac{k}{n}\right)\right] = n\sum_{k=1}^n\int_{I_k}\left[g(x) - g\!\left(\frac{k}{n}\right)\right]\mathrm{d}x.$$
> 对 $x \in I_k$ 由微分中值定理，$g(x) - g\left(\frac{k}{n}\right) = g'(\xi_{x,k})\left(x - \frac{k}{n}\right)$；又 $g'$ 在 $[0,1]$ 上连续，故一致连续，记其连续模 $\omega(\delta) := \sup_{|u-v|\le\delta}|g'(u)-g'(v)|$，$\omega(\delta) \to 0\ (\delta \to 0^+)$。于是
> $$g(x) - g\!\left(\frac{k}{n}\right) = g'\!\left(\frac{k}{n}\right)\left(x - \frac{k}{n}\right) + R_k(x), \qquad |R_k(x)| \leqslant \omega\!\left(\frac{1}{n}\right)\left|x - \frac{k}{n}\right|.$$
>
> **第三步：主项与余项。** 注意到 $\displaystyle\int_{I_k}\left(x - \frac{k}{n}\right)\mathrm{d}x = -\frac{1}{2n^2}$，故
> $$n\left(\frac{\pi}{4} - A_n\right) = \underbrace{-\frac{1}{2n}\sum_{k=1}^n g'\!\left(\frac{k}{n}\right)}_{\text{主项}} + \underbrace{n\sum_{k=1}^n\int_{I_k}R_k(x)\,\mathrm{d}x}_{\text{余项}}.$$
> 主项：$-\dfrac{1}{2n}\sum\limits_{k=1}^n g'\!\left(\frac{k}{n}\right) \to -\dfrac{1}{2}\displaystyle\int_0^1 g'(x)\,\mathrm{d}x = -\frac{1}{2}\left[g(1) - g(0)\right] = -\frac{1}{2}\left(\frac{1}{2} - 1\right) = \frac{1}{4}$。
> 余项：由 $\displaystyle\sum_{k=1}^n\int_{I_k}\left|x - \frac{k}{n}\right|\mathrm{d}x = \sum_{k=1}^n\frac{1}{2n^2} = \frac{1}{2n}$，
> $$\left|n\sum_{k=1}^n\int_{I_k}R_k\,\mathrm{d}x\right| \leqslant n\,\omega\!\left(\frac{1}{n}\right)\cdot\frac{1}{2n} = \frac{1}{2}\omega\!\left(\frac{1}{n}\right) \to 0.$$
>
> **结论**：$\displaystyle\lim_{n\to\infty} n\left(\frac{\pi}{4} - A_n\right) = \frac{1}{4}$。$\blacksquare$
>
> （点评：误差主项 $-\frac{1}{2}\int_0^1 g' = \frac{g(0)-g(1)}{2}$ 是"右端点矩形公式误差"的一般公式（详见 B11）；本题取 $g(0)-g(1) = \frac{1}{2}$。数值核对：$n = 10$ 时 $n(\pi/4 - A_n) \approx 0.254$，正在逼近 $0.25$。）

### B9（第07届·第五题，2015年）｜难度：中

**方法标签**：积分估值 + 反证 + 介值定理

设函数 $f$ 在 $[0,1]$ 上连续，且 $\displaystyle\int_0^1 f(x)\,\mathrm{d}x=0$，$\displaystyle\int_0^1 xf(x)\,\mathrm{d}x=1$。试证：

**(1)** $\exists\,x_0\in[0,1]$ 使得 $|f(x_0)|>4$；

**(2)** $\exists\,x_1\in[0,1]$ 使得 $|f(x_1)|=4$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：两个条件积分可配成"关于中心 $\frac{1}{2}$ 的一阶矩"：由 $\int_0^1 f = 0$ 得 $\int_0^1\left(x-\frac{1}{2}\right)f(x)\,\mathrm{d}x = 1$，而权函数 $\left|x-\frac{1}{2}\right|$ 的总量为 $\frac{1}{4}$——若 $|f|\le 4$ 则积分至多为 $4 \times \frac{1}{4} = 1$，恰好达到临界，于是整数值 4 被"逼"出来。
>
> **（1）** 反证法。设对一切 $x \in [0,1]$，$|f(x)| \le 4$。由 $\int_0^1 f = 0$，
> $$1 = \int_0^1 xf(x)\,\mathrm{d}x = \int_0^1\left(x - \frac{1}{2}\right)f(x)\,\mathrm{d}x,$$
> 于是
> $$1 = \left|\int_0^1\left(x - \frac{1}{2}\right)f(x)\,\mathrm{d}x\right| \le \int_0^1\left|x - \frac{1}{2}\right||f(x)|\,\mathrm{d}x \le 4\int_0^1\left|x - \frac{1}{2}\right|\mathrm{d}x = 4\cdot\frac{1}{4} = 1.$$
> 全链取等号，故 $\displaystyle\int_0^1\left(4 - |f(x)|\right)\left|x - \frac{1}{2}\right|\mathrm{d}x = 0$。被积函数非负连续，故对一切 $x \ne \frac{1}{2}$ 有 $|f(x)| = 4$，再由 $f$ 连续得 $|f(x)| \equiv 4$。于是 $f \equiv 4$ 或 $f \equiv -4$（$f$ 连续且处处非零，不变号），与 $\int_0^1 f = 0$ 矛盾。故存在 $x_0$ 使 $|f(x_0)| > 4$。
>
> **（2）** 由 $\int_0^1 f = 0$ 且 $f$ 不恒为 $0$（第一问已证存在 $|f(x_0)|>4$），连续函数 $f$ 在 $[0,1]$ 上必取正值与负值各至少一次，由介值定理存在 $x_2 \in [0,1]$ 使 $f(x_2) = 0$，即 $|f(x_2)| = 0 < 4 < |f(x_0)|$。$|f|$ 连续，在 $x_0$ 与 $x_2$ 之间由介值定理，存在 $x_1$ 使 $|f(x_1)| = 4$。$\blacksquare$
>
> （点评：第一问的等号分析要点是"非负连续函数积分为零 $\Rightarrow$ 恒为零"；把 $\int xf$ 与 $\int f = 0$ 合并成 $\int\left(x-\frac{1}{2}\right)f$ 是本题的题眼——中心化的设计使 $\left|x-\frac{1}{2}\right|$ 的积分恰好等于 $\frac{1}{4}$。第二问则说明 4 是"恰好达到"的临界值。）

### B10（第08届·第二题，2016年）｜难度：中

**方法标签**：变限积分辅助函数 + 两级单调性（积分不等式）

设 $f(x)$ 在 $[0,1]$ 上可导，$f(0) = 0$，且当 $x \in (0,1)$，$0 < f'(x) < 1$。试证：当 $a \in (0,1)$ 时，有
$$\left(\int_0^a f(x)\,\mathrm{d}x\right)^2 > \int_0^a f^3(x)\,\mathrm{d}x.$$

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：待证式两端都是 $a$ 的变限积分（左端是积分的平方），自然构造 $F(x) = \left(\int_0^x f\right)^2 - \int_0^x f^3$，验证 $F(0) = 0$ 后只需证 $F' > 0$。求导后出现 $f(x)\left[2\int_0^x f - f^2(x)\right]$，还差一个辅助不等式 "$2\int_0^x f > f^2(x)$"，它恰又是一个"两级单调性"问题。
>
> **第一步：证明 $f(x) > 0$（$x \in (0,1]$）。** 由 $f(0) = 0$ 及微分中值定理，存在 $\xi \in (0,x)$ 使 $f(x) = f(x) - f(0) = f'(\xi)x > 0$。
>
> **第二步：证明 $2\displaystyle\int_0^x f(t)\,\mathrm{d}t > f^2(x)$（$x \in (0,1]$）。** 令
> $$G(x) = 2\int_0^x f(t)\,\mathrm{d}t - f^2(x), \qquad x \in [0,1].$$
> 则 $G$ 在 $[0,1]$ 上连续、在 $(0,1)$ 内可导，$G(0) = 0$，且
> $$G'(x) = 2f(x) - 2f(x)f'(x) = 2f(x)\left[1 - f'(x)\right] > 0 \qquad (0 < x < 1),$$
> 这里用了第一步的 $f(x) > 0$ 与题设 $f'(x) < 1$。故 $G$ 在 $[0,1]$ 上严格递增，$G(x) > G(0) = 0$。
>
> **第三步：证明原不等式。** 令
> $$F(x) = \left(\int_0^x f(t)\,\mathrm{d}t\right)^2 - \int_0^x f^3(t)\,\mathrm{d}t, \qquad x \in [0,1].$$
> 则 $F$ 在 $[0,1]$ 上连续、在 $(0,1)$ 内可导，$F(0) = 0$，且
> $$F'(x) = 2\left(\int_0^x f(t)\,\mathrm{d}t\right) f(x) - f^3(x) = f(x)\left[2\int_0^x f(t)\,\mathrm{d}t - f^2(x)\right] = f(x)\,G(x) > 0 \qquad (0 < x < 1),$$
> 这里用了第一步与第二步。故 $F$ 在 $[0,1]$ 上严格递增，于是对 $a \in (0,1)$，
> $$F(a) > F(0) = 0, \qquad 即 \qquad \left(\int_0^a f(x)\,\mathrm{d}x\right)^2 > \int_0^a f^3(x)\,\mathrm{d}x. \qquad \blacksquare$$
>
> （点评：题设 $0 < f' < 1$ 的两半各用一次：$f' > 0$ 保证 $f > 0$ 与 $f$ 单增；$f' < 1$ 在 $G'$ 的符号中起决定作用。另注意题中只需 $f' > 0$ 与 $f' < 1$ 两个方向，缺一不可。）

### B11（第08届·第四题，2016年）｜难度：中

**方法标签**：黎曼和（右端点）误差的一般定理 + 一致连续性

设函数 $f(x)$ 在闭区间 $[0,1]$ 上具有连续导数，$f(0) = 0$，$f(1) = 1$。证明：
$$\lim_{n\to\infty} n\left(\int_0^1 f(x)\,\mathrm{d}x - \frac{1}{n}\sum_{k=1}^n f\!\left(\frac{k}{n}\right)\right) = -\frac{1}{2}.$$

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：先证一般结论——对任意 $g \in C^1[0,1]$，
> $$\lim_{n\to\infty} n\left(\int_0^1 g(x)\,\mathrm{d}x - \frac{1}{n}\sum_{k=1}^n g\!\left(\frac{k}{n}\right)\right) = \frac{g(0) - g(1)}{2}, \tag{★}$$
> 再取 $g = f$ 即得。证明骨架与 B8 相同：线性化提出主项，一致连续性压掉余项。
>
> **证明 (★)。** 记 $I_k = \left[\frac{k-1}{n}, \frac{k}{n}\right]$。则
> $$n\left(\int_0^1 g - \frac{1}{n}\sum_{k=1}^n g\!\left(\frac{k}{n}\right)\right) = n\sum_{k=1}^n\int_{I_k}\left[g(x) - g\!\left(\frac{k}{n}\right)\right]\mathrm{d}x.$$
> 因 $g'$ 在 $[0,1]$ 上连续从而一致连续，记连续模 $\omega(\delta) = \sup\limits_{|u-v|\le\delta}|g'(u) - g'(v)|$（$\omega(\delta)\to 0$，$\delta\to 0^+$），则对 $x \in I_k$（由中值定理）
> $$g(x) - g\!\left(\frac{k}{n}\right) = g'\!\left(\frac{k}{n}\right)\left(x - \frac{k}{n}\right) + R_k(x), \qquad |R_k(x)| \leqslant \omega\!\left(\frac{1}{n}\right)\left|x - \frac{k}{n}\right|.$$
> 于是原式
> $$= -\,\frac{1}{2n}\sum_{k=1}^n g'\!\left(\frac{k}{n}\right) + n\sum_{k=1}^n\int_{I_k}R_k(x)\,\mathrm{d}x,$$
> （用了 $\displaystyle\int_{I_k}\left(x - \frac{k}{n}\right)\mathrm{d}x = -\frac{1}{2n^2}$）。第一项是 $g'$ 的黎曼和，趋于 $-\dfrac{1}{2}\displaystyle\int_0^1 g'(x)\,\mathrm{d}x = \dfrac{g(0)-g(1)}{2}$；第二项由 $\sum_{k=1}^n\int_{I_k}\left|x-\frac{k}{n}\right|\mathrm{d}x = \frac{1}{2n}$ 有估计
> $$\left|n\sum_{k=1}^n\int_{I_k}R_k\,\mathrm{d}x\right| \leqslant \frac{1}{2}\omega\!\left(\frac{1}{n}\right) \to 0.$$
> 故 (★) 成立。
>
> **本题。** 取 $g = f$：极限 $= \dfrac{f(0) - f(1)}{2} = \dfrac{0 - 1}{2} = -\dfrac{1}{2}$。$\blacksquare$
>
> （点评：与 B8 对照记忆——"右端点和"的误差一阶为 $\frac{(b-a)(g(a)-g(b))}{2}$ 型；若把和改成左端点和 $L_n = \frac{1}{n}\sum_{k=0}^{n-1}g(k/n)$，同样推导得 $n(\int g - L_n) \to \frac{g(1)-g(0)}{2}$（两个端点各半）。这张"误差表"配上 A4 的中点公式是数值积分误差的完整入门版。）

### B12（第09届·第四题，2017年）｜难度：难

**方法标签**：构造含参积分 $F(t)$ + 关键恒等式 $F'' = F - 2f$ + 分部积分

设函数 $f(x) > 0$ 且在实轴上连续，若对任意实数 $t$，有 $\displaystyle\int_{-\infty}^{+\infty} e^{-|t-x|}f(x)\,\mathrm{d}x \le 1$。证明：$\forall a,b$，$a < b$，有 $\displaystyle\int_a^b f(x)\,\mathrm{d}x \le \dfrac{b-a+2}{2}$。

> **解答**（本解答由备考项目编写，非官方答案）：
>
> **关键想法**：记 $F(t) = \displaystyle\int_{-\infty}^{+\infty} e^{-|t-x|}f(x)\,\mathrm{d}x$（题设给出 $F \le 1$）。核函数 $e^{-|t-x|}$ 满足 $(1 - \frac{\mathrm{d}^2}{\mathrm{d}t^2})e^{-|t-x|} = 2\delta(t-x)$，故 $F'' = F - 2f$——**$f$ 可以用 $F$ 及其导数表出**：$f = \frac{F - F''}{2}$。再把区间上的积分用 $F$、$F'$ 表示，用 $F \le 1$ 与 $|F'| \le F$ 封口。
>
> **第一步：$F$ 的分解与求导。** 把积分拆成两半：
> $$F(t) = \underbrace{e^{-t}\int_{-\infty}^{t} e^{x}f(x)\,\mathrm{d}x}_{=: B(t)} + \underbrace{e^{t}\int_{t}^{+\infty} e^{-x}f(x)\,\mathrm{d}x}_{=: A(t)}.$$
> （两半各自收敛且有限：$B(t) \le F(t) \le 1$，$A(t) \le F(t) \le 1$。）直接求导（被积函数连续，两个边界项恰好抵消）：
> $$F'(t) = -e^{-t}\int_{-\infty}^{t} e^{x}f(x)\,\mathrm{d}x + e^{t}\int_{t}^{+\infty} e^{-x}f(x)\,\mathrm{d}x = A(t) - B(t).$$
> 由于 $A \ge 0$、$B \ge 0$ 且 $A + B = F$，得到关键的不等式串
> $$|F'(t)| = |A(t) - B(t)| \le A(t) + B(t) = F(t) \le 1. \tag{1}$$
>
> **第二步：关键恒等式 $F'' = F - 2f$。** 对 $A, B$ 再求导：$A'(t) = A(t) - f(t)$，$B'(t) = -B(t) + f(t)$，故
> $$F''(t) = A'(t) - B'(t) = A(t) + B(t) - 2f(t) = F(t) - 2f(t), \qquad 即 \qquad f(t) = \frac{F(t) - F''(t)}{2}. \tag{2}$$
>
> **第三步：区间积分估计。** 由 (2) 与 Newton-Leibniz 公式，
> $$\int_a^b f(x)\,\mathrm{d}x = \frac{1}{2}\int_a^b\left[F(x) - F''(x)\right]\mathrm{d}x = \frac{1}{2}\left[\int_a^b F(x)\,\mathrm{d}x - F'(b) + F'(a)\right].$$
> 由 $F \le 1$：$\displaystyle\int_a^b F(x)\,\mathrm{d}x \le b - a$；由 (1)：$-F'(b) + F'(a) \le |F'(b)| + |F'(a)| \le F(b) + F(a) \le 2$。两式相加得
> $$\int_a^b f(x)\,\mathrm{d}x \le \frac{1}{2}\left[(b-a) + 2\right] = \frac{b-a+2}{2}. \qquad \blacksquare$$
>
> **点评（最优性）**：当 $b-a$ 很小时该上界是渐近最优的——例如把质量为 $m$ 的两份集中在 $a$、$b$ 附近（用连续"高台"函数逼近 $\delta$），则约束 $F(a) \approx m(1 + e^{-(b-a)}) \le 1$ 给出 $m \approx \frac{1}{2} + \frac{b-a}{4}$，从而 $\int_a^b f \approx 2m \approx 1 + \frac{b-a}{2} = \frac{b-a+2}{2}$。本题最值得记住的是"用核函数的二阶恒等式把 $f$ 换成 $F$ 的表达式"这一思路——它把"逐点的 $f$ 估计"转成了"整体量 $F$ 的估计"，是积分不等式里少见的"算子反演"型技巧。
