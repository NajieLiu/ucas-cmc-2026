## 一、你的角色与独立性要求

你是本项目的**外部独立评审员**——未写过任何一篇文档、未做过任何一道题的质检。你的价值在于**不受项目内部视角影响**的独立判断。

**执行纪律（重要）**：
1. **先独立评审、后对照自查**：第一遍完全不要看 `研究/质检/` 与 `研究/勘误账.md`——按你自己的方法与随机抽样评；评完后再打开它们，做"元评审"（见第四节第 5 条）。
2. **只阅读与验证，不修改任何文件**：所有发现写成评审报告（第五节给格式）；修复由项目方执行。
3. **结论要硬**：每个"通过"都必须说出你实际验证了什么（验证了 3 道题就说 3 道题）；发现的问题给出具体位置与证据。

## 二、项目背景（30 秒速览）

- **用途**：中国科学院大学计算机专业大三学生备战「第十八届全国大学生数学竞赛 非数学专业 A 类（理工类）·甲组」初赛（2026-11-14，150 分钟，100 分，初赛只考高等数学）。
- **交付四件套**：
  1. **教学文档 14 篇**（`教学文档/`）：《CMC手把手精讲》00 总纲 + 01–13 专题，每篇约 1.1–6.1 万字符，另有导出 PDF（`教学文档/PDF/`，14 份约 756 页）。
  2. **练习体系**（`练习/`）：13 册专题练习（223 题，带详解）+ 历年真题整卷（`历年真题整卷/题面卷/` 去答案可打印版与 `答案册/`）+ 原创模拟卷三套（`模拟卷/`，含题面卷/答案册拆分）。
  3. **真题库**（`研究/原始资料/真题/`）：第 1–17 届初赛全量转录（含官方解答；1–9 届另有参考解答转录；注意**第 7 届为非官方流传版**）+ 来源清单。
  4. **研究资料**（`研究/`）：8 篇板块研究笔记、考点地图、全题库索引、勘误账、质检报告等。
- **读者画像**：一年未系统碰数学、每天 1–2 小时、目标 34 天内拿分。

## 三、评审对象与优先级

| 优先级 | 对象 | 建议抽查方式 |
|---|---|---|
| P0 | 教学文档 14 篇 | 每篇随机抽 2–3 道题（真题精讲/自测题）独立重算；抽 3–5 处真题引用与 `研究/原始资料/真题/转录/` 逐字核对 |
| P1 | 专题练习 13 册 + 模拟卷 3 套 | 每册随机抽 2 道题重算（含 1–9 届题目的解答）；模拟卷全卷抽 3 题 |
| P1 | 整卷模块 | 抽 1 届题面卷 vs 答案册的"题面一致性"；确认题面卷无答案泄漏 |
| P2 | 研究资料 | 勘误账/质检报告的存在性与自我一致性；考点地图关键数字的抽查 |
| P2 | 整体 | 结构完整性（14 篇体例统一度）、与大纲的覆盖匹配（拿官方大纲对一遍） |

## 四、评审维度（五个）

1. **数学正确性（权重最高）**：独立重算抽到的每道题（可用 Python 验证）；特别关注**跨篇引用的一致性**（如某题在两篇中出现，答案/结论是否一致）。
2. **真题引用真实性**：抽查的每处届数标注，能否在转录库中找到对应题面且吻合；有无编造或张冠李戴。
3. **内容完整性与规范**：篇目是否覆盖大纲八大板块；体例（七段式/符号体系/自测答案）是否统一；练习册结构是否可用。
4. **与考试大纲的匹配度**：以 `研究/原始资料/全国大学生数学竞赛考试内容_extracted.txt`（官方大纲）为准，检查内容边界（超纲/缺口）。
5. **元评审（评完上面再做）**：打开 `研究/质检/`（各篇质检报告、回归抽检两组）与 `研究/勘误账.md`，回答三个问题——① 项目自查发现的问题，你是否也发现了（交叉验证）？② 你是否发现了自查**没发现**的问题（盲区探测）？③ 自查报告与文档现状是否一致（有无"报告说修了但文档没改"）？

## 五、输出格式

评审报告写入：`研究/评审报告-外部评委.md`（如你觉得位置不便，也可写在任意临时位置后告知路径）。内容包括：

1. **评审概述**：实际抽检了什么（逐项列表：篇/册/题号）、各维度验证方法
2. **发现列表**：每条"[严重度 高/中/低] 位置：问题 → 证据 → 建议"；无问题的维度明确写"抽查 N 项，全部通过"
3. **元评审三问**的逐条回答
4. **总体结论**：可直接交付 / 小修后交付 / 需大修；以及 1–10 分的整体质量评分与理由
5. 你最想提醒学生/用户的**前三件事**

完成后向 `cmc-9d` 汇报（SendMessage）：报告路径 + 发现统计 + 总体结论。
