## 推荐使用顺序

1. 先读 [`教学文档/CMC手把手精讲-00-总纲与考点地图.md`](教学文档/CMC手把手精讲-00-总纲与考点地图.md)，了解考点分级与五周冲刺路线；
2. 按专题阅读精讲，完成对应 `练习/专题练习/` 中的配套练习；
3. 考前用 `练习/历年真题整卷/题面卷/` 限时模考（建议顺序 17 → 16 → 15 届），再用答案册复盘；
4. 冲刺阶段使用模拟卷 A（基础）→ B（标准）→ C（冲刺）。
