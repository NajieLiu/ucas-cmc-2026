拿到一个微分方程题
   │
   ├─ 是二阶常系数？（y''、y'、y 前的系数是常数）
   │     → 特征方程 → 齐次通解 →（非齐次）待定系数 → 初值定常数
   │
   ├─ 是一阶？（只有 y' 与 y）
   │     ├─ 能分离？（y'=φ(x)ψ(y)）──────────→ 分离积分
   │     ├─ 同次/只含 y/x？─────────────────→ u=y/x
   │     ├─ y'+P(x)y=Q(x)？────────────────→ 线性公式
   │     ├─ y'+Py=Qy^n？───────────────────→ 伯努利 z=y^{1-n}
   │     ├─ 凑得动微分？（x dx、y dy、x dy-y dx）→ 凑微分四式
   │     └─ 分式线性（带常数项）？───────────→ 平移化齐次
   │
   ├─ 是高阶？（y''=f(x) / y''=f(y,y') / 欧拉型）
   │     → 逐次积分 / 令 p=y' / x=e^t（保底项）
   │
   └─ 题面没有"方程"二字？（积分恒等式、路径无关、偏导条件）
         → 隐藏型：求导或代入，先把方程"挖"出来
   │
最后一步（永远要做）：回代原变量 + 定常数（通解留 C，特解算到底）
